# AI 助手：本地与远端运行

需要 Tunnelde 0.25.0 或更新版本，以及来自独立 [Tunnelde Hub](https://github.com/TunneldeDev/tunnelde-hub)
的 1.3.0 或更新版助手插件。从旧版基于配置方案的位置选择器升级时，请同时更新桌面程序与插件。

## 选择接入方式

各类编码助手插件启动对应机器上安装的编码代理，并使用其对应的结构化协议。远端运行通过 SSH 承载标准输入和
输出，不需要公开代理端口；通用 ACP 适配器尚未实现。API 助手需要配置服务商 URL、准确的模型 ID 和 API 密钥，
可以在本地或选定 SSH 主机上的独立进程中运行。远端模式下服务商网络请求从该主机发出，因此回环地址指远端机器。

每个插件分别安装、授权、启动和停止。设置、服务商密钥和对话不会在插件之间迁移；编码 CLI 自身的登录状态和
模型或服务商配置仍保留在执行机器上。

## 常规设置

1. 从**插件 → 市场**、本地文件夹或 ZIP 安装并授权插件。
2. 为插件选择 Node 运行环境。未经同意，应用不会使用系统 Node。
3. 编码助手需要在执行机器上安装并登录相应 CLI。受支持的远端目标在初始化期间也可提供需要明确批准的私有安装。
   本地代理使用其官方安装程序；仅当可执行文件不在该机器的 PATH 中时才需要覆盖路径。
4. 在聊天输入区打开**运行位置**，选择**本地**、已连接主机或已保存主机的**连接 · 主机名称**。**新建主机**打开常规主机编辑器。
5. 连接已保存主机时，使用正常的凭据与主机密钥验证弹窗；成功后自动选为当前对话的目标，不会打开终端或发送消息。
   凭据仍在连接弹窗中处理，不要粘贴到 AI 消息中。模型或服务商配置与运行位置分开。
6. 原生 SFTP 路径解析器读取主目录或目录元数据，不列出主目录，也不执行 shell。无需复制内部会话 ID。可选工作
   目录接受 `~` 和相对路径；本地目录提供原生选择器。
7. 首次发送消息前点击**初始化**。该操作检查代理协议但不发送提示词；若提供**安装并初始化**，安装需要单独批准。
   错误发生时消息草稿会保留，所选目标通过初始化后才可发送。仅选择目标或打开视图不会启动代理。

每个对话记住所选目标。更改已有内容的对话的机器或工作区会创建另一对话并保留原对话；重连后，只能重新绑定到同一
已保存主机身份。目标断开时返回连接错误，不会静默改为本地运行。

普通远端位置选择器目前支持 POSIX SSH 主机。本地 Windows 可运行；Windows SSH 盘符/SFTP 映射会被明确拒绝，
不会误当成 POSIX 路径。

## 远端运行环境授权与文件

在插件详情中检查已安装的助手版本；更新桌面程序不会自动更新插件。当前远端部署将其拥有的文件放在远端主目录下的
应用目录中。旧安装可能在主目录直接创建 `.tunnelde-*` 目录；对话或运行时仍在使用时不要删除相应目录。

编码助手通常通过 SSH 直接启动选定的二进制文件；某些集成需要事先批准上传权限扩展到新建的
`.TunneldeAI/Chats/pi-permissions-*` 目录，以通过其代理协议转发工具决策。

API 助手的远端运行需要在位置对话框中选择已有的远端 Node 22+ 可执行文件，并批准部署到新建的
`.TunneldeAI/Chats/tunnelde-ai-*` 目录。应用不会通过执行自动发现或安装 Node。当源码指纹和主机身份匹配时，
该对话会复用已批准部署。仅上传插件源文件；配置、对话状态和模型密钥通过加密的 SSH 标准输入提供，桥接进程
保留内存状态，桌面端保留插件存储。

私有运行环境安装在 `.TunneldeAI/Runtimes/node-*`；下载归档在验证和解压后移除。对话部署保留以供复用，
删除前会与记录的文件哈希核对。删除远端对话需重新连接其主机以完成清理。已知旧源码目录在下一次获批部署时
迁移到 `Chats`；未跟踪目录和已有运行时可执行文件路径会保留。

私有源码目录用于复用，不覆盖已有用户文件或系统服务。设置失败时只尝试清理自己创建的项目。普通运行使用活动
SSH 连接，可通过聊天控件停止并报告连接丢失；不提供自动离线执行或脱离连接后的恢复。

## 作用范围与审批

所选工作区为模型工具提供默认路径、命令工作目录和 SSH 会话上下文。`workspace_context`、`list_sessions` 和
`list_hosts` 提供当前上下文及受限发现；机器列表返回已授权元数据，不包含密码或密钥材料。路径参数缺失不再
意味着没有连接主机。

| 模式     | 行为                                                            |
| -------- | --------------------------------------------------------------- |
| 请求批准 | 命令与修改由用户审核                                            |
| 代我批准 | 使用独立 API 审核；拒绝、失败或无效结果会退回人工审批           |
| 完全访问 | 明确选择受支持的无限制执行，仍保留所选目标上下文                |
| 只读     | API 读取/发现工具或 Codex 的受限读取沙箱，不提供 shell/修改工具 |

Claude Code 和 Pi CLI 的工具设置无法提供这里要求的可验证操作系统只读沙箱，因此这些组合不提供只读模式。可执行插件和
编码代理拥有其账号的权限；作用域校验不能替代对任意命令的操作系统沙箱。

## 高级持久监督进程

旧版持久部署仍可在折叠的高级配置中使用，需要明确指定部署目录、远端运行环境及可选的匹配原生辅助程序；它与
普通位置菜单分开。参阅[原生辅助程序设置](../native-helpers/README.md)。不要假设断开连接的监督进程已经停止；
重连后应显式检查并停止。
