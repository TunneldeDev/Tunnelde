# 快捷键

打开 **设置 → 键盘快捷键**，使用 `Ctrl/Cmd+Shift+F12`，或在命令面板中搜索“键盘快捷键”。
可以按命令名称、命令 ID、上下文或按键搜索。点击绑定可替换，点击 **+** 可添加其他绑定；
按下组合键后选择保存。冲突会标红，也可以保留。按 Escape 取消录制。

安装或更新插件时，如果新增绑定与其他命令冲突，可以选择保留某一方、保留冲突，或在设置中解决。
在搜索框输入 `@is:conflict` 可筛选冲突；添加 `@plugins:插件ID,另一个插件ID` 可筛选相关命令。
保留冲突时，适用的命令可能都会执行。插件的实际快捷键取决于插件声明和用户配置，
没有插件提供时不会出现格式化快捷键。

修改会自动保存，并随设置配置方案导入导出。移除所有绑定可以禁用命令；可分别重置命令，
也可以选择**重置所有快捷键**。文件、编辑器和终端命令分别在相应视图生效；普通输入框
保留文本编辑快捷键。输入法组合输入和 AltGr 不会触发命令。方向键、Tab 和 Escape 等
控件导航不由快捷键编辑器重新映射。

以下为默认绑定；macOS 上通常使用 Command 代替 Ctrl。

| 按键                           | 操作                                     |
| ------------------------------ | ---------------------------------------- |
| `F1`、`Ctrl+K`、`Ctrl+Shift+P` | 快速访问：`>` 搜索应用与插件命令         |
| `Ctrl+P`                       | 快速访问：文件与已打开的标签             |
| `Ctrl+Shift+F`                 | 快速访问：`%` 搜索文件内容               |
| `Ctrl+N`                       | 新建主机                                 |
| `Ctrl+B`                       | 显示或隐藏当前侧栏                       |
| `Ctrl+,`                       | 打开设置                                 |
| `Ctrl+Shift+F12`               | 打开快捷键设置                           |
| `Ctrl+W`                       | 关闭当前标签；未保存的编辑内容会提示确认 |
| `Ctrl+Shift+W`                 | 关闭焦点所在窗格                         |
| `Ctrl+\` / `Ctrl+Shift+\`      | 向右 / 向下拆分标签                      |
| `Ctrl+Tab` / `Ctrl+Shift+Tab`  | 当前标签组的下一个 / 上一个标签          |
| `Ctrl+1` … `Ctrl+9`            | 切换到当前标签组中指定位置               |
| `Ctrl+=` / `Ctrl+-` / `Ctrl+0` | 放大、缩小或重置等宽字体                 |
| `Ctrl+X` / `Ctrl+C` / `Ctrl+V` | 在文件面板剪切、复制和粘贴文件           |
| `Ctrl+S`                       | 保存当前编辑文件                         |

在终端中，普通 Control 组合键通常留给 shell，例如 `Ctrl+K`、`Ctrl+N`、`Ctrl+B`、
`Ctrl+W`、`Ctrl+\` 和 Control 加数字。可使用 `F1` 或 `Ctrl+Shift+P` 打开快速访问，
使用 `Ctrl+Shift+N` 新建主机，使用 macOS 的 `Cmd+W` 或其他平台的 `Ctrl+Shift+W`
关闭终端标签或标签组。设置、标签切换和字体大小快捷键仍可使用。终端中的自定义工作台
Control 快捷键通常需要 Shift；设置、快捷键设置、标签切换和字体大小命令除外。插件注册的快捷键
不一定需要 Shift；终端自身处理的按键仍然优先。
对话框和输入法组合输入优先处理按键。

在快速访问中输入 `>` 加命令或插件名称可执行命令；输入 `%` 搜索内容，输入 `@` 查找已保存主机。
文件与内容搜索使用选定目录，可选择已连接的文件面板和远端编辑器作为根目录，也可以通过文件夹
按钮选择本地目录。搜索结果在编辑器中打开到匹配位置。

## 终端剪贴板

| 按键                           | 操作                                      |
| ------------------------------ | ----------------------------------------- |
| `Ctrl+V` / `Ctrl+Shift+V`      | Windows 和 Linux 粘贴                     |
| `Cmd+V` / `Cmd+Shift+V`        | macOS 粘贴                                |
| `Shift+Insert`                 | Windows 和 Linux 粘贴                     |
| `Ctrl+C`                       | Windows/Linux：有选区时复制，否则发送中断 |
| `Ctrl+Shift+C` / `Ctrl+Insert` | Windows 和 Linux 复制选区                 |
| `Cmd+C`                        | macOS 复制选区                            |

右键菜单提供复制、粘贴和全选。粘贴使用本机剪贴板和终端的括号粘贴机制，以适应远端程序。

## 文件面板

| 按键                                                    | 操作                        |
| ------------------------------------------------------- | --------------------------- |
| `↑` / `↓`                                               | 移动选区                    |
| `Shift+↑` / `Shift+↓`                                   | 扩展选区                    |
| `Enter`（Windows/Linux）、`Cmd+↓`（macOS）              | 打开文件夹或文件            |
| `Backspace`（Windows/Linux）、`Alt+↑`、`Cmd+↑`（macOS） | 转到上级目录                |
| `Alt+←` / `Alt+→`                                       | 返回 / 前进                 |
| `F5`、`Cmd+R`（macOS）                                  | 刷新当前目录                |
| `Ctrl+H`、`Cmd+Shift+.`（macOS）                        | 显示或隐藏隐藏文件          |
| `F2`、`Enter`（macOS）                                  | 原位重命名选中项            |
| `Ctrl+L`                                                | 聚焦并选中当前路径          |
| 文件名输入框中的 `Enter` / `Esc`                        | 确认 / 取消创建或重命名     |
| `Delete`、`Cmd+Backspace`（macOS）                      | 确认后删除选中项            |
| `Ctrl+A`                                                | 全选                        |
| `Home` / `End`                                          | 选择首项 / 末项             |
| `Ctrl+N` / `Ctrl+Shift+N`                               | 在当前面板新建文件 / 文件夹 |
| `Space`                                                 | 预览本地或远端文件          |
| `Esc`                                                   | 清除选区                    |

鼠标 `Ctrl/Cmd+单击` 添加或移除选区，`Shift+单击` 选择范围。删除、传输、剪切、复制、
粘贴和拖拽对整个选区生效。

## 窗口操作

- 中键点击标签可关闭标签。
- 拖动后台任务窗口标题栏可移动，拖动边缘或角可调整大小。聚焦标题栏或右下角手柄后，
  可使用方向键移动或缩放；按住 Shift 每次调整一个像素。拖动中按 Escape 取消调整，
  否则关闭列表。双击标题栏或选择重置布局可恢复默认位置。
- 页面和插件详情在每个窗格中复用斜体预览标签；再次选择同一项目或双击标签可保留。
  操作页面控件或拖动标签也会保留它。
- 通过标签右键菜单选择**保持打开**或单独**固定 / 取消固定**。`tab.keepOpen` 可在快速访问
  中使用，也可绑定快捷键。
- 将标签拖到另一个窗格的标签栏可移动，拖到窗口边缘可创建相应位置的窗格。
- 右键点击标签、主机或文件可打开其上下文菜单。
- 在设置 → 常规中切换系统标题栏与紧凑标题栏。紧凑模式下，拖动手柄或空白标签栏区域
  移动窗口，双击可最大化或还原；macOS 保留原生窗口按钮。
- 在两个文件面板间拖动文件或文件夹可复制；拖到同一面板可重命名或移动。面板可显示本机
  或已连接的会话。
- 拖动编辑器组分隔线或聚焦分隔线后使用方向键调整大小；双击或按 Home 恢复均分。
