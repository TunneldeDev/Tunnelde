# 公共面板布局

`src/lib/layout/types.ts` 定义可序列化的 `PanelLayoutNode` 树。叶子记录面板 ID，
拆分节点记录 ID、方向、比例和两个子节点。比例为 0 到 1 的小数，工作区现有的
序列化结构保持兼容。

`src/components/ui/layout/` 下的 `PanelLayout` 是受控渲染组件。调用方传入布局、
`renderPane(paneId)`、`onResize(splitId, ratio)` 和已翻译的分隔条无障碍标签。
组件不依赖工作区、存储、文件管理或插件模块。布局有效性、持久化、停靠、标签操作和
隐藏面板状态由调用方负责。保持节点 ID 和渲染回调稳定，可以在调整比例时保留挂载内容。

`SplitPanels` 为布局树和功能双栏提供同一套分隔行为，支持横向／纵向、flex／grid、
可配置边界、分隔条尺寸、键盘与复位操作。拖动时每个动画帧最多直接预览一次 DOM 几何，
松开后才通过 `onRatioChange` 提交。指针取消、Escape、失焦或卸载会丢弃预览，
恢复最新受控比例，包括拖动期间通过键盘提交的比例。指针移动不会保存偏好或重渲染子面板。

工作区 `PaneLayout` 只负责适配状态仓库。文件管理 `FileSplitView` 使用同一个公共
分隔组件，保留原有本地偏好适配和 20–80% 边界。存储键改变时重新挂载偏好适配层，
防止不同文件视图互相覆盖比例。工作区仍使用 15–85% 边界。

应用与插件面板继续通过现有工作区停靠宿主接入，共享位置、尺寸、显隐与标签操作。
此次重构不会把实验性的插件工作区 API 自动提升为稳定接口。

行为检查见 `tests/components/PanelLayout.test.tsx`、
`tests/components/PaneLayout.test.tsx`、`tests/features/FileSplitView.test.tsx`
及工作区／侧栏停靠测试。新增消费者应复用公共控件，避免重新实现指针监听或持久化。

## 综合工作台面板

`WorkbenchPanel` 是内置面板和插件侧栏的默认综合容器，内部组合公共标题栏、位置菜单、
展示状态和小窗几何控制。业务只提供一份正文和可选的 `PanelHeader` 操作，宿主将操作
移入统一标题栏，避免重复标题。只有特殊用途才直接组合底层基础组件；任务、连接详情、
输出、文件预览和插件侧栏不再分别维护小窗与面板外壳。

`SidebarContents` 为已访问面板保留唯一 React 所有者，`SidebarMount` 在侧栏、工作区和
小窗之间移动同一个 DOM 容器。同文档切换保留搜索、选择、展开和滚动；关闭只隐藏展示，
不停止 SSH 会话、任务或插件运行时。工作区关闭保留隐藏槽位。小窗使用通用状态并迁移旧
任务几何数据；进程内检查点可恢复已打开的小窗，但冷启动不自动弹出临时小窗。插件贡献
被移除时清理展示；停止运行时保留已安装视图的启动占位，运行时资源仍按作用域释放。

此机制只适用于同文档，不等于跨 WebView 所有权交接；没有明确交接协议前，不得声称
原生独立窗体能够保留 DOM 或所有临时状态。

### 实验性插件控制

通过 `extensions.describe().panelPresentations` 发现支持的展示方式与方法。
`workspace.panels.list` 返回 `{revision,windowId,panels}`，仅包含标识、可用性、位置、
可见性、固定状态和几何数据，不包含业务正文、草稿、密码或任意 store。

- `workspace.panels.observe({revision?})`：revision 不同时立即返回，否则等待变化或最多
  十秒。revision 是进程内不透明值，不提供持久重放；取消会释放监听。
- `workspace.panels.setPresentation({panelId,presentation})`：将现有面板移到 `sidebar`、
  `workspace` 或 `floating`。文件预览必须已存在，插件面板必须仍在贡献列表中。
- `workspace.panels.close({panelId})`：隐藏面板，不停止业务资源。

读取和观察需要 `workspace.read`，变更需要 `workspace.write`。正常请求授权、取消与
回复前的运行时代次检查保持不变。`workspace://panels-changed` 仅是包含 `{windowId}` 的
UI 失效通知；RPC 插件应使用 `observe` 并重新读取，不可从事件交付推断当前状态。
冻结的 `workspace.snapshot` v1 不变。

## 分隔线交点

`SplitGeometryScope` 不增加布局包裹节点，可连接由 React portal 保留的不同正文。
应用在工作台外统一接入；独立使用 `SplitPanels` 时会自动提供局部作用域。不同 DOM
根分别处理，因此小窗不会调整无关工作区边界。几何注册使用实例级 ID；语义 split ID
只需在同一所有者／批量回调内唯一，不要求不同布局根之间唯一。所有者或拓扑变化会
取消旧手势。

宿主按真实分隔线段寻找 T 型或十字交点。交点可同时调整两轴，相接的同轴线段共同
移动，无关线段不参与。各参与者使用自己的容器尺寸和上下限，按最严格的公共位移
限制保持对齐。预览复用帧级指针控制，不重渲染正文或逐次持久化；Escape、指针取消、
失焦和卸载恢复最新受控比例。方向键调整单轴，Shift 精细调整，Home 或双击重置。

为 `PanelLayout` 提供 `onResizeMany` 以原子更新一个所有者的布局。工作台通过
`workspace.resizeSplits` 一次发布两轴变更。独立控件保留 `onRatioChange`；跨不同
业务所有者的手势按所有者各提交一次，不声称独立持久化适配器属于同一数据库事务。
插件可通过实验性的 `workspace.resizeSplits({ratios:{splitId:ratio,...}})` 操作，
需要 `workspace.write`；一至三十二个已知 ID 和有限的 0.1–0.9 比例全部通过校验后
才执行一次变更，既有工作区尺寸限制仍会钳制比例。冻结的 workspace v1 不变。

## 原生视图交接（开发中）

独立窗体不能再次启动整个应用。`panel_windows` 使用宿主签发的文档身份与
带 generation 的面板租约；迁移流程为 prepare → 目标惰性渲染并保持 inert →
确认就绪 → 主窗单例提交。超时、取消、重载或已撤销的目标不能获得操作权。
关闭独立窗前须先归还视图；崩溃恢复依赖有大小限制的内存检查点，不能持久化
秘密草稿，也不能复制业务 store 或重新创建后台资源。

适配器须显式加入 `windowViews.transferablePanel`。目前已适配连接详情、后台任务、输出与可信主机密钥：
主窗发布显式的只读投影，独立窗通过 `ConnectionModelScope` 复用相同内容，
不向可写业务 store 灌入副本。局部 React 状态通过 `usePanelViewState` 显式登记，
滚动与光标使用稳定的 DOM 标记单独保存。目标树须先实际渲染，再原地提升为所有者，
不能重挂载；已提交的局部状态和 DOM 事件会合并生成原生检查点，不能用空壳或
加载动画充当目标就绪。

私有原生控制协议是封闭枚举。只允许协调器发布投影；读取须验证当前完整租约，
或有效迁移中的目标身份。元数据和事件均不携带投影、凭据草稿或文档令牌。
独立窗的普通业务 IPC 默认拒绝；任务／断开操作使用封闭请求，在校验发起文档与完整
租约后入队，仅由主窗领取一次。任务回调始终保留在单例注册表中；实例票据拒绝替换
来源的旧按钮，但进度更新不会让按钮持续过期。未领取工作可取消或超时；已领取工作
须等主窗完成清理，不能因发起文档重载或执行器局部作用域释放而解除迁移保护。
即使领取回复晚于本地释放，也必须最终回报，不能用普通读取的释放后检查丢弃它。
请求、结果和票据均不得进入元数据或事件。
主窗入口应聚焦实际所有者，不能再创建一份同面板内容。

`PanelWorkspace` 组合既有 `PanelLayout`／`SplitPanels` 与 `WorkbenchPanel`，
提供文档内标签、横纵分栏、浮动及合并，只移动保留的 portal 容器，不重建 React 或
资源所有者。独立窗几何状态只放内存，不能覆盖主窗偏好。关闭单个面板只归还该视图，
关闭原生窗口才归还全部。从独立窗再次拆出目标窗，须在原生创建前后校验当前可交互的
适配器租约；只有创建文档能丢弃空目标窗，已初始化但放弃的目标也须自动回收。
原生销毁前须在所有权锁内预留空窗关闭，避免新迁移与平台销毁竞争；前端取消或重载
不能解除预留，只有原生销毁失败清理或实际销毁可以。

以上是分步实现，并不代表多窗功能已全部完成。其他内置面板、插件及原生跨窗拖拽仍需
适配与平台验收，传输专用重连／确认界面及插件任务界面提供者也仍须完成窗体适配。
不能提前宣称支持，也不能以放宽网关权限
掩盖适配缺失。公开插件 workspace v1 协议保持不变。

### 协调器中断与有界视图状态

协调器文档重载不能证明已领取的任意回调所提交的原生副作用已经停止。须将结果标为
未知，禁止重放，并按面板在原生层保留隔离保护；结果 TTL、来源销毁、认证解锁或复用
面板 ID 均不能解除它。显示可见警告并保持正文 inert；用户检查资源状态后须重启软件
解除此进程内保护，不能提供不安全的自动重试或强制解锁按钮。

重复列表使用 `PanelViewStateGroup`，由一个父字段聚合行状态，仍受严格 JSON 以及
整体字节、节点和深度限制。长列表不能在渲染时抛错；超限应在交接前捕获阶段拒绝，
保留可编辑的来源及全部草稿，不得截断以凑合迁移。

文档内指针拖拽支持标签排序、边缘分栏及中心停靠，包含浮窗的停靠手柄。保留的 portal
沿 React 祖先链传播事件而不是物理 DOM 链，因此接收区须用原生捕获监听校验文档内
不透明令牌。手势期间将被拖浮窗排除出命中测试，在松手、Escape、取消、失焦或卸载时
恢复其原有样式。

### 原生拖拽桥接（开发中）

通用指针驱动须区分正常松手与 Escape、丢失捕获、失焦、卸载；文档内已接收的拖放应
取消原生授权。跨窗松手前，宿主签发的短期、单次授权必须已经就绪，不能等待延迟回复后
再读取已经变化的鼠标位置。原生松手入口须重新检查发起文档及可交互的完整租约；后续
交接仍须匹配该实例，不能按面板 ID 悄悄换成新所有者。拖拽就绪元数据和插件消息均不
携带授权或文档令牌。

目标由原生命中测试确定：已有注册窗、来源窗（不操作），或全部可见应用窗之外（新建）。
几何／查询错误不等于窗外，不得因此新建窗。macOS 鼠标位置使用主屏幕 backing scale，
窗体边界却使用各窗自身 scale，比较前须统一为 Cocoa 桌面点坐标；Windows／Linux
保留原生物理桌面坐标，不可信任浏览器 screenX/Y。

真实 WebView 内的合成指针测试只能验证网关和分阶段交接，不等于实际 OS 指针捕获、
各平台输入路径、混合 DPI 多屏硬件、SSH 传输连续性或所有内置／插件面板均已通过验收。
公开完整能力或发布前仍须完成这些要求。

### 输出适配与单例读取

输出使用主协调器的唯一 `OutputSource`，不能每个 WebView 各维护日志游标。
文档内视图保留读取需求；独立窗已拥有或正在接收输出时增加后台需求，因此隐藏主窗
不会停止更新。最后一个消费者释放后停止轮询；仅本地消费者且文档隐藏时暂停读取。
刷新合并执行，不重叠读取；在途读取期间清空不能复活旧行，来源释放后的迟到回复须忽略。

独立窗通过 `OutputModelScope` 复用 `OutputPanel`。筛选、通道、等级、自动跟随和换行
使用临时状态胶囊，滚动使用共享 DOM 标记。运行信息只投影显示所需元数据，不传递完整
AppInfo、插件运行令牌、安装／数据路径或全部设置。刷新、清空、打开日志／目录、复制
通过封闭的租约操作中继执行；独立窗不能直接调用日志、文件系统或剪贴板原始命令。

输出按完整行的 UTF-8 JSON 字节限制，而不是 UTF-16 消息长度。输出私有投影单独允许
2 MiB 包络，以容纳有界行及显示元数据；其他投影与草稿胶囊仍保留 1 MiB 限制。
输出内容及复制文本均不得进入公开元数据或失效通知。

### 可信密钥面板与文档级确认保护

已知主机视图共享协调者数据源，在不同窗口复用 `KnownHostsList`。卫星窗口只接收
可信密钥的展示投影，不开放原始应用 IPC。搜索及显式标记的滚动/焦点经临时快照
迁移；刷新和忘记操作使用绑定精确租约的封闭动作中继。

确认界面打开前必须取得 `beginInteraction` 保护。不透明令牌绑定文档和租约，阻止
迁移、新建目标窗、拖拽授权及关闭回收，但允许提交已确认的动作。多个重叠确认各自
释放自己的令牌；取得授权前组件已卸载，也要释放迟到的令牌。这些保护随文档重载或
崩溃失效，不等同于资源动作保护；已接收的动作仍独立保持原生围栏，直到完成，或在
协调者丢失时进入现有的结果未知隔离。

发起窗口使用共享受控 `ConfirmDialog`，不传递回调、不在主协调窗重复弹框。明确展示
确认对象的算法和指纹；删除时在同一事务核对地址、端口、算法、指纹和更新时间，
不能用过期确认删除新的可信密钥。保留信任生命周期失败回滚，失败时保持可见且可重试。
旧插件无条件删除操作保持兼容，内置界面始终提交预期密钥身份。确认框、令牌和回调
不得序列化到视图快照、元数据事件或持久布局。

### 可跨窗口复用的传输与连接展示边界

`ConnectionPrompt` 统一连接、主机密钥和凭据界面，仅接收精简主机展示投影及显式的
`ConnectionPromptServices`，不启动 SSH、不读取主协调窗的凭据或主机 store，也不跨窗
导航。现有 `ConnectDialog` 是主窗口专用适配层，保留原生目标审核、单例连接获取和
工作区导航；卫星窗口不得使用它补缺，远程服务缺失时不能回退为本地原始接口。
连接质量测试及其取消必须经过同一个所属后端。忘记凭据的嵌套确认留在发起窗口，
失败时不能关闭确认或清除已保存凭据的提示。

传输行通过 `TransferTaskControllerScope` 接收控制器，不把执行直接塞入展示组件。
原生窗口控制器须根据当前所属任务解析封闭的位置类型，不接受视图任意传入的路径。
本地回退保留捕获的会话身份复核，不得把已断开的远程目标解释成本地路径。卫星窗口
缺少显式控制器时直接拒绝。展开状态、限速编辑器及未完成的草稿使用分组临时快照，
进行中的副作用不属于草稿。

原生传输适配在每条命令执行前核对来源及任务实例票据，只投影明确的传输展示字段和
可检查位置，不复制会话句柄或可写 store。协调者根据当前任务解析封闭的位置类型，
远程失联不能解释成本地路径。检查路径是显式用户操作，通过已注册文档的原生显示
网关唤起主窗口文件工作区，不放宽通用窗口 IPC 权限。

重连确认挂载前必须先取得精确原生保护令牌；原生在动作接收和领取时分别校验令牌。
多个缺失端点顺序确认时保持同一保护，每次副作用独立持有资源围栏，界面关闭不代表
副作用已结束。取消不得恢复传输；任务或确认句柄过期后，即使远程关闭失败，用户仍
能关闭本地确认并释放界面保护。暂停、取消、恢复须等待后端接收，不能把 store 的
异步发起误报成已完成。

审核连接句柄必须私有，并绑定租约代数、任务实例及保护令牌；限制数量和空闲生命周期，
所属窗口或来源失效时退役，仅取消该句柄自己命名空间内的诊断测试。凭据及密钥操作
限定在已审核路由主机内，后台连接请求由协调者构造，不接受任意目标。已保存凭据状态
随一次私有准备批量取得，避免无限并发中继动作。密钥安装路径、审核令牌及凭据不得
进入读模型、快照、公共元数据或事件。组件清理不能撤销已接收副作用的独立原生围栏。

### 独立插件视图传输

前端单例激活/就绪状态留在协调窗口；视图传输是有数量上限、可撤销的子级，不是互相
竞争的激活。已批准的不可变资源应共享引用。视图不能确认或上报单例激活失败；关闭
它不能撤销兄弟视图或依赖消费者。替换/关闭激活会撤销所有子级及其待处理调用。可选
状态工厂本身不授予原生窗口权限，也不代表提供者句柄已经支持跨窗口。尤其不能用异步
工厂外壳替代提供者同步挂载 Workspace/Screen 的契约。逐文档授权、状态警告和领域
网关齐备之前，保留旧渲染路径。

协议 CORS 使用受信任配置中的开发 URL origin，不回显请求的 Origin，也不硬编码
开发端口；打包应用的 origin 保持不变。隔离原生 QA 的标识和数据，不接触已安装应用；
需测试真实模块导入，而不只是 mock 加载器。

### 公开原生窗口元数据与生命周期 API

`extensions.describe().nativeWindows` 声明实验性、权限受控的 RPC：
`workspace.windows.list/observe/create/close` 和 `workspace.panels.ownership`。
读取要求 `workspace.read`，生命周期操作要求 `workspace.write`。不改变冻结的
`workspace.snapshot` v1，不暴露私有文档令牌、草稿快照或模型，也不授予卫星窗口底层
应用 IPC 权限。所有者 generation 和 `canMove` 仅供参考，实际修改仍检查原生状态。

list 和 ownership 返回同一份带 revision 的原生快照，包括窗口角色、就绪/关闭状态、
面板 ID 与当前所有者 generation。observe 是先订阅后检查的、可取消的十秒长轮询；
单纯业务进度不会改变 revision。`workspace://windows-changed` 仅包含不透明 revision
作为失效提示。RPC 插件可用 observe 替代原生 JS 事件；revision 不保证持久重放。

create 返回宿主构造的隐藏卫星占位窗口，使用现有原生多显示器定位，全局最多 16 个
窗口。不接受 URL、脚本、调用方窗口标签或任意原生命令。空占位窗口二十秒后回收。
创建等待被取消时，后台保留原生构造直到实际完成，清理迟到的空结果，包括已发送却未
被接收方读取的结果。插件撤销仅清理其旧 generation 的空占位窗口，不能销毁已有用户
面板的窗口，也不能中断正在交接的面板。

close 仅请求正常的卫星窗口捕获/归还流程，不能关闭协调窗口、强制卸载视图、丢弃草稿、
绕过凭据确认或停止 SSH/任务。`{windowId, requested: true}` 仅表示接受请求，不表示
已经关闭；应观察原生元数据确认结果，或在交互保护解除后重试。原生关闭或捕获失败时
必须保留可恢复的所有权。

平台创建或设置窗口失败时，也必须复用原子空窗清理预留，不可直接销毁目标窗口。
目标可能在创建者返回前就已接收其他用户面板；创建者刷新或失去权限不代表可以
销毁这些面板，也不能中断正在进行的交接。

### 公开移动请求必须在源文档执行

`workspace.panels.moveToWindow` 要求 `workspace.write`、已支持的面板及已就绪的现有
原生目标窗口。可选 `expectedOwner` 的窗口与 generation 用于拒绝过期自动化请求，
而不是悄悄改动新一代所有者。原生层记录双方文档身份、预留面板，只允许精确源文档
领取封闭、不透明的捕获任务。不可从协调窗口旧 store 捕获卫星草稿，也不能转发任意
UI 命令。

只有原生 prepare/ready/commit 才转移所有权；RPC 在提交后返回新 generation，不在排队
或捕获后提前完成。领取、准备及提交均重查插件权限；最终有界元数据提交在权限锁内
执行，与撤销线性化。锁顺序为原生所有权 -> policy -> invocation，撤销清理先释放
policy 再访问原生窗口。invocation 围栏在条目锁内同步重查传输取消与期限，并持锁完成
有界提交；不能因为异步调用方尚未再次被轮询，就绕过已经返回的取消。围栏内禁止业务
资源操作、await 或获取请求注册表。提交前取消/撤销必须删除预留或 staged offer，
保留源所有权；提交后取消不撤销已接受的移动。刷新、崩溃、超时、视图未就绪、移除面板只清理对应请求，不能把业务资源
当成请求的附属资源。

待处理移动最多全局 32 个、单插件 8 个，请求生命周期 25 秒，另受正常交接时限约束。
源执行器销毁时要释放迟到领取及未完成预留。协调器提交失败后若原生确认 offer 已退休，
应刷新快照，不要把预期取消误报为新错误。请求调用方负责错误展示，卫星不因插件取消
请求而弹出无关错误 toast。可移动能力仍按适配器显式启用，不能假称未支持的 provider
已经具备原生多窗口能力。

### 源文档展示适配器

每个文档只安装一个私有展示适配器。协调窗口适配器必须拒绝修改其他窗口所有的面板；
卫星适配器只使用本地布局与浮窗 slot，不读写主窗口业务 store，也不启动资源引导。
向原生源路由提供封闭布局元数据与同步 set/hide/reveal 操作，不能提供任意 store
访问。卫星支持 workspace/floating，不可把不支持的 sidebar 请求悄悄转成其他形式。

隐藏本地视图时保留原 slot、分隔比例与 portal 所有者，只在渲染投影中裁去隐藏区域，
不能破坏源布局；再次显示要恢复同一个 DOM、草稿与分组。原生成员移除仍须释放 slot
及观察者。适配器只操作当前文档；公开面板 API 必须经过原生所有权路由，不能用协调
窗口代理来修改卫星布局。

原生聚焦必须显示请求的面板，而不是只抬起一个仍选中其他标签的窗口。聚焦后仅通知
原生采样的所有者 lease，重查文档与 generation；源文档只显示精确匹配、非 staged 的
当前视图。聚焦不能启动资源、恢复插件激活或扩大卫星的应用 IPC 权限。

### 公开面板元数据与已接受展示操作

`workspace.panels.list/observe/setPresentation/close` 由原生 workbench RPC 处理。
读取要求 `workspace.read`，修改展示要求 `workspace.write`。list/observe 投影各精确
所有者 lease/文档发布的封闭布局元数据：窗口、展示形式、可见性、固定状态、有界位置、
可用性与支持形式，不包含视图内容、凭据、草稿快照、插件令牌或业务模型。冻结的
workspace v1 不变。源尚未发布时应返回 `panel.window.viewNotReady`，而不是伪造主窗
状态；list 最多等两秒，observe 最多等十秒。不可用的文件预览目录行只属于主窗，且
不能显示为可见。

布局 revision 与资源进度分离，先订阅后检查快照；`workspace://panels-changed` 仅发
不透明 revision 提示。目标确认前要发布实际 staged 布局元数据，提交时随新所有者
原子复制，保证移动成功后不会报告旧源位置。刷新或所有者变更后，旧元数据失效，
直到精确源重新发布。

set/close 预留封闭源操作，绑定插件 lease 和同步 invocation 围栏，只允许精确源领取
一次。原生 Begin 按所有权 -> policy -> invocation 锁顺序重查所有权、交互、权限及
取消；它是操作被接受的准入点。Begin 前取消应释放预留且不改 UI；Begin 后，调用方
取消、超时或权限撤销不能回滚已接受的同步展示效果。原生围栏须保留到源完成或精确
文档消亡，不能在迟到 Begin 回复仍可能修改视图时，允许其他窗口取得它。取消窗口
关闭不代表文档退休，不能释放已接受效果；效果结束前也不能复用面板 ID。

Begin 返回后，执行器重查生命周期和适配器，并在没有中间 await 的情况下同步修改
自身布局。完成时提交真实元数据：set 必须可见且形式匹配，close 必须隐藏；失败则通过
仅清理用途的精确源调用释放任务。迟到领取、销毁或适配器替换不能修改已退休视图。
效果结束前应预留该面板的元数据发布通道，避免旧刷新覆盖已完成结果；其他面板仍应
正常发布，不能被单条迟到的 Begin 回复阻塞。
待处理操作限制全局 32 个、单插件 8 个，排队 TTL 十五秒，RPC 最多等待二十秒。
这些操作只改变展示：隐藏保留渲染器、slot 和草稿，不停止 SSH 或其他业务资源。
源不支持的展示形式明确失败，不能转而修改主窗口。

### 异步临时视图状态捕获

面板交接与检查点等待 `captureAsync`；同步捕获仍兼容内建同步字段，但明确拒绝仅支持
异步的字段。每个面板同时共享一次捕获，总期限为 15 秒。取消某个等待者不释放不响应
取消的渲染器所占名额；所有选中回调（包括兄弟回调失败后仍运行的回调）实际结束后才
允许下一次捕获。沿用严格 JSON、字段数和总大小限制，不截断草稿。内容变化使在途快照
失效；窗口适配器仅在原总期限内重试，发布前再次校验精确控制器、租约与 DOM 根。
状态胶囊不持久化，也不进入公共元数据。

工厂渲染器通过面板作用域绑定 `{version, pluginId, viewId, state}`。恢复结束后才挂载
真实渲染器；暂存确认必须等待真实视图提交就绪，并覆盖随后注册的子字段。加载占位和
错误回退均不视为目标就绪。焦点和光标恢复同时等待就绪与所有权提交；来源 DOM 状态
必须在 `inert` 导致失焦前捕获，回滚时等待本地与原生冻结均解除后恢复光标。渲染异常仅隔离
对应面板；暂存失败回滚到原来源。不支持状态的工厂明确拒绝捕获，不伪造空状态。

独立窗口关闭前异步捕获全部面板，再调用原生 `beginClose`，校验其原子冻结的成员与
捕获租约逐一相符。失败仅取消已经开始的原生关闭，并按精确原租约解除本地冻结，旧
清理不得解冻替代实例。文档销毁取消等待，禁止迟到结果继续准备交接。

这只是异步状态与就绪链路的基础，**不代表插件原生视图网关已完成**。可跨窗的内建
适配器仍须逐项启用，不能据此开放独立窗口插件激活或原始 RPC，也不代表旧插件状态
警告与提供者等价性已经完成。

### 原窗口插件确认（内部网关）

原生视图的 `ui.confirm` / `ui.showMessage` 排队发送到精确的所属窗口及文档，
不得转发给隐藏的协调窗口。失效通知不含提示文本或能力。受限的列表/回复网关
从原生调用者获取窗口身份，校验文档与请求归属，并在最终交付锁内重新校验面板
租约、视图 token、插件代次/权限与调用取消状态。暂存或冻结视图不能发起确认。
锁顺序为所有权 -> 前端模块 -> 插件策略 -> 调用；同步门内不得重入安全或原生
所有权锁。

确认在结束前持有面板交互锁，阻止交接。每个原生窗口最多一个确认，每个插件
最多八项 UI 排队，全局最多 64 项。确认 55 秒超时返回 false，消息 15 秒超时。
传输取消或权限/文档撤销会撤下旧确认，不允许迟到的批准。两类文档共用确认
控件，不导入主窗口资源启动流程。既有用户对话框不能被替换；消息只展示一次
并确认接收。失效刷新加有限轮询在漏掉事件时同样撤下过期提示。文档销毁拒绝
当前确认，并忽略迟到 UI 回复。

`mounts.runtime.requestForceUnmount` 独立审查，只有已提交的原生视图可调用。
宿主私有的 `__mounts.forceUnmount` 提示始终使用危险操作样式，默认焦点为取消；
公开 `ui.confirm` 的参数不能选择此路由。待确认请求持续绑定 `mounts.write`、
精确原窗口及原调用。批准绑定规则、组、revision、运行实例和会话；接受后在组锁内
复核，文件系统探测结束、真正准入前再次检查，不能把旧确认用于替换后的实例。

保留的卸载策略按原窗口、权限、调用、运行状态的锁顺序，仅在元数据准入内同时提交
取消竞争和 `desired:false`，通知必须在释放这些门之后发送。准入前取消、撤权或
身份变化不修改原意图；准入后工作线程持有组锁直到卸载、子进程回收及宿主状态更新
全部结束，即使结果投递过期或权限变化也必须完成。成功清空实例及会话；失败保留
精确的清理预留、`cleanupRequired` 与 `desired:false`，阻止后台自动重新挂载。
最终状态更新是已准入副作用的收尾，不是另一项需要重新授权的插件写操作。前端
在发布确认框前登记精确回调，允许同步接受、关闭、替换或销毁，不能误关后来出现的
其他对话框。单元测试中的子进程夹具不等于真实 FUSE 挂载验收，验证报告必须区分。

旧挂载的 `mounts.legacy.list/convert/dismiss` 同样仅允许已提交的原生视图。
在等待或派生线程之前捕获原窗口及调用围栏；SQLite 互斥忙时退出所有准入门，
在有界工作线程中重试，不能阻塞异步执行器或持有策略锁等待数据库锁。
转换全程保留组锁和挂载注册表锁：以同主机、组 revision 和新规则 ID 校验并保存，
提交后无异步间隙地转移挂载所有者并登记运行实例，即使调用取消也必须收尾。
失败不转移所有权；一次性挂载原有的用户 SSH 会话只被借用，不能登记为专用连接，
不能随组连接释放而断开，也不能让恢复器把它误当成组连接。

`mounts.runtime.open/reveal` 在真正系统启动准入前，复核原窗口、原调用、写权限和
精确规则 revision／组／挂载实例／会话。注册表与组预留贯穿探测、路径包含校验及
系统启动；不能先取快照，再让卸载或替换抢先发生。嵌套文件系统超时仅结束结果等待，
实际线程仍持有原生副作用围栏和这些预留，直到真实调用返回。macOS 设备查询、
路径规范化、兼容打开操作及 Linux 有界挂载表读取共用保留工作线程的机制。
系统打开／定位在元数据准入门外执行；准入后完成已接受的操作，不因权限变化
重新授权收尾。测试中模拟系统打开或使用普通子进程不等于真实 FUSE 或文件管理器验收。

该内部传输及测试不代表生产插件面板适配器或资源 RPC/原生窗口能力已经完整。
实际适配器、真实副作用生命周期和原生验收完成前，能力发现仍保持保守。
面板 ID 接受完整插件/视图组合身份（7 + 128 + 1 + 128 个 ASCII 字节），不能
为了旧的 256 字节限制截断不同的 ID。

## 普通页面与空分组

所有内置工作区页面均可通过标签或分组菜单打开为同文档小窗。`PanelFrame`
是页面与 `WorkbenchPanel` 共用的表面、几何与 Escape 底座，两者只是适配器，
不是两套窗口系统。`WorkspaceContents` 始终只持有一次页面；`TabContent`
移动保留容器，保持编辑器草稿、终端实例及组件状态。浮动分组保留停靠目标与
返回分组；Escape 或“移至工作区”只回停靠，标签关闭才真正关闭页面。
拖动小窗标签到其他分组沿用工作区拖放适配器。浮动几何为临时状态，不扩展冻结
的 workspace v1，冷启动将保存页面恢复为普通分组。这不是原生窗口交接；
原生窗口仍必须使用前文的独立所有权协议。

插件可在 Manifest 的视图条目声明 `allowFloating: false`，省略则允许。
宿主在修改入口强制执行限制，并从能力快照及菜单中移除该展示方式。
内置页面不能采用允许列表或自行禁用小窗。所有浮动适配器共享一套叠放时钟。

侧栏、面板和标签顶栏统一采用 `--td-workbench-header-h`。空分组不显示标签
工具栏、锁或更多按钮，但内容区仍接受拖放。紧凑原生窗口仅保留必要的窗口
控制/拖动安全区。工作区面板不得重复显示标签栏已有的移动/关闭操作；业务
命令仅保留一套。输出的频道、搜索、错误等级、跟随、清空和更多位于标签栏
下方的同一业务工具栏，不向标签栏注册输出操作。

## 关闭连接消费者

`disconnectOnPanelClose` 默认开启，旧设置文件同样使用此默认值。显式关闭
页面后，仅当该精确会话的最后一个终端、SFTP 数据源、编辑器或监控消费者
消失时释放连接。双文件面板必须追踪两侧数据源。普通页面关闭不释放转发或
挂载规则持有的连接。移动、回停靠、隐藏或卸载组件不能断开连接。用户可关闭
设置以保留后台会话。该新增设置通过 `settings.get/update` 和设置配置档开放，
不得暗中扩展冻结的公共 preferences v1。

连接管理复用 `SearchToolbar`/`SearchField` 的文本、`@type`、`@status` 和
`@host` 解析。只允许选择当前可见的活动结果，查询变化清空选择。批量确认
绑定固定 ID 集合，限制并发清理数量，失败项保留以供重试。历史记录可以搜索，
但不能选择执行断开。

`mounts.dependencies.documentation` 只打开宿主指定的平台安装说明链接，不会为了打开说明扫描
FUSE 路径或运行 SSHFS。持久规则与旧入口都捕获原始窗口/请求，在浏览器启动准入时重新验证
`mounts.read`；有界启动工作者保留原生效果直到实际调用完成，即使调用方已取消交付。
浏览器启动在准入锁之外执行，暂存渲染器不能打开说明。

卸载前的存在性与挂载身份探测也必须在内部超时后保留原注册表/组预留，直到实际文件系统
工作者返回。探测超时不等于工作结束；不得让重试、规则接管或替换提前穿插。

### 转发面板视图状态适配

转发面板的主机选择、规则编辑身份、不完整输入字符串及组编辑/名称草稿使用通用临时面板胶囊。
外部导航先收敛到明确选择，目标文档不必复制主窗口导航仓库。草稿绑定主机、规则与 revision；
空端口保留字符串，直到用户明确保存。新组尚无 ID 时也携带主机身份。取消会注销草稿；
捕获本身不保存规则、不连接、不重启，也不写入偏好。

提供者的延续权限属于当前文档，绝不能序列化或在目标窗口悄悄升级为不受限的内置权限。
提供者编辑、待完成的连接/确认及进行中的规则/组修改必须拒绝捕获。
该捕获检查不是原生效果栅栏，也不表示转发原生窗体适配完成：原生资源准入、原窗口交互、
共享数据/操作传输以及提供者句柄仍须独立验证。

### 转发共享读取源

主机详情和全局转发面板保留同一份单例规则源及显式分组源。私有命令
`forwarding_groups_list` 接受可选主机 ID；省略时读取全部分组，包括没有规则的空组。
消费者按主机身份筛选，不能从规则行推断分组存在。第一个订阅者启动观察与读取，
最后一个订阅者退出时停止观察、清空快照并隔离已放弃读取的迟到响应。
连续失效合并为一次后续读取。组修改即使部分失败也刷新两个源，手动刷新同样重试两者。
此文档内共享源只是跨窗口数据/操作传输的前置工作，不代表后者已实现。

### 宿主持有挂载维护与旧安装说明入口

插件查询不再把全局进程/桥接清理当作隐藏的前置操作。已有宿主恢复循环负责非阻塞注册表维护，
也覆盖没有持久组的一次性挂载。注册表被精确事务预留时跳过本轮，后续再试；保持健康工作者、
所有权及原有清理错误。进程退出不等于文件系统消失，不能据此删除挂载记录。
仅记录新的清理状态时发送变更通知。

已有 `mounts.documentation` RPC 与 `mounts.dependencies.documentation` 共用原窗口、读取授权
及请求栅栏约束的浏览器启动器，不再经过旧注册表清理或依赖探测。两者只允许已提交的原生视图调用。
这不表示其他旧挂载别名已准入，也不代表物理 FUSE 或系统浏览器验收完成。
