## 额外修复

- 远端删除目录符号链接改为删除链接本身，避免跟随链接递归误删目标；复制/传输拒绝跟随符号链接。
- 覆盖目标必须确认；文件/目录类型冲突拒绝；复制失败或取消保留源。
- 编辑器保存基线使用提交时快照，避免慢保存吞掉后续输入；断线保留未保存草稿，禁用保存并支持重连校验远端变动。
- 系统窗口关闭按钮和紧凑关闭按钮遇到未保存草稿会确认；取消保持草稿，关闭到托盘继续保留窗口状态。实际 Windows 程序验证取消、托盘保活与确认后退出。托盘“退出”和 macOS Cmd+Q 仍走独立退出流程，尚未纳入统一草稿确认。
- 真实服务器验证发现并修复短文本保存残留旧尾部；写入显式截断、不重建已删除文件，并等待远端关闭确认。严格检查 UTF-8 编码、二进制内容及实际读取大小，避免静默损坏文本。
- 连接/断开去重，断开失败保留会话；迟到快照不能复活已关闭会话。
- 远端监控共享采样、慢请求不重叠、隐藏暂停；进程列表结果按会话隔离。本机监控在面板收起和文档后台时同样暂停，恢复后立即采样。
- 设置写入、重置和加载串行；失败回滚保留后续修改；布局写入合并最新状态；初始化部分失败不会错误清除已保存标签。
- 插件状态和刷新拒绝过期结果，忙碌状态按插件独立；插件市场同时安装的状态互不覆盖。
- 原始终端输入历史默认关闭，可显式启用，避免将密码提示或交互程序输入自动当成命令记录。
- 修复现有 CSS 多余闭合括号，以及超长中文自定义 CSS 在 UTF-8 字符中间截断导致的后端 panic。

## 运行验证范围

在 Windows Tauri 程序中使用独立的 `.tmp/review-native-data` 和插件目录运行，不使用用户的正常应用数据。

- 实际指针拖动：主机顺序写回数据库，标签排序保持单组，边缘拖放创建分栏。
- 实际本地文件操作：界面内新建、重命名、重命名目标滚动定位、跨面板拖拽复制、目标列表刷新、Alt+← 后退；独占创建拒绝已有文件。
- 实际原生 IPC：读取系统语言、切换系统/紧凑标题栏、读取插件 ZIP 清单并在安装弹窗预览。
- 实际 Windows 窗口操作：系统/紧凑来回切换后验证四边与四角缩放；验证最小化、最大化、还原、拖动以及隐藏右面板后的按钮让位；紧凑模式没有新增标题行，标签关闭图标居中。
- 渲染夹具：通过真实 Tauri 事件通道发送 ANSI 数据，确认红/绿、256 色橙色、RGB 紫色及 Fira Code；分栏后终端 DOM 和输出仍保留。
- 编辑夹具：模拟远端文本读取，修改草稿、移动编辑组、标记断线，确认同一 textarea 和草稿保留且保存按钮禁用。

使用用户提供的测试服务器完成 46 项真实 SSH/SFTP 检查：主机指纹/密码连接、Unicode 与长文件名、独占创建、覆盖保护、递归复制与合并、目录上传下载和二进制校验、取消/失败后保留源、符号链接保护、ANSI 颜色、只读监控/进程查询、界面内创建重命名刷新、实际指针拖拽上传下载、路径快捷键、编辑器快捷键保存、断线保留草稿及重连冲突处理。另验证同会话文件覆盖移动、目录合并移动及类型冲突保留源。所有写入、重命名和删除均限定于新建 UUID 临时目录，测试目录已清理；未修改服务器服务或既有用户文件，未执行免密配置。

操作系统桌面文件拖入以及 macOS/Linux 原生窗口交互仍需对应环境实机验证；外部拖入路由有组件回归，macOS/Linux 构建由发布 CI 验证。SFTP 协议 mock 另覆盖短/空文本截断、已删除文件不重建、写入/关闭失败以及等待关闭确认。
