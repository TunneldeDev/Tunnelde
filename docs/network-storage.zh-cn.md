# 网络路由、传输与 SSHFS

连接测试的结果和局限请参阅[连接质量指南](connection-quality.zh-cn.md)。

这些功能需要桌面版 0.27.0 或更新版本。现有主机及偏好保留原值；代理和跳板均为可选配置。

## 各功能代理

打开**设置 → 网络与代理**，添加命名的 HTTP CONNECT 或 SOCKS5 代理配置，再选择默认路由。
应用更新、插件市场与下载、SSH/SFTP/端口转发、本地插件进程以及各个插件可分别覆盖路由。
每一项可以继承默认路由，使用系统代理、直连或命名配置。代理密码存储在操作系统凭据库中；
密码留空会保留已有密码，“忘记已保存的代理密码”用于删除已保存的密码。连接测试使用测试控件
中选定的路由。

代理连接和身份验证在同一配置中分别编辑；窄面板会纵向排列控件，单个插件的覆盖配置可折叠。
连接测试分别标明目标地址和端口与代理服务器，测试期间锁定输入。

系统模式下，SSH 和原生 HTTP 请求使用系统或环境代理及绕过规则，但不执行 PAC 脚本。
显式 SOCKS5 路由通过代理解析目标主机名；指定代理不可用或拒绝连接时，请求失败，不会静默直连。

本地可执行插件和 AI 任务通过 `HTTP_PROXY`、`HTTPS_PROXY`、`ALL_PROXY` 及对应小写环境变量
接收显式代理配置，回环流量绕过代理。系统模式继承进程环境，不会将桌面系统代理配置转换成环境变量；
可执行程序必须支持这些变量。修改路由后需重启正在运行的插件。远端进程使用远端主机的出站网络设置。

设置配置方案包含代理元数据和各功能选项，不包含代理密码。导出的元数据包含代理用户名和地址；
在另一台计算机导入后需要重新输入密码。删除代理或重置网络偏好会忘记被移除配置的已存密码。

## SSH 跳板机

编辑已保存的主机，展开**代理与跳板机**，选择代理并按连接顺序添加已保存的主机，最外层跳板排在首位。
可以使用相邻控件调整顺序或删除。路由最多包含八台不同的跳板机，目标主机不能同时作为跳板。
这个列表即完整路由，不会递归展开跳板主机自身保存的跳板列表。

仅第一条 TCP 连接使用目标路由的代理；后续跳转通过已认证的 SSH `direct-tcpip` 通道完成。
每一跳都使用各自的密码或密钥认证及主机密钥校验。连接对话框会标明正在审核的机器，请求缺失的
跳板凭据，并在允许连接前验证目标主机。更换路由不会绕过主机密钥信任；SFTP、端口转发和 SSHFS
复用认证后的连接。

## 传输性能

在**设置 → 文件 → 传输**中，可以独立设置上传和下载总限速，单位为 KiB/s。两项默认为 `0`
（不限速），立即作用于运行中的任务，并在并发传输和 SFTP 数据通道之间共享预算；即使关闭传输优化，
限速仍然生效。远端到远端传输同时使用上传和下载预算，本地磁盘复制不使用这两个预算。限速针对文件
传输负载字节，不包含 SSH 帧或终端流量。

运行中任务上的速度表按钮可设置任务限速。`0` 跟随全局限速，正值增加任务上限，不能超过全局
上限。任务限速随任务保存，暂停、重连和应用重启后仍然生效；设为 `0` 可恢复为仅使用全局限速。
低速传输仍报告进度，暂停和取消可以中断限速等待；改变限速时
已经发出的请求可能完成。等待带宽额度时仍会推进已发出的 SFTP 请求，各分块保留受限请求流水线；
修改限速不会重启文件或重置偏移量。

传输优化默认启用。分块并发数、分块大小和每分块 SFTP 请求数默认均为**自动**。应用对小文件使用
更少的分块，对较大的远端文件最多自动使用四个分块；手动并发可选择 1、2、4 或 8。本地复制保持顺序执行。
分块大小可自动选择或设为 256 KiB、1 MiB、4 MiB、16 MiB；每分块请求数可自动选择或设为 1、4、8、
16、32，总在途请求上限为 64。设置在开始或恢复时生效，并随配置方案保存。

后台任务共享调度器：整个应用最多同时运行四个传输任务。每条 SSH 连接最多使用六个传输通道；
每个端点预留一个元数据通道和一个数据通道；开启优化的持久任务还为每个端点预留归档通道，
远端覆盖任务则为目标预留原子提交通道。因此同一连接可同时执行两个优化或覆盖上传/下载、
三个无需额外通道的传输，或者一个最多占用六个通道的同连接复制。
源端和目标端的额度一起预留。
其他任务在打开通道前显示**排队中**。不同连接可以独立推进，共享端点的任务保持队列顺序。
排队期间也可暂停或取消；等待不占用文件句柄，取消或停止插件会释放队列预留。重启后的任务保持暂停，
直到用户主动恢复。

并发分块在独立 SFTP 数据通道上使用显式文件偏移。上传、下载和远端复制遵守服务器声明的包大小限制，
处理短读取，且不会预取越过分块边界。元数据和目录操作保留独立通道。上传包大小使用服务器声明的写入
限制，内存上限 256 KiB；未声明限制的服务器使用兼容的 32 KiB 回退值。每个排队包适合两个端点，避免
在较大的逻辑包内部串行等待写入确认。每一组分块开始前，日志记录已确认的连续前缀；恢复时先丢弃被中断的
分块窗口再校验前缀，不会把稀疏写入当作完成数据。关闭文件句柄或清理临时文件前会停止并排空工作项。

### 自适应传输压缩

启用传输优化时，**自动压缩传输数据**默认开启。普通分块传输中，总大小小于 256 KiB 的任务继续使用标准 SFTP。
较大任务先从第一个源文件采样最多 16 KiB；如果数据适合压缩，会尝试通过已有认证 SSH 连接启动临时
Python 3 工作进程。不可压缩任务保留 SFTP 流水线。目录任务复用初始传输方式，但之后的每个数据块仍
独立决定是否压缩。工作进程只使用远端标准库，不安装脚本或服务，SSH 流关闭时退出。缺少所需 Python、
POSIX 文件操作、exec 权限或 SFTP/exec 主目录不一致时会回退到 SFTP。

每个有界数据块先采样；仅当样本和完整数据块均至少节省 10% 时使用快速压缩，已经压缩或随机数据通常
原样传输。上传、下载和远端复制仍保留显式偏移、共享请求限制、限速和持久检查点。工作进程只打开已有
普通文件，不创建或截断文件。压缩读写校验输出长度，并拒绝截断或尾随数据。暂停、恢复和取消沿用普通
SFTP 任务拥有的暂存与清理规则。需要标准 SFTP 数据路径时，可在文件设置中单独关闭压缩；修改在开始或
恢复时生效，并随配置方案保存。

进度和速度显示原始文件字节，即使压缩后网络上传输了更少数据。压缩收益取决于内容以及 CPU 和网络瓶颈。
对不覆盖已有文件的目录复制，优化还会在已有通道上重叠处理文件准备、数据传输和提交。
自动模式最多同时处理四个目录项；手动并发可选择 1、2、4 或 8。嵌套目录共享这个上限，
不会按层级重复增加并发。目录项分摊任务的请求预算，已确认的进度集中汇总；失败或取消后，
停止启动排队项，等待活动写入收尾后再清理任务。覆盖任务仍顺序执行原子提交。
普通 SFTP 服务器可以使用目录并发流水线，无需安装远端程序。

### 小文件归档

开启传输优化后，目录复制可以将不超过 64 KiB 的小文件合并为内存归档，每批最多八个文件、
归档最大 1 MiB。上传、下载和远端复制使用上述临时 Python 工作进程；不在磁盘上创建归档，
也不安装远端脚本。归档成员采用数字名称，与单独校验的文件清单对应，拒绝任意路径、链接和
特殊文件。每个目标文件仍经过原有的任务暂存、源文件检查、持久检查点和逐文件提交流程。

上传归档前会记录暂存文件的写入代次。如果写入被中断且未收到确认，恢复时会先移除旧暂存文件，
再创建新名称的暂存文件，不会复用旧路径。只有受影响的小文件重新传输，已完成文件保留已验证的进度。
迟到的请求既不能重新创建旧路径，也不能写入新代次的文件。暂停还可以中断归档检查点的只读元数据等待。

归档功能独立于压缩开关；开启压缩时，仅当至少节省 10% 才压缩该批数据。单个文件、大文件、
已部分恢复的文件、覆盖任务、不支持工作进程的主机，以及无法取得整批限速额度的任务沿用
标准分块流水线。动态限速仍然有效。目录工作项共享归档通道，调度器会将其计入每连接的通道预算。
不足一批时会及时发送，不必等待所有工作项；失败或取消后，先等待活动写入收尾再清理。
进度按写入已确认的原始文件字节计算。

开始复制前，Tunnelde 会扫描源目录以估算大小。远端扫描复用目录列表中明确提供的文件类型与长度，
缺少信息时再单独查询。整个目录树最多同时进行四项元数据操作，并遵守更小的自定义请求预算。
展开子目录前会重新检查目录类型。目录不可读、符号链接、特殊文件或必要元数据缺失会在创建目标前
停止准备并报告错误。总大小是进度估算；实际复制和恢复时仍会检查每个文件。

## 暂停与恢复传输

Windows 本地文件移动如果需要先复制，会在复制前持有源文件句柄，阻止普通写入和替换。删除源文件前，
应用会锁定已完成的目标文件，逐字节比较两侧内容并将目标刷盘；将文件身份、长度与 SHA-256 持久化到
删除检查点和通过句柄删除源文件时始终持有两侧
句柄。已有写入者、校验失败、取消或检查点保存失败都会保留源文件。此保护适用于本地普通文件，不代表
远端或 Unix 移动也具有相同保证。

其他需要先复制的持久文件移动，会完整比对已提交的目标与源文件，然后保留源文件并显示**需要检查**。
SFTP 和 Unix 按路径删除无法保证已检查的文件在删除前未被替换或修改。请检查两侧文件，再自行决定是否
删除源文件；清除任务会保留两份文件。额外读取仅用于移动，不影响普通复制或同主机原子重命名。

在不同 Windows 盘符之间拖动本地文件或文件夹时，会建立后台复制任务并保留原项。剪切并粘贴文件时会
建立后台移动任务，仅在移动成功后清除对应剪切项；关闭文件视图或暂停后恢复不会丢失这项联动。失败或
取消会保留剪切选择，旧任务完成也不会清除后来复制或剪切的新选择。同一来源且盘符相同的移动继续使用
重命名。需要先复制的文件夹移动仍不可用，请改用复制。此盘符判断不识别同一盘符下的挂载卷、UNC 共享
或远端挂载边界。

状态栏的后台任务入口可从任意页面打开紧凑任务列表，也可通过 F1 搜索后台传输；隐藏状态栏时，入口会
出现在窗口底部角落。可以固定列表以便在其他页面工作。运行/暂停、需关注和已完成分组均可折叠，已完成
默认折叠；大分组每次加载 20 条。展开任务可查看源和目标路径、剩余字节与任务限速。传输运行时文件面板
保留完整高度。

后台传输结束或暂停时会通知相关文件面板刷新；即使原文件视图已关闭，之后从后台重试也能刷新当前打开的
面板。复制刷新目标来源，移动还会刷新源来源。短时间内的多个完成通知会合并为每个相关面板一次目录读取，
不刷新无关主机。

拖动窗口标题可移动，拖动任意边缘或角可缩放；位置和大小在关闭、重启及托盘窗口重建后保留，应用窗口
缩小时会限制在可见区域。双击标题或选择重置布局可恢复默认角落位置。聚焦标题后使用方向键移动，聚焦
右下缩放手柄后使用方向键缩放；按住 Shift 每次调整一个像素。拖动时按 Escape 取消本次调整，否则关闭列表。

列表提供暂停、恢复、取消和清除。桌面拥有的传输会在本地保存任务和逐文件进度。中断或重启后，连接相同
已保存主机并在列表中恢复，无须因终端会话 ID 改变而重建任务。缺少主机连接时，恢复可以打开连接对话框，
仍执行正常的密码与主机密钥检查。应用使用与原主机及记录地址匹配的最新连接；改变主机地址不会静默重定向
旧任务。本地传输可直接恢复。

数据写入任务拥有的同级 `.tunnelde-….part` 文件。正常暂停会保存已关闭暂存文件的大小和修改时间；源文件
和暂存元数据均匹配时，恢复校验首尾数据块并从保存的偏移继续。中断写入、旧版任务或暂存元数据变化时，
使用完整前缀校验。源文件变化或部分文件不匹配会被拒绝。校验具有独立可见状态，其元数据请求、只读文件
打开、读取和关闭均可取消；延迟的读取或 CLOSE 响应不会阻塞暂停，共用连接仍可继续使用。关闭空的远端
暂存句柄，或关闭所有写入均已确认的数据句柄时，也可以在暂停后停止等待，且不会中止目录内其他文件共用的
目标数据通道。若有写入结果尚不确定，仍保留有时间限制的 CLOSE 等待，之后才允许恢复截断暂存文件。
正常传输仍须收到 CLOSE 确认才继续完成；恢复截断和创建新的远端暂存文件也仍需等待服务器确认。

在最终远端重命名期间暂停，会停止等待响应，并保留事先记录的发布不确定状态。恢复时，若已完整写入的
暂存文件仍存在，会先将它移动到预先记录的新一代暂存路径，再继续使用；延迟到达的原重命名无法发布
替代暂存文件。恢复重命名的响应丢失时，会重试同一代路径。若原重命名已经完成，恢复会完整比对目标与
源文件后才报告成功；目标缺失或内容变化会校验失败，后续重试也保留此保护，不会重新上传并覆盖目标。
正常传输仍在收到发布确认后才报告完成。上述保护以任务暂存路径未被其他应用独立修改为前提。

新的远端覆盖任务会在上传前协商 `posix-rename@openssh.com` 版本 1。暂存新文件期间，原目标仍可读取；
暂存写入关闭后，通过一次服务端原子重命名替换目标，不创建备份。不支持该扩展的服务器会在写入新的上传
数据前拒绝覆盖，不会先删除原目标作为退路。如果提交确认丢失，恢复会将已完成目标与源文件核对后再报告
成功。这保证目标的原子发布，不代表能隔离特权干预或暂存路径上的并发修改。

本地覆盖和已记录备份事务的旧远端任务继续使用可恢复且经校验的原目标备份流程。
移动操作在复制成功后才删除源文件，并单独记录检查点。
如果应用在删除源文件期间中断，恢复不会重新开始复制。带有新删除检查点的 Windows 本地文件移动会重新
取得保护句柄，将两侧身份及完整内容与保存的摘要核对后再删除源文件。源文件已不存在时，仅在原目标的
身份、长度与摘要全部匹配时报告成功。被替换的文件（包括内容完全相同的副本）或内容发生变化的文件都会
保留并要求人工核查。已有写入者或 I/O 错误会保留检查点供重试；删除前暂停同样保留检查点，取消则保留
尚未删除的源文件及已经提交的目标。

缺少该证明的旧任务和其他平台仍需人工核查。仅凭源文件消失、目标存在不能证明移动成功。核查错误会保留
两侧路径并隐藏恢复按钮，请检查后再清除任务。此保护不覆盖特权干预、预先存在的可写内存映射或父目录路径
被替换的情况。
此类错误会直接显示两侧路径并隐藏恢复按钮；其他可恢复的中断传输仍提供恢复按钮。

暂停保留部分数据以便恢复；取消会停止传输并删除任务拥有的临时数据后才报告完成，保留已完成的目标文件，绝不删除
源文件。已取消任务不能恢复。如果清理失败（例如远端断开），任务进入**等待清理**且不可恢复，目标重新连接
后自动重试；重试按钮也可打开连接对话框。删除操作会先清理任务暂存文件再移除日志；若覆盖中断并留下原目标
备份，会保留备份和日志，避免覆盖同时创建的文件。任务显示最后检测到的备份和目标路径，无法识别的备份会
单独提示。已完成的目标文件和源文件均保留。目前尚不支持自动以不覆盖方式恢复备份。

本地传输在提交目标和建立备份时，使用系统提供的拒绝覆盖重命名。若其他程序在提交前创建目标，任务会
失败并保留该目标、暂存数据及已有备份。

Windows 成功传输后清理本地备份时，会锁定该文件，禁止常规写入、重命名和删除，校验大小、修改时间及
完整内容摘要后，通过持有的句柄删除同一个文件对象。已有写入者、备份变更或取消会保留备份和日志以便
重试。这不能隔离特权操作或内存映射修改。

Windows 本地下载会从新建暂存文件的句柄记录卷、完整的 128 位文件标识和创建时间。恢复时锁定已识别的
文件，禁止常规重命名和删除，同时允许传输写入与检查点裁剪。写入关闭后，通过始终持有的同一句柄重命名
提交，不先解锁再重新打开暂存路径；并发创建的目标会被保留。清理时打开并锁定文件、核对记录的身份，
再通过同一句柄删除。即使替换后的文件内容完全相同，也会保留该文件。无法识别的暂存文件（包括缺少身份
记录的旧版 Windows 任务）需要人工检查，不能直接恢复或清除。任务显示准确的临时路径，并提供打开父目录
的入口；确认文件不再需要后自行删除，再重试清理。文件系统无法提供可用标识时会安全失败并保留暂存文件。
这不能隔离特权干预、父目录重定向，也不代表所有目标提交竞态均已解决。

传输临时文件和备份仅使用文件删除操作。若路径已变成目录，会保留该目录，不递归删除其中内容。这不代表
SFTP 或 Unix 暂存文件删除能够原子地核对文件身份。已有备份事务在 SFTP 和 Unix 上写入新目标后仍保留旧目标备份，显示**需要检查**及
两份文件的路径。请检查后自行删除不再需要的备份，再清除任务；重试传输无法安全删除该备份。恢复路径旁
可直接打开应用内的父目录。远端目录只使用主机及地址均与记录匹配的有效连接，不会退回本地路径。

离线移除会在访问连接前持久保存清理意图；只有清理完任务拥有的文件后才删除日志，这一状态跨应用重启保留。
每次清理有等待上限，且不能与恢复并行。旧版目录传输若存在无法识别的原备份，会保留备份并报告需要恢复。
已完成记录可在离线时移除。

列表显示已传输与剩余字节、近期吞吐量及预计剩余时间。恢复后吞吐量历史重置，已有字节不计为新传输流量。
可执行插件发起的传输仍绑定授权的运行时，在应用重启或权限撤销后不能恢复。

## 本地与远程端口转发

在活动栏打开**端口转发**，可查看各已保存主机的运行端口数；展开主机管理其端口。
主机详情也提供入口。选择**添加转发**，再选择**访问远端服务**或**共享本地服务**。
编辑器分别展示监听端点和服务端点，并标明由哪一台计算机解析地址。名称可留空，默认使用服务地址和端口。
可选择**保存并启动**，也可仅**保存**为未启动规则。启动时按需建立独立后台 SSH 连接，凭据和主机密钥
验证仍按正常流程进行。同一主机下的端口共享这条连接；**全部启动**启动尚未运行的端口，**断开**停止该
连接及其端口。已有终端连接独立运行，无须选择 SSH 会话。端口转发面板可拖动到任意工作区分组，收起再
展开后保留布局。

| 方向                | 监听位置 | 目标由谁访问 |
| ------------------- | -------- | ------------ |
| 本地监听 → 远端服务 | 本机     | SSH 主机     |
| 远端监听 → 本地服务 | SSH 主机 | 本机         |

例如远端数据库监听 `127.0.0.1:5432`，可创建本地规则监听 `127.0.0.1:15432` 并转发到
`127.0.0.1:5432`，然后让本地应用连接 15432 端口。远程转发的目标地址指本机网络，而非 SSH 主机网络。

规则列表直接显示启动或停止；编辑、复制本地连接地址和删除位于各规则的操作菜单中。运行中的规则需要
先停止才能编辑。启动失败会保留在已保存规则旁，便于重试而不创建重复规则；保存失败会保留编辑草稿。
其他打开的转发视图会在变更后刷新。窄面板中端点分组会纵向排列。

停止时会等待本地监听器关闭，或等待 SSH 服务器确认释放远端监听。在此期间显示**停止中…**并禁用
操作，完成后即可编辑并立即重新启动同一端口。无法确认释放时会在规则旁显示错误，请先断开该主机的
转发连接后重试。中断后的清理也会保留远端端点占用，直到取消请求完成，避免旧清理关闭同端口的新监听。

规则会持久保存，但监听器需要连接后手动启动。默认监听回环地址，暴露监听器需要确认。远端监听受 SSH
服务器转发策略和 `GatewayPorts` 影响。停止规则或关闭所属会话会停止监听及现有转发连接；插件拥有的
规则也会在其权限撤销或运行时退出时停止。

## SSHFS 挂载插件

桌面端提供兼容插件可使用的原生挂载接口。从市场安装挂载提供者，打开其视图，选择已连接主机、浏览远端
目录，再选择本地空目录或 Windows 上未使用的盘符，例如 `Z:\`。挂载默认为只读；运行环境和权限授权
取决于提供者。

挂载面板检测 FUSE 与支持 passive/stdin 传输的 SSHFS 版本，缺少或不兼容时提供安装指引，但不安装驱动。
原生服务直接将已认证 SFTP 子系统连接到 SSHFS；密码和私钥不会作为进程参数传递，也不会暴露本地 TCP
桥接。操作系统中出现挂载后才报告完成，各提供者共享挂载点预留。

断开连接前请先卸载。断开、插件停止或权限撤销以及应用退出会关闭认证访问并尝试正常清理。目录忙时请关闭
使用它的文件后重试；强制卸载需要确认。挂载不会自动重启。驱动兼容性与各平台挂载行为需要结合所安装的
SSHFS 发行版验证。

## 文件预览

在任一面板选中文件并按空格、点击预览工具栏按钮或从右键菜单选择预览。文本预览为只读；Markdown 默认
渲染，并提供源码切换。本地文本限制为 512 KiB，远端文本使用现有的 2 MiB 读取限制。不支持的文件或
二进制文件会显示预览错误；远端预览使用所选面板的 SSH 会话。关闭预览后焦点返回文件列表；底部入口可
使用系统程序打开本地文件，或编辑选中的文本文件。

可从市场安装兼容的预览提供者，支持图片、音频、视频、PDF 等格式；运行环境与权限要求显示在插件详情中。
多个匹配提供者可在选择器中切换；不支持的二进制格式会提供市场搜索，而非显示原始字节。文件图标主题与
预览提供者相互独立。

图片上限 32 MiB，PDF 上限 128 MiB。音视频在用户操作后开始播放，并取决于系统可用编解码器。PDF 按需
加载，不执行文档脚本。远端媒体通过所选 SSH 会话执行有界范围读取，不在远端机器创建临时副本。
关闭预览会撤销访问票据并关闭文件句柄。内建文本与 Markdown 无须插件；由提供者处理的文本或 Markdown
上限为 2 MiB。支持的扩展名和资源限制见[预览贡献接口](plugins.zh-cn.md#文件预览提供者)。
