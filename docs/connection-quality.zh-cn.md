# 连接质量

[English](connection-quality.en-us.md)

## 网络与代理测试

在**设置 → 网络与代理 → 测试连接**选择连接方式和目标后，点击**测试连接**。
结果直接显示在按钮下方，包含连接延迟（中位数）、最快与最慢耗时、波动和成功次数；
展开每次结果可查看各次耗时或失败。可点击**重新测试**，修改目标、代理或默认路由后旧结果失效。

最多测量三次 TCP 连接，总时限 15 秒，沿所选直连、系统代理或已保存代理路径执行，
不会在代理失败时绕过代理。延迟包含 DNS、TCP 建连和必要的代理协商，不是 ping RTT、
网络丢包率或带宽测试，也不验证 TLS 或目标服务的应用功能。测试结束关闭临时连接。
失败不按 0 毫秒计算；不足 1 毫秒显示为 `<1 毫秒`。全部失败时耗时显示 `—`。
中位数不高于 100 毫秒标为延迟较低，不高于 300 毫秒为适中，更高为较高；部分失败会单独标明。

## SSH 主机测试

打开主机的连接对话框，首次读取主机密钥时会显示沿当前路径建立 SSH 的耗时。
整条路径的密钥完成信任后，在**连接质量 → 测试连接**中进行最多三次短连接测试。

结果包含建立耗时的中位数、成功次数，以及最慢与最快成功连接的耗时差。
展开**查看每次结果**可看到每次耗时或失败情况，失败不会按零毫秒计入统计。

这里测量的是连接建立耗时，包含 DNS、代理协商、SSH 密钥交换，以及必要的跳板登录。
它不是 ping 往返延迟、网络丢包率或带宽测量；三次成功也不能保证长连接一直稳定。
测试不会登录目标账号、创建终端、运行远端命令或读取文件；目标账号凭据会在正常连接时验证。

耗时中位数不高于 500 毫秒时标记为建立较快，不高于 1,500 毫秒时为正常，更高时为较慢。
部分连接失败会单独标明。请结合具体路由理解这些提示，多级跳板本身就需要更多建立工作。

测试沿用主机的代理和跳板配置，不绕过所选路径。整条路径必须已信任；遇到新密钥、
密钥变化、凭据错误或配置错误立即停止，不会自动接受密钥或重试错误认证。
密钥变化时会重新进入验证流程。

点击**取消**或关闭对话框可停止测试。切换目标、修改跳板凭据或信任状态也会取消旧测试，
旧结果不会出现在新目标上。总时限为 25 秒，同一主机只能有一个测试，全局最多同时测试
四个主机；探测结束后关闭临时 SSH 连接。
