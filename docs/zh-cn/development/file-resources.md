# 文件读取与预览生命周期

编辑器、内置预览及插件提供者预览共同使用 `src/lib/files/resources/` 下的宿主读取
生命周期。`target.ts` 固定不可变的请求坐标，`read.ts` 适配文本读取，`preview.ts`
管理原生预览凭据和有界文本组装。它们复用扩展运行层已有的 `ResourceScope`，
不另建取消引擎，也不增加公开插件方法。

目标保留原始路径，以及本地来源或明确的 SSH 会话 ID。它不是规范文件身份、
别名解析器、授权、快照或删除文件的依据。调用者之后修改来源对象不会改变
已经请求的读取目标。

销毁会停止投递并请求取消。原生 IPC 可能仍在进行，其作用域额度直到实际 Promise
结算才释放。消费者还根据当前文档或预览激活状态检查返回结果。关闭视图不表示
文件写入已停止或回滚。

## 预览所有权

每次提供者预览都使用宿主新生成的唯一凭据 ID。原生提供者发现尚未结束时关闭
视图，会先请求关闭；打开成功结果迟到后再次关闭，因为原生注册可能晚于第一次
关闭请求。清理始终使用请求 ID，不使用尚未验证的返回 ID。正常打开的凭据保留
到视图关闭或渲染器失败。

读取前校验返回 ID、选定渲染器、安全整数大小及原生渲染器限制：文本/Markdown
2 MiB、图片 32 MiB、PDF 128 MiB、音频/视频 1 TiB。文本每段最多读取 1 MiB，
在一个有界缓冲区中组装并校验 UTF-8 和 NUL 字节。打开、元数据、分段读取、解码、
PDF 或媒体失败时立即开始清理。重试使用新凭据；切换语言不重新打开正常预览。

保留文件句柄不承诺文件系统快照不可变。原生预览注册表、I/O 限制和远端会话检查
仍为最终依据；发出清理请求不能证明原生清理已经成功。

## 原生本地读取

本地预览区间、内置文本预览和插件本地文本读取复用
`src-tauri/src/services/files/read/`。服务解析用户明确选择的路径别名，再通过平台
标志打开普通文件，拒绝最终路径被替换为符号链接、重解析点或特殊文件。保留已打开
句柄，并串行执行定位与读取。Windows 读取允许已有日志写入者继续写入；编辑器用于
安全发布的严格句柄仍独立保留。祖先目录解析遵循操作系统，并非文件系统沙箱。

本地阻塞 I/O 与远端协议 I/O 共用最多八个排队或执行中的读取/打开任务。即使异步调用者超时或关闭，
容量仍由实际工作线程持有，直到它退出。已取消的排队工作跳过 I/O；等待文件游标锁的
读取在取得锁后再次检查取消。已经执行中的文件系统 I/O 仍可能继续完成。容量满时
返回明确的繁忙错误，不继续排队。单次字节读取最多 32 MiB，以保留整张图片预览；
HTTP 区间仍最多 1 MiB。文本前缀沿用调用方原有限制，多读一个字节判断是否超限。
其他程序仍可修改文件，保留句柄不等于获得不可变快照。

本批次不增加公共 RPC 或插件权限。完整公开内容与预览资源仍需独立的生命周期、
权限、传输与 SDK 契约。

远端预览也复用同一来源服务，为每个来源保留独立的只读 SFTP 通道和已打开句柄。
每条 READ 都携带明确偏移和受限长度，不共享可变预读游标。收到短包时从实际返回的
位置继续补读，不越过请求区间。服务遵循协商后的包/读取限制，拒绝空 DATA 或超长
响应，并检查已打开句柄的普通文件类型及明确返回的大小。

调用者取消后，实际任务仍持有配额，直到当前协议响应结束，之后跳过后续请求并停止
投递。OPEN 确认迟到时关闭已放弃的通道。读取错误或整次读取超时会在释放配额前
关闭该专用通道，保留用户的父级 SSH 连接。来源通道最多 64 个，包含尚未完成的打开
和仍由任务持有的通道。打开最多 15 秒、单条协议响应最多 15 秒、整次读取最多 30 秒。

SFTP v3 不提供本地 `O_NOFOLLOW` 的保证，也不能控制服务器阻塞中的文件系统操作。
关闭通道表示请求释放远端资源，并不证明服务器的系统 I/O 已停止。来源固定的是句柄，
不是不可变文件内容；本层仍不增加公共内容或预览 RPC。

## 编辑器请求

打开、关闭、断线或被新请求替代都会使旧读取失去投递资格。并发重连采用最后一次
明确意图。首次加载被打断时记录尚未读到基线，重连后可填入文档，避免误报冲突或
一直加载。断线期间输入的文本保留；已成功加载的草稿遇到远端基线变化时，仍需
明确审查。旧内存检查点通过已有加载/错误字段推断基线是否可用。

保存合并绑定文档代次和准确 Promise。被替换文档的旧写入不能阻塞新保存、清除新
任务、修改新基线或弹出过时错误。保存期间继续输入仍保留未保存状态。替换文档
不会取消、重放或回滚已经开始的写入；原生基线检查仍然必要，本层不是写入事务。

稳定编辑器 API 和实验性缓冲区比较交换契约不变。文件修改所有权、持久写入结算、
跨来源移动，以及完整的共享文件数据/订阅契约仍是独立待办。
