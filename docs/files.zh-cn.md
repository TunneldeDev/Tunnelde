# 文件管理

[English](files.en-us.md)

从活动栏的**文件**或主机的文件操作入口打开文件管理。每个文件面板独立维护来源、路径、选择和视图偏好。
可以为同一来源打开多个面板，并拖动标签页将它们放入不同的工作区分组。

## 列与视图偏好

在**视图选项**中选择**详细信息视图**或**分栏视图**。详细信息视图支持：

- 显示或隐藏类型、大小、修改时间列；名称列始终保留。
- 拖动表头调整列的顺序。
- 拖动表头边缘的分隔线调整列宽。聚焦分隔线后，左右方向键每次调整 10 像素，
  Shift 加左右方向键每次调整 50 像素。双击分隔线会根据表头和当前显示的内容适配列宽，
  包括被省略号截断的文字。
- 点击表头排序，再次点击反转排序方向。

筛选、分组、隐藏文件和文件夹优先排序均由各面板独立控制。列顺序和列宽随视图偏好保存。
拖动调整时实时预览，松开后保存；Esc 或切换到其他窗口会取消未完成的拖动。
两个文件面板之间的分隔条也遵循这一行为，双击可恢复等宽。
**恢复面板默认视图**会恢复默认列、顺序和宽度，清除筛选与分组，并恢复设置中的排序和隐藏文件默认值。

分栏视图按目录层级展开。单击文件夹打开下一栏；右方向键打开选中的文件夹，左方向键返回父目录并选中
刚离开的文件夹。在前面的某一栏点击或输入定位时，该栏会成为当前操作目标。

## 路径与键盘导航

点击路径中的某一级进入该目录，点击旁边的箭头列出其子目录。点击路径栏右侧空白区域，或按 Ctrl+L
（macOS 为 Cmd+L）编辑路径。Enter 打开路径，Esc 取消编辑；两者都会将键盘焦点返回当前面板的文件列表。

直接输入名称可以定位文件，也支持输入法提交的文字。连续输入组成前缀；重复字母可以匹配 `yy.exe`
之类的名称。方向键、Home 和 End 移动选择，Shift 扩展连续选择，Ctrl/Cmd 加单击切换单项选择。
刷新会保留仍然存在的选择项及范围选择的起点；进入其他目录则重新开始选择。其他面板或插件修改文件后
也会刷新列表，同时保留尚未提交的路径输入。

新建文件、文件夹和重命名使用列表内的输入框。Enter 提交，Esc 取消并将焦点返回列表。新建或重命名成功后，
对应项目会被选中并滚动到视图内；失败时保留草稿并显示错误。各平台快捷键及自定义方法见
[键盘快捷键](shortcuts.zh-cn.md)。

文件在 Tunnelde 内打开。空格和预览按钮可打开快速预览，兼容插件可以扩展预览格式。本地项目的右键菜单
提供使用系统程序及原生文件管理器打开的入口。传输行为、恢复限制和预览大小限制见
[网络路由、传输与 SSHFS](network-storage.zh-cn.md)。

切换界面语言时，已打开的预览会保留文件连接。音视频的播放位置与播放器设置，以及 PDF 的页码和缩放比例
保持不变，同时更新控件和已支持的错误信息的语言。

## 搜索已打开的工作内容

按 F1 后输入 `> ` 查找命令，输入 `% ` 搜索文件内容。范围选择器提供文件面板与已打开编辑器对应的目录；
未打开文件面板时，也可搜索编辑器文件的父目录，还可另选本地文件夹。内容搜索会用已打开的编辑器文字
替代该文件的磁盘内容，因此无需保存即可搜索未保存修改。选择对应结果后会返回原编辑器并定位到匹配行。
本地 Windows 盘符与 UNC 路径会统一比较斜杠方向和大小写；远端路径保留大小写与反斜杠字符的含义。

## 移动文件面板

拖动文件管理面板左上角的手柄，可将其中一侧移到工作区四边、其他分组的内容区或标签栏。
边缘用于分栏，中间和标签栏用于加入对应分组；分栏会在可用空间允许的范围内保留原宽度或高度。
拖到接收区域之外或按 Esc 取消时，原面板保持不变。

## 复制文件

文件管理与插件的复制命令统一使用后台任务引擎。打开**后台任务**可查看进度、设置任务限速或取消。
复制期间先写入暂存文件，数据写入及文件关闭成功后再提交目标，已有目标文件在此之前保持完整。
取消会清理尚未提交的暂存文件，保留源文件和已经提交的目标文件。目录复制逐个文件提交，不是整个目录的事务。

在同一 SSH 会话中，优化复制使用服务器支持的 `copy-data` 扩展，文件数据无需经本机转发；其他情况使用普通传输流程。
全局上传、下载限速约束经本机传输的数据。本地复制和服务端复制仍受单任务限速约束，不消耗全局网络额度。

## Windows 本地目录的复制后移动

本地目录需要通过复制来移动时，统一进入后台任务。源目录清单、目标目录身份和逐文件校验记录分别保存；
所有文件复制并校验完成后，先将恢复日志同步到磁盘，再开始清理源文件。

中断后点击继续，会重新核对记录的文件身份和完整内容。已经开始清理源文件的任务只继续校验与清理，
不会重新进入复制阶段。发生修改或被替换的文件保留待审查；源目录中新加入的项目也会保留，只有空目录才会被移除。
整个目录按文件逐步完成移动，不是一次性提交的事务。

复制后移动时，如果检测到源文件或文件夹包含 Windows 命名数据流，会保留源内容，因为传输流程尚未复制这些数据流。
请使用系统原生移动或支持保留数据流的工具处理这类源内容。

这项恢复能力适用于 Windows 本地路径。需要复制后删除的远端目录移动仍受限制；同一远端主机内的普通移动继续使用服务端重命名。

## 远端移动失败

同一远端主机内的剪切粘贴使用服务端重命名，避免文件经本机重新传输。两个目录属于不同挂载点时，
服务器可能拒绝重命名。SFTP 状态码 4（`Failure`）是通用失败，无法据此确定原因；目标冲突或服务端
限制也可能返回此错误。

移动失败会显示两端路径，并保留服务器提供的说明；点击错误提示中的**打开原始日志**可查看结构化信息。
失败项仍保留在剪切选择中，同一批次中已成功的项目会被移出。断线后重试前，请刷新检查两端目录，
因为未收到回复并不能证明服务器是否完成了操作。通用失败不会触发自动复制后删除的重试。
