# 本地 API 兼容规则

本地协议 v1 的稳定声明仅涵盖以下七个方法。接口发现提供 `stability: stable`
及各方法的 `since`。已有稳定插件 RPC 承诺独立保留；桌面应用进入 1.0，不会自动
让其他插件、runner 和 UI 扩展接口全部稳定。

| 方法                   | 契约边界                                                               |
| ---------------------- | ---------------------------------------------------------------------- |
| `api.describe`         | 当前二进制的协议、方法、输入与结果 Schema、错误及退出码                |
| `app.info`             | 应用与协议版本、操作系统、架构                                         |
| `hosts.list`           | 原生保存的主机：公开 ID、分组 ID、名称、地址、端口、用户名、收藏及标签 |
| `sessions.list`        | 已发布的活跃 SSH 连接，包括后台连接；`terminal` 区分终端会话           |
| `preferences.schema`   | 带版本的公共设置组及校验 Schema                                        |
| `preferences.snapshot` | 当前设置值、默认值及不透明修订号                                       |
| `preferences.update`   | 经由桌面共用设置写入器执行条件更新                                     |

`since: 0.38.0-beta.1` 表示首次公开引入，而非稳定声明时间。
`tests/fixtures/local-api/stable-v1/` 的声明通过历史夹具摘要冻结原方法、输入、
结果和错误契约，仅叠加经审查的稳定元数据及独立发现 Schema。历史夹具不会为
适配新实现而重写。新增方法必须声明自身稳定状态和引入版本；协议稳定不会自动
将实验方法提升为稳定。

本地设置适配器将共享设置 Schema 投影为稳定 v1 契约，插件设置适配器仍为实验
状态。两者使用同一个桌面写入器；共享 Schema 的变化也必须符合已冻结的本地
契约。

## 数据与生命周期

主机 ID 标识保存的记录，不是授权凭据；删除主机后身份结束。会话 ID 标识一次
连接的生命周期，重连可能产生新 ID。`connectedAt` 为 Unix 毫秒时间。列表是
当时的观察，随时可能过期；多次调用不组成共同事务。列表不承诺排序，调用方应
自行排序。插件提供的主机来源不属于 `hosts.list`。

设置修订号只用于相等比较，不是可排序计数器、时间戳或事件游标。写入前获取最新
快照，明确处理 `stale_revision`。客户端显示的字段未变化时，修订号也可能改变。
默认值描述当前应用版本，可以演进。部分对象更新保留未提供的字段；集合按公共
Schema 整体替换。

本地协议没有订阅、持久事件回放或通用取消方法，需要时轮询快照。七个稳定方法
不创建网络监听器。自动化端点本身始终只监听回环地址，没有远程监听模式。
API 不公开任意原生命令、shell 执行或凭据。

实验领域方法有独立的行为契约。例如，`forwards.save` 可以保存远程方向的规则，
`forwards.start` 在原生用户确认和正常的主机密钥、凭据检查后，可以建立对应的
SSH 监听器。`forwards.cancelStart` 仅取消待启动请求，不能停止已准入的监听器。
回执生命周期、重试规则以及另行确认的 `forwards.stop` 流程见[本地 API](local-api.md)。
这些方法不扩大七个稳定方法的声明范围。

连接关闭或超时不代表回滚；响应丢失时，写入可能已提交。应重新读取并核对。
协议请求 ID 用于关联，不提供去重保证；领域专用回执 ID 可按转发启动的明确约定
提供有界重放。不要自动重放超时写入，也不要由取消推断已回滚。

发现结果包含描述自身结构的有限 JSON Schema，覆盖协议与传输信息、方法输入和返回值
Schema、读写类型、错误及 CLI 退出元数据。调用方校验必要字段，忽略新增元数据和方法。
Schema 值为 JSON Schema 对象或布尔值，不递归嵌入完整发现结果。发现结构基线单独版本化，
已有历史方法夹具保持不变。

## 稳定声明规则

稳定声明明确协议与有限方法及 Schema 基线。兼容版本保留方法名、必填请求字段、
可接受输入、输出类型与含义、错误码及退出码映射、权限边界和写入语义。增加可选
输入字段、新方法、可忽略输出元数据可以兼容；可选变必填、缩小输入范围、删除
输出或悄悄改变含义属于不兼容修改。

调用方检查必需字段类型和协议版本，忽略新增响应字段，按文档兜底处理未知错误码。
提示文本、本地化标签及数组顺序不是机器契约。Schema 描述当前生产者，生产者
严格的 `additionalProperties: false` 检查不能导致历史消费者拒绝未来新增输出。
校验 Schema 时必须支持 `x-maxBytes`。

稳定接口的不兼容变化需要新的协议或领域契约版本及应用主版本，提供迁移路径；
当前应用主版本系列持续支持上一协议。弃用需在接口发现及双语文档中说明替代接口
和最早移除版本，在边界前保持行为。实验接口变化仍需更新说明和既有客户端审查。
设置修改也必须审查独立版本的公共设置契约，不能只检查本地适配器。

## 发布证据

稳定审查需要冻结输入、结果及错误样本，校验实际生产输出，验证旧版真实 CLI 对
新版宿主，完成平台 CI、打包 CLI 执行、安装升级数据保留及迁移规则。历史消费者
样本保持不变，新版本并列添加。Schema 相等检查只是回归证据，不能证明所有行为
或平台通过。执行边界见[本地 API](local-api.md)。
