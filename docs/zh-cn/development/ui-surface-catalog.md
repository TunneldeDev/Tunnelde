# 功能界面与 UI/UX 风格台账

本页记录各功能位置的设计约定和实现入口，供设计、开发和评审对齐；不代表所有位置已完成视觉验收。
新增或修改界面时同步更新对应行，包含入口、层级、操作位置、窄宽度行为和状态；不要仅记录截图。
公共控件与主题规则见 [公共 UI 控件](ui-controls.md)，窗口归属见 [面板布局](panel-layout.md)。

## 全局规则

沿用工作台、面板、板块、内容行四层结构。颜色、字体、圆角和控件尺寸使用现有主题 token 与
`components/ui` 封装。页面间距沿用 `.page` 的 20px/24px 内边距和 14px 间距；普通卡片内边距
14px，紧凑面板内部通常 12px。不要把页面卡片的留白直接套在终端、编辑器或表格行上。

相关新建操作置于标题工具栏右侧，随后是帮助、刷新与更多菜单；右侧工具栏保持自身尺寸，宽度不足
时整组换行，禁止覆盖标题。正文空态不承载唯一的新建入口。运行操作跟随对应分组／行，表单的
保存与取消在底部。危险操作、授权和恢复信息直接可见。页面内容超出高度时滚动，不压缩卡片使其
子内容跨卡片溢出；每张独立卡片保留完整边框。

重点信息必须在当前流程中直接可见：阻断错误、导入冲突使用红色边框／浅底、警告图标和具体原因；
待用户保存的密码与安全后果使用醒目的警告区域。颜色必须配合文字，不能只藏在 tooltip、
新增按钮或静默开关里。自动生成导出密码后切换到独立保存确认对话框，提供可选择的密码、
显式复制、取消和“已保存密码，继续导出”；确认前不打开文件保存流程。

### 进程分页与高度

进程页通过完整 flex 高度链将滚动限制在表格内，页脚提供首页／上一页／下一页／末页、页码输入跳转和 25／50／100／200 条选择。搜索或排序回到首页，条数切换保留当前首行所在页，采样缩减时夹紧页码。窄宽度分页换行，极矮窗口允许容器滚动；选中详情与指标说明有独立高度上限。分页、详情与提供者共享唯一正文。

### 进程操作和性能明细

进程行共用系统右键菜单与 Shift+F10：详情、远端文件位置、结束、结束进程树；危险操作单独确认并在执行时复核身份。新建任务与结束相邻，表单显示命令、工作目录、错误及提交 PID，保留输入供修正。监控页／面板共用性能明细：主题卡片、标签小字、等宽数值、可换行设备信息和自适应列；逐逻辑 CPU 以有界滚动网格展示，超过 32 个默认折叠。短窄面板纵向滚动，缺失值统一使用破折号并解释来源限制；复用现有图表历史与采样，不因切换展示重复采集。

状态栏的后台任务和输出入口共用按钮尺寸、字体、间距、圆角、悬停、展开和键盘焦点样式；任务运行、暂停、待处理与聚合进度作为同一按钮内的状态增强，不另造按钮外观。

旧右侧监控检查栏已移除，不再挂载正文、启动采样或预留宽度；状态栏、设置与命令面板均不提供旧入口。性能和进程使用独立会话页面／面板。旧偏好字段与 Inspector 插件槽保留兼容，不能重新启用旧检查栏；紧凑 Windows 标题栏始终在最右侧工作区预留窗口按钮空间。

后台任务的入口决定展示方式：活动栏打开／收起侧栏面板，状态栏（含隐藏状态栏时的独立按钮）打开／收起右下角小窗；不继承另一入口的展示偏好。每次从状态入口打开均恢复右下角锚点，以修复旧的错误坐标；本次打开期间仍可拖动和缩放，正文与任务所有者保留。已迁移到其他原生窗口的面板仍聚焦其唯一所有者。只允许可见浮动框提交几何，停靠、隐藏、窗口进入后台或零尺寸测量不得覆盖浮动坐标。
