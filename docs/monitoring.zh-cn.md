# 远端监控与进程管理

[English](monitoring.en-us.md)

CPU、内存、网络和磁盘读写图表共用带时间戳的历史记录。水平虚线标明刻度，鼠标悬停可查看采样时间和具体数值；聚焦图表后也可用左右方向键或 Home／End 浏览采样。从面板标题栏可打开更大的完整监控视图，同一连接的面板与完整视图共用一次采样循环。调整尺寸时只缩放图表，不重建采样曲线。

在远端监控面板中打开**进程**。进程管理器遵循**设置 → 监控 → 采样间隔**，
每次请求完成后才安排下一次采样，应用隐藏时暂停。轻量模式的间隔至少为五秒。
**暂停刷新**会保留当前列表，暂停期间仍可点击**刷新**进行一次采样。
刷新失败时保留已有行和上次成功更新的时间。

可以按进程名称、PID、用户名、用户组、UID 或 GID 搜索。点击列标题排序，再次
点击反转排序方向；未知值始终排在最后。每页最多显示 100 个进程，窄窗口下表格
可以横向滚动。选中某一行后可查看用户和组 ID、父进程、线程数、状态以及单核
口径的 CPU 使用率。

| 指标           | 含义与限制                                                                                                                             |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| CPU            | 最近间隔内进程 CPU 时间增量占整机 CPU 时间增量的比例，归一到 0–100%。详情中的单核口径在多核机器上可以超过 100%。首次采样尚无间隔数据。 |
| 内存           | 驻留内存 RSS，共享页面可能被多个进程分别计入。                                                                                         |
| 磁盘读写       | Linux `/proc/PID/io` 提供的实际存储读写字节速率，不含缓存命中。其他用户的计数可能无法读取。                                            |
| TCP 接收与发送 | 根据 `ss` 公开的 TCP 连接字节计数估算，不含 UDP、两次采样间消失的连接和不可见的连接归属。共享连接可能被多个进程分别计入。              |
| GPU            | NVIDIA `nvidia-smi` 或 Linux DRM `fdinfo` 公开的最繁忙引擎占用，取决于驱动支持。                                                       |
| 显存           | 驱动公开的分配量，按设备和客户端去重。NVIDIA 计算进程统计无法覆盖所有图形分配。                                                        |

`—` 表示不支持、无权读取，或尚未取得有效的第二次采样。监控通过 Linux 上的
只读命令采集，不安装工具、不请求提权。GPU 支持是可选能力；这些计数不能
用于完整核算全部进程流量或共享资源。

**停止**会在确认后，以当前 SSH 用户的权限发送 SIGTERM，PID 1 受到保护。
发送前会核对进程启动标识，拒绝操作已经退出或被复用 PID 的进程。
关闭窗口或切换服务器会使待确认操作失效。
