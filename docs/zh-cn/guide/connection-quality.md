# 连接质量

[English](../../en-us/guide/connection-quality.md)

## 网络与代理测试

在**设置 → 网络与代理 → 测试连接**选择连接方式和目标后，点击**测试连接**。
结果直接显示在按钮下方，包含中位数、最快与最慢耗时、波动和成功次数；
展开每次结果可查看各次耗时或失败。可点击**重新测试**，修改目标、代理或默认路由后旧结果失效。

443 端口沿所选线路最多发送三次独立 HTTPS HEAD 请求，所有主要统计和质量判定都来自
成功请求。每次耗时包含 DNS、连接建立、TLS 握手和等待响应头；证书校验保持开启，
不复用连接、不跟随重定向，也不把客户端初始化计入网络耗时。任何 HTTP 状态码都能证明
目标已响应，但不代表登录、下载或业务功能成功。本地／透明代理立即确认 TCP 建连时，
也必须等到 HTTPS 响应后才记为成功，不能把本地确认的 `<1 毫秒` 当成目标请求耗时。

其他端口最多测量三次 TCP／代理通道建立，包含 DNS、TCP 建连和必要的代理协商；
不发送应用数据或验证 TLS。本地／透明代理可能在目标就绪前确认连接，这些数值只能
说明通道建立耗时。两种测试都不是 ping RTT、网络丢包率或带宽测试，不测试目标登录。

线路解析和所有采样共用 15 秒总时限，沿所选直连、系统代理或已保存代理路径执行，
不会在代理失败时绕过代理。测试结束关闭临时连接。失败不按 0 毫秒计算；不足 1 毫秒
显示为 `<1 毫秒`，零波动显示 `0 毫秒`，全部失败时耗时显示 `—`。中位数不高于
100 毫秒标为较快，不高于 300 毫秒为一般，更高为较慢；部分失败或未完成全部 HTTPS
采样会单独标明。成功次数对应当前测量类型，HTTPS 失败不能显示为 TCP 成功。

## SSH 主机测试

打开主机的连接对话框，首次读取主机密钥时会显示沿当前路径建立 SSH 的耗时。
整条路径的密钥完成信任后，在**连接质量 → 测试连接**中进行最多三次短连接测试。

结果包含建立耗时的中位数、成功次数，以及最慢与最快成功连接的耗时差。
展开**查看每次结果**可看到每次耗时或失败情况，失败不会按零毫秒计入统计。

这里测量的是连接建立耗时，包含 DNS、代理协商、SSH 密钥交换，以及必要的跳板登录。
它不是 ping 往返延迟、网络丢包率或带宽测量；三次成功也不能保证长连接一直稳定。
测试不会登录目标账号、创建终端、运行远端命令或读取文件；目标账号凭据会在正常连接时验证。

耗时中位数不高于 500 毫秒时标记为建立较快，不高于 1,500 毫秒时为正常，更高时为较慢。
部分连接失败会单独标明。请结合具体路由理解这些提示，多级跳板本身就需要更多建立工作。

测试沿用主机的代理和跳板配置，不绕过所选路径。整条路径必须已信任；遇到新密钥、
密钥变化、凭据错误或配置错误立即停止，不会自动接受密钥或重试错误认证。
密钥变化时会重新进入验证流程。

点击**取消**或关闭对话框可停止测试。切换目标、修改跳板凭据或信任状态也会取消旧测试，
旧结果不会出现在新目标上。总时限为 25 秒，同一主机只能有一个测试，全局最多同时测试
四个主机；探测结束后关闭临时 SSH 连接。

## HTTPS 与插件下载

代理测试默认使用插件市场线路，包含按功能配置的代理覆盖。也可选择软件更新线路、
全局默认、系统、直连或指定配置。443 端口显示三次 HTTPS 请求统计；其他端口仅显示 TCP 建连统计。

CONNECT 成功不能证明 GitHub 或重定向后的安装包域名可达。不会关闭证书校验，也不会
在代理失败时悄悄切换直连。插件 GET 请求遇到握手提前 EOF 时，最多原线路重试两次；
证书错误和代理认证失败不重试。
