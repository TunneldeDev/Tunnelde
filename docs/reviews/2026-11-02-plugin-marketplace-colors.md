# 插件市场、全局 API、安全模式与工作台复核（0.21.0）

本轮实现插件市场与首批独立插件，并将运行环境选择、颜色设置和菜单分组贯通到原生桌面程序。

插件市场已迁至独立的 `TunneldeDev/tunnelde-hub` 仓库，包含四个独立包、生成目录、贡献流程、确定性打包、校验与发布工作流。主仓库保留旧版目录兼容快照，已有官方源与安装来源自动迁移并保留用户配置。Hub 的 SDK 提供双向 JSON-RPC、TypeScript 声明与由原生方法表生成的 68 项 API 文档。

| 范围       | 实现与操作逻辑                                                                                                                                                                        |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 插件市场   | 官方与自定义 HTTPS 源、搜索、已安装/可更新筛选、工作区详情、手动更新、离线缓存、原生下载进度与取消。安装先展示可执行代码和来源提示。                                                  |
| 包管理     | 校验 SHA-256、ID、版本、运行时、API 与引擎要求；更新绑定原始来源，事务式替换与失败回滚，启动恢复中断的替换。                                                                          |
| 本地安装   | 原生 ZIP/文件夹选择器与拖放；预览后确认，同一路径重新选择会重新检查。隐藏的插件侧栏不接收拖放。                                                                                       |
| Node       | 不捆绑 Node；默认仅定位本机候选而不执行。使用系统环境需要明确授权，可撤销；也可手动选定一个文件，或确认后下载应用私有 Node 24 LTS。私有安装不改 PATH/Shell。                          |
| 首批插件   | JSON 格式化/压缩、时间戳转换、UUID v4 批量生成。独立无 npm 依赖，声明式表单，本地处理，仅显式点击复制结果时写入剪贴板。                                                               |
| 并发与资源 | 每个插件独立操作锁与状态快照，列表不会等待插件调用；拒绝旧请求覆盖新状态；限制协议行大小，请求超时覆盖 stdin 写入与回复。                                                             |
| 颜色       | HSV、HEX、RGB、预览、应用、取消与重置；工作台分区独立背景与终端文字/光标设置，浅深主题共享自定义值。自动派生可读文字与控件颜色，保留 ANSI 调色板和用户显式前景，用户 CSS 仍有优先级。 |
| 菜单       | 主机、文件、终端与标签操作按领域分组；分界线、键盘导航、测量定位及焦点恢复。                                                                                                          |
| 源文件     | 移除第一方重复 SPDX/版权头，保留根 LICENSE、安装包许可证和第三方声明。                                                                                                                |
| 全局 API   | 固定版本方法覆盖应用设置、主机分组、SSH 命令、终端、文件、监控、历史、工作区、剪贴板与隔离存储。拒绝任意 IPC 调用、密钥库读取和自动信任主机密钥。                                     |
| 安全模式   | 执行前审批绑定包指纹与声明权限；更新、重装和改动后重新批准。设置可撤权及启用受限模式，CLI 参数锁定当前进程，异常退出后自动受限并提示恢复。                                            |
| 传输       | 插件上传/下载支持二进制与目录，取消和状态查询限定插件及运行时代际。每插件最多 8 个后台传输，最近 256 个完成状态保存在内存；撤权、受限、停止和进程退出会取消活动传输。                 |
| 面板       | 主机、插件与 Trusted Hosts 可移入标签组、四向分屏或移回侧栏；稳定容器保留真实 DOM、输入、展开及滚动。                                                                                 |
| Markdown   | README 使用安全 Markdown 与 GFM 渲染；表格、代码横向滚动，不执行原始 HTML，不自动请求外部图片。                                                                                       |
| 终端       | 固定官方 Unicode grapheme addon 0.4.0，使用 Unicode 15 字符簇宽度及跨 SSH 分包的流式 UTF-8 解码。                                                                                     |

- 14 项原生脚本检查通过，覆盖生产资源、私有运行时、真实 UUID/JSON/时间戳进程、JSON 大整数精度与错误定位、标签切换草稿保留、菜单分界线、颜色预览不写入设置、取消/应用/重置及窄窗口无横向溢出。

- 原生测试发现并修复长下载确认框遮挡进度/取消的问题，补充确认回调立即返回的回归测试。

## 验证边界

本机访问 GitHub 网页/原始资源域名存在网络超时，并配置了失效的系统代理。测试仅对 QA 进程设置 `NO_PROXY=*`，没有修改系统或 Git 全局配置，也没有关闭 TLS 验证。Node 官网下载正常；GitHub CLI 能下载已发布的真实插件包并验证校验值。原生市场列表测试使用由已核对目录构造的本地缓存，未将其描述为成功在线获取；市场网络下载/取消和离线回退由自动化测试验证。macOS/Linux 原生交互交由跨平台 CI 和发布构建检查，本机不声称已人工验证。

本轮没有连接测试服务器，也未修改服务器已有文件或服务。没有读取或修改系统剪贴板。

SSH 执行与传输的真实远端任务未在本轮连接服务器验证；传输所有权、运行时代际、并发限额、状态缓存和撤权取消由回归测试覆盖。Node 的权限控制保护宿主 API，并非 OS 沙箱；受限模式不能回滚插件已经完成的外部操作。WASM 保留有限 ABI，受 fuel/内存预算和执行审批保护，不声称支持完整的异步 Node API。
