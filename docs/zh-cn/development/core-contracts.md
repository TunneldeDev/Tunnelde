# 面向 1.0 的核心契约收口

桌面应用拥有业务服务。Tauri 命令、本地自动化和插件 RPC 是这些服务的适配层，
各自的协议与权限独立。内部命令可调用，不等于它自动成为公共 API；应用版本更新
也不会自动将实验方法提升为稳定接口。

## 兼容规则

- 稳定接口必须有明确归属的请求、结果和错误 Schema，说明副作用及生命周期，
  提供兼容样本和真实生产者／消费者测试。
- 同一契约主版本内，不得增加必填输入、收窄已接受输入、删除或改变已有输出含义，
  不得改变错误码含义。增加输出字段前必须确认消费者允许扩展字段。
- 修订号是不透明的持久代次标识。写入携带原修订号，陈旧编辑应失败，不能覆盖
  新设置。重试不代表重新授权，取消也不代表回滚。
- 事件默认用于失效通知，只有契约明确说明时才承诺可靠送达。消费者必须能从
  快照重建状态。重连和窗口重建不会恢复旧插件或旧运行代次的授权。
- 错误暴露稳定代码和安全的公共详情，解释性文字可以改进。日志应标明领域和阶段，
  不得泄露凭据。
- 弃用必须可发现并有文档，在新契约主版本移除前提供替代接口及迁移期。已有
  插件 v1 的稳定承诺继续有效，CLI v1 不替代它。

## 领域归属及发布门槛

首批本地稳定接口候选限定为以下七个方法。这是审查范围，尚非稳定承诺：

| 接口                                                               | 契约边界                                                                                                          |
| ------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------- |
| `api.describe`、`app.info`                                         | 协议／方法发现与运行版本；离线 CLI 描述自身构建，不能替代宿主发现                                                 |
| `hosts.list`                                                       | 通过共享主机服务获取一次已保存主机快照；不含凭据、修改和插件主机源，数组顺序无保证                                |
| `sessions.list`                                                    | 一次运行连接快照；ID 标识连接而非永久主机，返回后也可能立即断线；`connectedAt` 是 Unix 毫秒时间戳，数组顺序无保证 |
| `preferences.schema`、`preferences.snapshot`、`preferences.update` | 仅公共设置；不透明修订、严格局部更新、集合整体替换和陈旧写入拒绝；不含迁移与凭据                                  |

快照不预留资源、不承诺事件送达；本地协议仅请求／响应，不提供事件流。设置提交
仍在应用内部发布普通失效通知。写入回复丢失时结果未知，应重读快照确认，不能自动
获取新修订后重放。调用者已是同一操作系统用户，凭据仅授予上述有限能力，不复用
插件权限，也不弹交互审批。

已有 16 个稳定插件方法保留独立冻结契约。更多本地修改、插件 UI、runner 和高级
传输恢复可在桌面 1.0 后继续保持实验状态，不作为首批稳定契约的前提。剩余发布
门槛是历史客户端兼容、支持平台二进制检查、基本文件安全，以及实际安装／升级
数据保留验收；新增 API 方法不属于门槛。

以下是收口检查清单，不代表全部候选接口已经稳定。[本地 API](local-api.md) 是
第一批面向外部程序的适配入口。

| 领域           | 现有归属                                         | 承诺公共稳定前需要收口                                                         |
| -------------- | ------------------------------------------------ | ------------------------------------------------------------------------------ |
| 发现与错误     | `automation/contract.rs`、插件目录与历史核心样本 | 版本协商、认证、有界通信、结果与错误严格互斥、历史消费者                       |
| 主机           | `services/hosts.rs`                              | 独立公共 DTO；各适配层保留校验、审计、重命名与变更通知                         |
| 连接           | `ssh/session.rs`                                 | 连接和主机身份、信任认证、断线与取消语义明确，结果不携带凭据                   |
| 设置           | `services/settings/preferences/`                 | 冻结公共 Schema、修订冲突、校验与副作用顺序、重启要求，排除内部 Settings       |
| Profile 与存储 | `settings_profiles/`、`storage/`                 | 导入导出限制、迁移恢复和数据保留；不完整恢复保留实验状态                       |
| 转发           | `services/forwarding/`                           | 区分规则持久修订与运行连接身份、正确反映断线状态、复用校验                     |
| 文件与任务     | `services/files/`、`ssh/files/`                  | 基本复制、移动、取消、重连，安全保留源文件与清理；不能按路径缺失推断未知副作用 |
| 诊断           | `logs/`、`platform/logging/`                     | 有界分页、领域归属、游标筛选与脱敏规则；诊断不自动承诺可靠审计                 |
| UI 与扩展      | `src/lib/extensions/`、领域桥接                  | 保留已有稳定承诺；高级扩展与远端 runner 可以在 1.0 保持实验状态                |

不能用增加 RPC 数量替代这些边界收口，也不应把每个插件或高级传输恢复机制全部
做完作为首个稳定桌面版本的前提。即使延后高级功能，基本文件安全、实际安装和
升级数据保留仍需验证。

## 自动化证据

`scripts/ci/check-core-contract.mjs` 检查历史稳定插件契约。
`scripts/ci/check-local-api-contract.mjs` 校验实际本地域生产者输出及已提交的候选
契约样本。`src-tauri/tests/automation_cli.rs` 启动真实控制台及桌面 CLI 子进程，
对接固定的 v1 协议夹具。这些检查不能替代真实桌面服务联动、跨平台安装包及升级
验收。
