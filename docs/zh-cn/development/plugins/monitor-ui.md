# 监控界面提供者

[English](../../../en-us/development/plugins/monitor-ui.md) · [界面提供者](ui-providers.md)

实验性可信 UI SDK 提供 `provider: "monitor"`，同时用于完整监控页和远端侧栏。
声明不含 `location` 的组件视图，申请 `ui.trusted`、`sessions.read`、`monitor.read`，
再按常规方式注册视图。用户在“设置 → 插件 → 界面提供者”中主动选择；安装不会自动替换界面。

`props.monitor.snapshot.presentation` 用 `page`、`panel` 区分显示位置。
不可变快照包含连接、主机、标题、修订号、采样归属、请求状态、错误、最新资源绝对值，
以及至多 240 个带时间戳的历史点数量。未知或无效指标为 `null`；`latest.load`
是不可变三元素元组。进程查看和控制保留独立的原生生命周期与接口。

用 `monitor.read({ revision, offset? })` 读取历史，每页至多 128 点，按时间从旧到新排列，
通过 `nextOffset` 继续读取。保留的页是独立不可变副本；修订号不匹配或偏移无效会被拒绝。
当前可见帧可以调用 `monitor.refresh()`，通过已有共享采样器请求采样；并发请求会合并，
结果或错误由新快照呈现。隐藏、关闭、断开或撤权后，保留的句柄不能启动新任务。

`monitor.Charts` 可选挂载已有原生图表或卡片，每个提供者实例至多挂载一次。
也可省略它，通过有界数据自行绘制。采样归宿主所有，省略图表不会暂停可见监控。
同一连接的侧栏和完整页共用一个等待请求完成后再计时的循环。最后一个消费者关闭后，
在途结果不再写入状态；重新打开时，等待旧传输结束后再采新样本，保留已有历史。
应用可见性和轻量模式的采样间隔仍然生效。

标题、连接错误、进程操作和恢复入口由宿主保留。提供者报错或重复挂载图表时恢复原生界面；
主动恢复也保留已有图表 DOM 和历史。每次读取和刷新均检查权限、运行代次及提供者选择。
可信前端代码仍与宿主共用执行环境；导致界面阻塞的代码需要通过受限模式恢复。

公开契约位于 `src/lib/extensions/contracts/monitor/`：`sample.ts`、`reading.ts`
描述数据，`provider.ts` 描述表现接口。私有投影和授权适配位于 `extensions/monitor/`；
原生组件和共享采样分别位于 `features/monitor/components/`、`features/monitor/runtime/`。
SDK 生成器只镜像公开契约，检查依赖循环并拒绝私有类型引用；兼容入口仅重新导出领域类型。
该提供者仍为实验性接口，不改变稳定 RPC 契约，也不代表所有领域已具备 1.0 发布条件。
