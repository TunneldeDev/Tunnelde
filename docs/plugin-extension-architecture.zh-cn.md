# 插件扩展架构

[English](plugin-extension-architecture.en-us.md) · [API 兼容性](plugin-api.zh-cn.md)

扩展按领域组织，以契约、运行、数据、表现、行为、治理六层检查能力。
这是架构建设方向，不表示所有领域都已具备六层完整能力。

## 发现已实现能力

通过 `api.describe` 查询实际 RPC 方法、权限及稳定契约。该目录包含
`extensions.describe` 时，可调用其实验接口查询已实现的运行时 UI 扩展点。
结果包含版本、稳定性、六层标识、领域及 RPC 命名空间，以及扩展点的 ID、领域、
层级、稳定性、组合规则、注册方法、所有权、权限和配额。未知字段和类型应视为
未知能力，不应据此推断授权。

当前扩展目录列出主机装饰、底栏项目和标签栏控件。`composition: "merge"` 表示
多个所有者按该扩展点规定的顺序组合；`ownership: "runtime"` 表示贡献绑定插件的
已批准运行实例，不是持久化应用数据。领域命名空间分类实际方法，不表示已开放
公共依赖注入、完整领域服务、远端执行或相应权限。测试会核对目录引用与实际方法、权限。

[主机装饰](plugin-host-list.zh-cn.md)、[底栏](plugin-status-bar.zh-cn.md)和
[标签栏](plugin-tab-bar.zh-cn.md)使用共享运行时所有权注册表。前端先订阅再读快照，
按修订同步，卸载时释放监听；授权变化后隔离排队的旧读取和事件。
该机制不依赖某个具体视图或 Zustand store。

## 运行时资源所有权

前端内部资源作用域管理订阅与异步工作。`use` 注册已有清理操作，`acquire` 在打开资源前
预留配额并持有清理操作，`run` 在工作结束后释放预留。获取资源或执行工作时可指定调用方
取消信号与超时。父级取消或作用域释放后，调用者及时收到失败，即使底层操作不响应取消，
也不必继续等待；晚到的资源会被清理，不再交付。取消不代表撤销原生或远端已经产生的效果。

被取消的底层工作实际结束前仍占用配额，未完成的异步清理也占用配额，防止反复重试在
限制之外积累工作。资源获取成功后归作用域所有，获取阶段的超时和调用方信号不再关闭该资源；
作用域释放资源时会中止其获取信号。

释放操作幂等，先中止生命周期，再按注册的逆序启动清理。同步或异步清理错误会被观察并报告，
但释放操作不等待异步清理，也不能强制不响应取消的工作结束。作用域默认配额为 128，
无效配额和超时在启动工作前拒绝；关闭、调用方取消及超时使用不同错误码。

主机装饰、底栏项目与标签栏控件同步已使用此机制。监听初始化和每次快照读取的超时均为
30 秒。读取超时后仍保留订阅，后续刷新可以恢复，过期读取不能覆盖当前内容；初始化失败会
清理部分成功及晚到的监听。这是内部生命周期基础设施，不是已发布的 UI SDK，也不能为
直接加载的前端代码提供沙箱隔离。

## 领域边界

公开数据采用协议 DTO，不任意暴露内部状态。操作经领域服务执行，并在执行时
再次授权。插件执行位置与目标资源位置分别表达。取消、撤销、补偿和原子事务
采用不同契约；被取消的远端操作可能已经产生效果。

保存的主机和分组已由应用命令与插件 RPC 共用同一个原生领域服务。服务负责输入
规范化、持久化、会话名称同步、凭据清理、审计记录与提交后的失效通知。删除主机与
保存的连接路由使用同一个数据库事务，主机排序也采用原子事务。写入失败不发布成功
通知，也不清除凭据。现有 RPC 的请求和返回结构保持兼容。这是首个已抽取的领域，
不表示所有原生命令已经完成迁移。

每个扩展点明确贡献是合并、选择提供者还是替换视图；优先级不能解决所有冲突。
视图/工作台提供者以及既有快捷键冲突遵循用户选择。插件存储及附加数据字段
使用插件命名空间和 Schema。

## 可信前端组件：计划中的边界

目标 UI SDK 允许受信任前端模块组合公开宿主组件，并提供视图或完整工作台。
模块共享受支持 React 运行时，声明 UI SDK 兼容范围，通过公开服务访问器操作。
当前扩展目录尚未实现该加载器或完整工作台替换，不应导入内部源码路径或假定
已经存在组件 ABI。

直接加载的前端代码共享宿主 JavaScript 上下文，不具备操作系统、DOM 或原生桥
沙箱隔离；错误边界无法阻止死循环或撤销任意副作用。此类模块需要明确的信任、
宿主管理的恢复入口和不加载前端扩展的启动方式。凭据、主机密钥信任和授权决定
继续由宿主呈现。现有 Node 插件的 API 权限检查也不等于对 Node 进程进行沙箱隔离。

迁移期间保留既有稳定 RPC 契约。新扩展目录和主机装饰方法属于实验接口。
扩大稳定范围前必须完成 SDK 同步、旧插件兼容、真实生命周期/授权和平台验收；
完成迁移本身也不代表已经具备 v1.0 发布条件。
