# 日常工作流设置与默认值复核（0.20.0）

本轮集中扩展日常使用偏好，保留已有用户保存值。新安装、缺失的新字段和显式恢复默认使用当前平台默认值。

| 范围       | 实现与行为                                                                                                                        |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------- |
| 设置发现   | 中英文跨分类搜索、仅显示已修改、默认值与数值范围、单项/分类/全部恢复。分类和全部恢复需要确认。                                    |
| 数值与 CSS | 数值输入允许中间草稿，Enter/失焦校验提交，Escape 放弃；重置清除无效草稿。CSS 显式应用，切换分类保留草稿，异步保存不覆盖后续输入。 |
| 默认值     | 系统语言/主题、Fira Code 14 px、界面 13 px、舒适密度、监控面板关闭。Windows 紧凑标题栏，macOS/Linux 系统标题栏。                  |
| 终端       | 历史容量、行高、光标形状/闪烁/失焦形状、滚轮/平滑滚动、输入回到底部、选中复制、右键行为和自动/DOM 渲染。实时更新同一实例。        |
| 工作区     | 状态栏、启动恢复、双击/Enter 主机激活动作、动效模式。单击/Space 仅选中主机；启动恢复不自动连接 SSH。                              |
| 文件       | 隐藏文件、文件夹优先、自然名称/大小/时间排序、方向。键盘、范围和批量操作共享显示顺序，隐藏项仍参与碰撞检查。                      |
| 性能       | 预加载共享两个后台并发，前台导航优先，按照可见排序预热父目录和前 N 个子目录，丢弃失效结果。全选计数复用 Set。                     |
| 编辑与监控 | 自动换行、制表符宽度、拼写检查只改显示；监控间隔即时生效，共享请求并在隐藏时暂停。                                                |

## 验证

- TypeScript、ESLint、345 项前端测试、82 项 Rust 测试、Rustfmt、Clippy、版本一致性和 538 项中英文翻译键一致性检查通过。
- Windows 独立 QA 标识与独立数据目录，运行嵌入生产前端资源的原生构建，页面地址为 `http://tauri.localhost/`。没有停止或替换用户已安装的程序。
- 19 项原生设置检查覆盖系统中文、平台默认、双语搜索、数值校验、分类恢复确认、终端预览及实时变更、生产 DOM ANSI 颜色、GPU 切换、动效、状态栏、窄布局和 CSS 草稿。
- 真实 SSH 会话验证参数变化后仍为同一连接和终端实例，既有输出保留；原生剪贴板右键粘贴成功，Shift+右键始终提供菜单。测试后恢复原剪贴板，断开 QA 会话。
- 远端文件测试仅使用新建的随机临时目录，覆盖自然排序、隐藏快捷键、排序后选中保留、编辑器草稿保留、显示设置不写回远端文件和关闭草稿确认。每次测试结束均清理自己创建的目录；没有修改已有文件或服务器服务。
- 原生截图检查常规布局与约 480 px 内容宽度的分类横向导航，设置内容无横向溢出。

macOS/Linux 的原生交互没有在本机执行；相关代码由跨平台 CI 和发布构建检查。
