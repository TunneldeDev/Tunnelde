# 原生文件保存传输（实验性）

[开发文档](README.md)

内部 `ssh/files/native_save` 适配器对接可选 helper 的 `files.save.v1` 协议，与旧
SFTP 清理、runner 控制相互独立。该模块不会安装运行时、声明支持、启用桌面保存或
增加公开插件 API。桌面生命周期可加载已有恢复记录，并在后台任务中显示明确的
恢复操作；安装、初始化和编辑器实际保存路径仍未启用，须完成接入验收。

代码按契约、解码、客户端和传输分类。POSIX/PowerShell 公共命令编码放在
`ssh/command`；命令参数中不包含正文或私有控制令牌。请求使用有界 stdin、单个
绝对传输时限和 stdout/stderr 合计上限。关闭 SSH 通道不能证明远端 worker 已结束。
错误区分尚未发送与可能已经发送，不回显远端原始输出。

发送任何私有控制信息前，传输层比较原主机密钥、认证账户和规范作用域与所选连接。
恢复不能被后来修改的主机设置重定向。响应必须匹配原权威、作用域及私有状态目录
对象身份、操作、运行代次、意图摘要和绑定。未知协议字段或状态、畸形回执、权威
变化、旧修订，以及非零或缺失退出状态都会被拒绝。`live: null` 和
`backupRetained: null` 保持未知，不能转成真假值来批准清理。

客户端显式初始化、提交、查询、取消或释放。提交失败不会自动再次提交。恢复使用
原权威查询，不重新初始化远端存储。释放要求已知回执、排除原执行器、准确修订；
存在备份时还要求明确同意丢弃备份，与通用清理权限独立。提交客户端要求私有恢复
日志提供的一次性许可；服务只有持久记录可能发送状态后才能获取许可。

`journal/` 按记录契约、数据库生命周期和修订 CAS 转换拆分。独立数据库
`native-file-saves/recovery.sqlite3` 位于所配置的数据库位置。已有存储缺失、损坏、
属于其他用途或被替换时直接拒绝，不自动重建。SQLite 使用 `synchronous=EXTRA`；
预留、可能发送、回执和清理意图通过短事务保存。凭据写入和删除在系统凭据操作
返回前持续持有 SQLite 即时写事务，以跨进程互斥防止令牌仍可写入时先删除预留。
存储清单在迁移和重置时
携带整个目录；存在恢复存储时，不允许仅更换数据库位置而不迁移数据。

日志记录原所属者及代次、认证目标、helper 选择、权威和意图，不保存文件正文或
控制令牌。`secrets` 使用独立且按应用标识隔离的系统凭据服务，QA 标识同样隔离。
服务先预留记录，再保存并核验独立令牌，最后进入就绪状态。令牌缺失、变化或无法
访问都不会触发轮换或创建替代操作。显式完成流程先持久标记未发送操作已放弃，
或已确认释放的记录已退役，再移除匹配的凭据和记录；未知操作及保留的远端备份
不能通过该流程丢弃。系统凭据查询及删除不构成针对任意外部写者的 CAS，操作键
不得重新分配。

所有日志及系统凭据操作均运行在有界阻塞 worker 上；调用者取消后，实际操作完成
前不归还配额。桌面管理器惰性打开已有存储；一旦观察到存储，缺失或失败保持为
错误，不能伪装成首次启动的空状态。列出记录不读取凭据或连接远端，历史活跃回执
显示为待处理，不能作为当前仍在运行的证明。

恢复任务提供查询原操作、丢弃未发送保存、完成本地恢复和打开软件日志入口。查询
只选择匹配原认证目标的当前连接，不安装、初始化、重提、取消或丢弃远端备份。
旧本地、旧远端和原生恢复存储独立读取，某处失败不会隐藏其他记录。

旧编辑器保存、传输、新建、重命名、删除和保留产物清理之前会检查已有原生恢复
预留。公共路径比较覆盖父子目录、Windows 盘符路径和 POSIX 的字面反斜杠；恢复
仍依赖的原 helper 程序及私有状态目录也受保护。潜在
主机别名按连接捕获的地址、已保存主机 ID 或认证密钥保守匹配；恢复仍要求准确的
原身份。通过有界 SFTP 规范路径查询核对现有路径或最近的现有父目录，并设置总
时限。恢复存储损坏或无法访问时拒绝修改，浏览和诊断继续可用；首次缺失存储不会
因检查而自动创建。

这一步只保护已有记录，尚未完成双向修改准入。新原生预留入口仅在测试编译中
存在。开放新保存前，仍须用持久准入服务原子排除两个方向的活跃及未结算旧写入，
并由实际 worker 在取消和进程丢失期间保留归属。允许并发创建新预留时，网络等待
前的一次读取检查不足以保证互斥。现有检查不能排除任意外部文件写者，也不能证明
路径符号链接在后续修改时身份不变；不能据此结算未知的旧 SFTP 请求。

内部第二版日志将旧式修改占用记录放入同一个 SQLite 权威库。格式升级需要明确
调用并在事务内完成；重新打开第一版不会自动升级。两类记录共享 128 条记录和
四个已发送 worker 的限额，在 `BEGIN IMMEDIATE` 内双向检查原 helper 状态目录、
父子路径及其他冲突。占用记录保留连接捕获的目标、请求及规范路径、所属者代次、
修订和发送检查点。只有原实际 worker 获得一次性结算许可；普通退役不能删除可能
已发送的占用。丢失结果保留为需要关注的任务，提供日志入口，不提供无法兑现的
远端查询或丢弃操作。

远端新建、建目录、重命名、删除以及编辑器保存和原暂存清理 worker，在存在明确
升级的存储时接入此内部权威。前台等待超时不会取消已经准入的基本修改；原 worker
继续观察原操作，最长五分钟。基本修改逐一跟踪原始请求，收到认可的 SFTP 终态
拒绝回复后释放占用，同时保留原操作错误；这不表示没有发生部分文件修改。断线、
超时、畸形回复及未逐请求接入的组合操作失败仍保留占用。后续请求成功不能结算
先前的未知请求，只读准备失败也不会虚构待处理写入。编辑器只有在确认暂存清理
成功并移除原恢复记录后才释放占用，保存“稍后清理”记录不代表清理已经完成。
原 worker 只有在全部原始请求均收到认可的终态回复后，才能将准确的编辑器占用
保留为可续接清理。旧恢复记录保存占用所属日志及操作的关联。续接必须匹配原
所属者及代次、认证目标、请求及规范路径，通过事务中的修订检查保证只有一个
worker 获准继续；取消不会删除原占用。每次清理修改均先持久记录可能发送检查点。
清理回复丢失仍视为未知，即使后续发现目录不存在，也不能通过再次清理消除未知。
只有清理确认成功且原恢复记录已移除，才能释放占用。

插件新建、建目录、重命名和删除 worker 保留原运行代次及请求授权。持久记录可能
发送检查点后，重新解析预留的请求及规范路径、检查认证目标，并在轮询修改前
执行取消和最终授权准入。递归删除与目录合并在只读准备之后，每次后续修改前
重新授权。撤权阻止后续步骤，但不会撤销已经准入的请求或已完成的部分修改。
已准入文件句柄的关闭仍观察原始完成结果。准备或最终准入失败时，只有确认未
轮询任何修改才能释放占用。

内部传输适配器可在同一事务中预留全部会修改的远端。原存活传输可在使用新暂存或
备份路径前扩展准确占用。扩展保留原所属者、认证目标及已有路径，在同一事务中
检查其他原生及旧修改占用，并推进发送修订；不会锁住无关同级文件，也不授予发送
请求的权限。扩展回复丢失会使旧结算许可失效，扩展后的占用继续保留。单条占用仍
限四个作用域及 32 个已存路径，不是无限目录传输清单。传输和产物清理现已使用该
占用；全部修改边界及完整桌面生命周期仍需完成覆盖。

内部传输续接保留所属日志及占用身份、任务所属者及代次、准确修订和不可替换的
原始根路径。私有权威日志单独保存原始根路径，不从调用者的续接凭证推断。
生成路径可以扩展占用，但不能变成新的任务根路径；多路径任务也不能被缩成部分
路径。未记录原始根路径的旧内部传输记录继续保留占用，不采纳新调用者提供的根。
原始尝试只有在全部已观察请求和可写句柄结算后，才能原子封闭本轮请求准入，
再保留或释放占用。
共享旧观察的排队原始、缓冲和压缩写入，此后均在提交修改前被拒绝。续接在有界
解析时限内重新检查原认证目标、根路径及生成路径覆盖，通过准确的持久发送修订
检查后获得新一轮请求观察。准备或取消不能释放原保留占用；原始请求结果未知时
仍保留为已发送。暂未收到回复时，原 worker 和许可继续保留；观察到该回复后才可
再次尝试保留占用。已封闭的尝试不能继续扩展路径或第二次保留、结算占用。这一
内部状态机现已通过持久任务关联接入传输运行及产物清理；下文所列的剩余生命周期
边界仍是生产启用前的门槛。

实际分块通道已按传输共享一份内存请求观察，包括并行目录 worker、压缩通道、批量
归档写入和脱离前台等待的暂存目录创建。原始 SFTP 修改在错误转换为界面消息之前
观察；可写 OPEN 另保留句柄回执，只有原 CLOSE 明确成功才能释放。关闭被拒绝、
通道退出或后续写入成功都不能释放它。压缩协议 worker 在交付结果前按原请求 ID
验证修改回复结构，因此调用者取消后仍能观察迟到终态。未保留原 worker 的 SFTP 请求被调用者
丢弃后，底层库不再向观察者交付该回复，仍保持未知。连接类伪状态不能当作 MKDIR
终态拒绝。普通元数据通道的可写文件和传输目录创建也与分块 worker 共享观察。
包括空暂存文件及续传句柄，可写 OPEN 必须等自己的 CLOSE 明确成功才释放。
高层文件适配器返回 IO 错误而非原始 SFTP 状态，因此缓冲写入、刷新及关闭失败
保守保留。目录创建前取消不生成修改回执；发送后取消等待原 MKDIR 回复。
若该等待被丢弃，即使后续元数据探测发现目录已存在也仍保留未知状态。
运行时传输注册表现在持有元数据及数据 worker 使用的本轮请求观察。发布重命名、
原子替换、暂存文件删除和暂存目录删除，在转换错误之前观察原始类型化回复；
异常扩展包不能确认替换成功。任务结束及结果缓存清理不丢弃未确认的请求轮次，
重新注册同一任务也不能忘记它们。清理先原子封闭已结算的上一轮，再取得新一轮，
阻止旧排队适配器继续发送。原请求的迟到回复可允许该转换，后续探测或其他操作
成功不能代替它。发布、恢复重命名、原子替换及产物清理现在会在调用者取消或等待
超时后保留原协议 worker；传输及清理收尾不能提前关闭该 worker 持有的元数据通道。
原始类型化终态回复才能结算请求；通道关闭、异常回复及协议超时仍保留未知。
运行时保护与持久任务占用关联相互补充；私有日志独立于结果缓存管理崩溃恢复。
全部修改前的最终授权及完整生命周期验证仍待完成。重启应用不能证明未确认传输
已经结束。

私有传输占用记录现可在创建事务中绑定不可替换的任务 ID 与操作意图，包括两端路径、
认证后的远端身份、复制／移动与覆盖选项、插件归属。生成路径扩展、暂停与续接均保留
原始意图；重新打开日志后按任务查找必须完全匹配。旧无绑定记录不能从应用任务历史
认领新任务，可能已发送的占用也不能重放。占用记录缺失不是完成凭据；只有原 worker
留下的私有终态记录才能授权下述本地任务投影交接。

传输运行及显式产物清理现已用注册表自身的请求轮次准入原私有任务。发送前先同步
应用存储中的关联凭证；该凭证不能替换私有任务，也不能在原始私有记录丢失后授权
重放。注册表释放任务时会保留实际原始许可，包括独立协议请求仍等待回复的情况。
后续清理只有等原轮次结算后才能将原许可转为可续接状态。暂存和备份路径通过同一
许可登记，递归复制的目标也在只读准备后复核准入；任务投影不能将远端改为本地，
或替换主机及地址，插件 worker 还需复核有效授权代次。请求校验保留注册表的同一
轮次和任务实例，在新远端写入前检查取消状态、插件运行代次及认证身份；压缩通道
排队后、独立元数据 worker 启动后再次检查。本地分段写入在远端读取完成后检查，
本地发布在实际阻塞 worker 内检查。撤权后仍可接收原请求回复并完成已有句柄的
刷新和 CLOSE；拒绝新写入不能生成完成凭据或抹去未关闭句柄。这仍是部分生命周期接入。
已绑定任务成功运行或确认完成产物清理后，先封闭原始请求轮次并保存私有终态记录。
原路径继续保留占用，直到任务投影及关联凭证在同一事务中按 FULL 或更强的既有设置
同步提交，再按准确修订删除占用。投影失败保留私有终态，可只修复本地记录。启动及
列表恢复可用原始私有意图重建丢失的任务行；应用中的路径、主机、选项或插件归属被
修改时拒绝确认。已完成或已取消任务不能续传，旧应用凭证也不能重建丢失的私有占用。

明确未发送的任务，只有检查产物及进度记录均不存在后才能无远端写入地处置；曾经
发送或暂停的任务不能将应用产物记录缺失当作处置证据。恢复入口同样先保存终态
投影，不能直接丢弃已绑定的传输占用。实际进程死亡测试覆盖两份 SQLite 文件间的私有
完成、未提交转换、应用投影和占用释放。这些检查不能替代完整桌面生命周期验收。
复制清理使用原始私有源身份，不要求源主机在线；移动清理仍需复核会修改的源端。
全部修改边界的复核仍待完成，不代表已经启用生产写入。

可续接编辑器阶段属于明确初始化的内部第二版候选格式，不是公开插件 API，也不
触发自动升级。可能已发送且没有原始终态回执的任务，中断后仍保守保留占用；终态
投影可在本地恢复，远端未知结果继续维持未知，完整桌面生命周期验收仍是生产启用
前的门槛。

生产初始化和传输／产物全部接入尚未启用，因此这
不代表双向保护已覆盖所有入口，也不开放原生编辑器保存。新装 helper 无法证明
历史旧 SFTP 请求的未知结果。

可能发送后只查询原操作。远端状态缺失仍视为未结算。记录在确认释放前持续保留
目标路径；最多保留 128 条记录，最多准入四个可能仍活跃的 worker，不驱逐未知项。
释放前先保存清理意图，包括准确回执修订和明确的丢弃备份选择；释放回复丢失后
通过查询恢复，不再次提交释放请求。发送前仍需检查所属者准入和当前传输身份。
此服务不能结算旧 SFTP 的未知结果。

测试只执行明确选定的已审查 helper，覆盖原生创建、替换、准确重复请求、客户端
重建、先取消占位和绑定修订的释放；另测历史 helper 维持不支持。独立规范摘要样例、
畸形响应和权威变化测试补充实际生产者／消费者验证。上述测试不能替代真实认证
SSH 断线、桌面进程重启、安装授权、物理平台验收，也不能结算旧 SFTP 未知结果。
