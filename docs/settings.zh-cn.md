# 设置

[English](settings.en-us.md)

从活动栏底部打开设置，或按 `Ctrl+,`（macOS 为 `Cmd+,`）。设置搜索支持中英文标签、说明和偏好名称；“仅显示已修改”与当前平台默认值比较。各项显示默认值和适用范围。外观、工作区、终端与文件等类别在同一页中按用途分组，例如“文件 → 预加载”将开关和子目录数量放在一起；缩进导航可跳转到对应分组。

开关和下拉项立即保存；数字在按 Enter 或失焦且验证通过后保存，Escape 放弃未完成的输入。自定义 CSS 使用“应用”按钮，切换类别时保留草稿。待保存或失败状态显示在类别列表上方。每项均可重置；重置类别或全部偏好需要确认，不会删除主机、凭据、插件、打开的标签或未保存的编辑内容。

全新安装默认使用系统语言和主题、舒适密度、13 px 界面文字、14 px Fira Code、显示状态栏并关闭监控面板。Windows 默认使用紧凑标题栏，macOS 和 Linux 默认使用系统标题栏。升级保留已保存值，新字段使用默认值。

| 工作区     | 状态栏、监控面板、面板宽度、恢复工作区、主机激活行为                       |
| 终端       | 滚动缓冲、行高、光标、滚动、剪贴板、渲染器、命令历史                       |
| 键盘快捷键 | 搜索命令、录制快捷键、查看冲突、禁用和重置快捷键                           |
| 文件       | 隐藏项目、文件夹优先、排序、预加载、图标主题、传输参数和限速               |

## 应用更新

**设置 → 更新**显示当前版本、检查与安装进度，以及可展开的更新说明。可以选择**正式版**或**公测版（Beta）**，以及 GitHub 或兼容的自定义 HTTPS 更新源。应用内不提供开发快照。所有构建默认使用正式版、GitHub、每天自动检查，下载和安装由用户发起；也可以选择每次启动或每周检查。旧的 Nightly 设置迁移为正式版，已保存的正式版或 Beta 选择不受影响。

展开更新说明可查看已安装版本到目标版本之间的已发布变更，覆盖范围和限制见[更新指南](updates.zh-cn.md)。切换到正式版不会自动降级当前 Beta，而是等待更新的正式版。安装会重启应用。更新源、渠道和检查频率随设置配置方案保存。

自定义来源 URL 的路径必须恰有一个 `{channel}`，例如 `https://updates.example.com/{channel}/latest.json`；编辑后选择“应用”。来源须提供 Tauri 更新清单与签名安装包，不能只是网页。来源与各功能代理分别配置。镜像要求见[发布运维说明](releases.zh-cn.md#应用内渠道来源与-ota)。

## 文件传输

**设置 → 文件 → 传输**中的优化默认开启；并发数、分段大小和每段请求深度默认自动决定，也可分别手动设置。关闭优化会保留手动值供以后使用；设置在新传输或恢复传输时生效。详见[传输性能](network-storage.md#transfer-performance)。

自动传输压缩也默认开启，只在节省流量时压缩数据块，跳过很小的任务，在远端不支持时回退到 SFTP，不自动安装软件。关闭传输优化时压缩也随之停用；压缩开关和手动分段值随配置方案保存。

总上传与下载限速默认均为 `0`（不限速），单位 KiB/s，实时作用于并发任务。运行中任务的仪表按钮可以设置临时的单任务上限，总上限仍然生效。状态栏中的后台任务入口或 F1 命令可查看任务；固定后可继续工作时保持打开。拖动标题移动，拖动边缘或角调整大小；布局在重新打开、重启和托盘恢复后保留。重置布局或双击标题可恢复默认布局。键盘调整、重连和清理说明见[暂停与恢复](network-storage.md#pause-and-resume-transfers)。

## 快速访问和插件快捷键

- F1 或 `Ctrl/Cmd+Shift+P` 以命令模式（`>`）打开快速访问。
- `Ctrl/Cmd+P` 搜索选定目录中的文件和已打开标签；`Ctrl/Cmd+Shift+F` 打开内容搜索（`%`）；`@` 搜索已保存主机。
- **设置 → 键盘快捷键**列出已安装插件声明的命令和视图；搜索元数据不会启动插件。执行仍需运行时同意及可执行插件审批。自定义快捷键随配置方案导入和导出。
- 插件安装或更新产生快捷键冲突时，可保留其中一个、保留冲突或跳到设置页筛选相关项。保留的冲突以红色标识，匹配当前上下文的命令可以同时执行。筛选支持 `@is:conflict` 与 `@plugins:插件ID,另一个ID`。详见[快捷键指南](shortcuts.md)。
- 终端中可用 F1 和 `Ctrl+Shift+P` 打开快速访问，`Ctrl+K` 和 `Ctrl+P` 保留给 shell；macOS 的 Command 快捷键仍可用于应用操作。

内容搜索使用可见的本地或 SSH 目录，按字面忽略大小写匹配，不执行 shell；跳过链接、隐藏和构建目录、二进制及过大文件，并受 100 条结果、4,000 个条目、8 层目录、8 MiB 读取和 15 秒等限制约束（另有连接建立和关闭的时间限制）。远端编辑器草稿优先于磁盘结果，跳转时保留。见[快捷键指南](shortcuts.md)。

## 外观与颜色

文件图标主题位于**文件 → 浏览 → 文件图标主题**。“自动”使用已安装的图标主题，“普通文件图标”关闭插件图标；即使提供者暂时不可用，配置方案和导出仍保留具体选择。

外观提供内置配色和已安装的插件主题，一个插件可以提供多个配色，纯主题包无需 Node。展开“自定义颜色”可分别设置工作台与终端区域。主题选择、区域组和颜色项通过缩进及引导线区分。主背景自定义色也会推导弹窗、对话框、边框和原生控件的整体颜色；只修改其他区域不会改变全局配色。应用配色会一次保存基础外观、强调色和颜色映射；手动修改后显示自定义状态，卸载主题提供者不会清除已应用的颜色。

颜色选择器支持 HSV、HEX 和 RGB，可调整强调色及主工作区、活动栏、侧栏、紧凑标题栏、标签栏、编辑器、面板、状态栏，以及终端背景、前景和光标。主机标记也使用颜色选择器。自定义色在浅色和深色主题间共享，未修改或重置的区域继承当前主题；系统标题栏仍由操作系统控制。

拖动只预览；“应用”保存，取消或 Escape 恢复最近保存的值。已有终端会实时预览，输出与连接保留；区域重置移除覆盖。自定义 CSS 优先于外观设置。插件源和 Node 运行时位于插件设置；重置普通偏好不会删除来源、授权、运行时或已安装插件。

## 配置方案

设置顶部的配置方案选择器可切换已保存的偏好快照。“另存为配置方案”保存当前已应用值；后续修改会标记为已修改，选择“更新配置方案”并确认后才覆盖快照。“管理配置方案”支持重命名、应用、单独导出和删除；删除快照保留当前偏好。名称唯一，长度 1–64 字符，最多保存 32 份。

导入与导出通过系统 JSON 文件选择器完成。内容包括外观、自定义 CSS、行为、终端、编辑器、文件视图、快捷键以及代理元数据和功能路由。代理密码保留在本机系统凭据库，换机后须重新输入；主机、密码、SSH 密钥、插件配置与凭据、历史、打开的标签和更新记录均不包含。

导入会检查格式、版本、大小（最大 512 KB）、设置名称、类型和允许范围，显示方案名及变更项数量，确认后才应用；取消不会更改设置。应用采用普通设置相同的顺序保存和跨窗口同步流程，包括原生标题栏、终端外观和快捷键。更新记录保留；丢弃未应用的 CSS 草稿前需要确认，成功应用后重置数字与 CSS 草稿。导入后的设置可以保存为具名方案；配置方案不会更改插件授权、Node 运行时、SSH 会话或编辑器文本。

## 主机与面板

单击主机默认打开详情；**工作区 → 主机激活行为**可将单击和 Enter 改为连接终端或编辑主机。双击始终连接终端。“激活主机时直接连接”默认开启：连接终端时使用已保存的密码或密钥，无需再次点击连接。SSH 认证前仍验证实际服务器密钥；遇到未知或变更密钥、缺少凭据或认证失败时会打开连接对话框，绝不会自动信任。关闭该设置可每次先查看连接对话框。

创建或编辑主机时可将密码存入系统凭据库。保存后的值不会显示，也不会写入主机元数据或设置配置方案。留空保留原密码，输入新值替换，选择“移除已保存密码”可移除；更改只在保存时生效，保存前可撤销移除。保存密码失败时草稿保留以便重试，不会重复创建主机。主机专用代理及有序跳板在主机编辑器的“代理与跳板”区域设置；转发可由主机详情或独立的转发工作区管理。[网络指南](network-storage.md)说明路由优先级、传输恢复和 SSHFS 依赖。

主机、插件和受信任主机面板可通过标题拖动手柄或标题菜单移入工作区标签；拖到标签组或边缘可重排、拆分，再拖回活动栏/侧栏或选择“返回侧栏”。搜索、展开和滚动状态随移动保留；点击活动图标可隐藏并恢复停靠面板及其位置、尺寸和状态。每个窗格可锁定为新页面目标，与键盘焦点无关。工作区恢复只恢复标签和布局，不会自动重连 SSH。

## 存储位置

**高级 → 存储位置**区分数据库、已安装插件、插件数据与聊天、托管 SSH 密钥、托管 Node 运行时、缓存/临时文件、日志及远端部署记录。通过系统目录选择器选择空目录或新目录；多选后可选择父目录，为各类别创建独立子目录。可单独“重置位置”或批量“重置所选位置”，默认迁移当前数据回显示的默认路径。默认路径已有的旧数据会单独归档以便恢复，数据库/缓存的共享根及其他类别保留，完成后列出恢复路径。复制现有数据默认开启；关闭后该类别从空数据开始，并会在确认界面明确提示。安排迁移前请检查所有源和目标路径。详见[存储位置](storage.zh-cn.md)。

更改在下次完整启动时、打开 SQLite、日志写入器和插件进程之前执行。完成正在进行的工作后完全退出（包括托盘中的进程）再重开；仅关闭窗口不会迁移。此前资源继续使用原位置，设置页可以取消已计划的迁移。

迁移检查路径冲突、嵌套关系、已识别本地磁盘的剩余空间和不支持的链接；先复制到独立暂存目录，逐文件校验 SHA-256，全部准备好后才切换所选位置。原始数据保留用于恢复，不会被 Tunnelde 删除。中断后的已发布数据只有仍与源一致时才复用；目标冲突时保留目标并继续使用原位置，在设置中显示恢复信息。可修正冲突，或取消并选择新的空目录。每份清单上限为 200,000 个条目和 64 层目录；迁移期间其他进程不应写入应用数据。

原应用数据目录中的 `storage.json` 是保存待执行计划和旧位置的小型启动索引。存储位置属于本机，不包含在配置方案或设置导出中。设置 `TUNNELDE_PLUGINS_DIR` 时由它决定插件位置，该类别在设置中不能迁移。

系统钥匙串凭据、外部密钥、工作区、传输目标和远端文件不会随之移动；数据库与缓存只迁移各自资源，不会搬走共享父目录中无关的文件。复制后的托管密钥和运行时存在时，其引用会相应调整。插件自行保存的绝对路径可能需要在插件内修改；用户自建目录不会被合并或覆盖。

## 后台运行和安全模式

macOS 关闭窗口后应用和会话继续运行。**常规 → 后台运行时显示在程序坞**默认关闭；关闭窗口会移除运行中的 Dock 图标，可通过菜单栏托盘或再次启动恢复窗口，恢复后 Dock 行为正常。开启此项可在后台保留 Dock 图标。最小化保留 Dock 图标，退出则结束进程。

**常规 → 托盘时释放 WebView**默认开启。关闭到托盘后（macOS 自动，Windows/Linux 需选择），应用先保存内存检查点并销毁隐藏窗口；原生 SSH 会话、传输、转发和插件进程继续运行。托盘、Dock 或再次启动可重建窗口。终端画面、滚动历史、未发送输入、编辑器草稿和光标、文件位置及视图草稿只保存在进程内，不会跨退出或崩溃保留。未完成的视图操作或对话框会推迟释放；无法生成检查点时保留隐藏窗口以避免丢失工作。关闭此设置则继续保留隐藏 WebView。

**常规 → 轻量模式**默认关闭。开启后释放终端 GPU 渲染器、停止推测性目录预加载，将本地与远端监控采样间隔设为至少五秒；手动导航、传输和 SSH 连接继续。原渲染器、预加载与采样偏好保留，关闭轻量模式后恢复。两个后台设置均随配置方案导入导出。

插件设置提供受限模式、逐插件审批/撤销、运行时选择及市场来源。`--safe-mode` 和 `--restricted-mode` 为当前进程强制启用受限模式，包括已经运行的单实例。可执行 Node/WASM 插件保持停止，纯主题包仍可用。插件运行后异常退出时，下次启动进入受限模式并提供恢复。安装更新在验证安装包后记录计划重启，自动重启不会误判为崩溃；显式启用的受限模式仍保留，安装失败会恢复当前进程的恢复标记。

## 终端、文件与监控

终端设置无需重新连接即可作用于已打开的终端；减少滚动缓冲会丢弃超出新容量的行。平滑滚动遵循动画偏好，减少动画会关闭它。右键默认打开菜单，也可设置为直接粘贴，或先复制选区并清除后再粘贴；Shift+右键始终打开菜单。选中即复制默认关闭；开启后支持鼠标感知工具发起的 OSC 52 剪贴板写入，剪贴板读取请求会被阻止。自动渲染优先使用可用的 WebGL，否则回退 DOM；可滚动预览使用相同终端设置。命令成功记录后，停靠在其他位置的命令历史面板也会刷新。

预览和连接中的终端都使用 Unicode 15 字素宽度处理中文、表情序列和表格；流式 UTF-8 解码器保留分散在 SSH 数据包中的字符。

隐藏项目包括点文件和本地 Windows 隐藏属性文件，仍参与名称冲突检查。文件列表聚焦时 `Ctrl+H` / `Cmd+Shift+.` 切换显示；新建或重命名的隐藏项会暂时显示。默认按名称自然排序并将文件夹置前，未知修改时间排在末尾。预加载父目录及配置数量的子目录，两个面板合计最多两个后台请求；数量为零时仅预加载父目录，关闭预加载会停止新的后台请求。

编辑器偏好只改变显示，不会重新缩进或改写已有内容。监控视图共享请求，隐藏时暂停；切换工作区恢复、状态栏或动画不会关闭会话或丢弃编辑器草稿。远端 CPU、内存、网络和磁盘读写图表提供带刻度的虚线与时间轴，支持鼠标和键盘查看采样；缺失的磁盘采样显示为不可用，不会编造零值。

## 远端进程管理

远端进程管理器支持自动刷新、CPU/内存、磁盘 I/O、可用的 TCP/GPU 数据、可搜索的用户和组信息，以及可排序、分页的列表。权限和指标定义见[监控指南](monitoring.zh-cn.md)。
