# 远端监控与进程管理

[English](../../en-us/guide/monitoring.md)

监控页将 CPU、内存、网络、磁盘及 GPU 分成资源卡片，每张卡片合并曲线和明细，随当前面板宽度动态排版。点击 **编辑布局**，拖动卡片标题左侧手柄排序，拖动右下角缩放宽高；也可使用前移／后移、整行／半行与重置按钮。聚焦排序手柄使用上下键，聚焦缩放手柄使用方向键；Escape 取消正在进行的缩放。窄面板自动使用单列，保留宽面板的宽度设置，较长明细在卡片内滚动。布局按主机自动保存，重新连接后恢复；**恢复默认布局**仅重置当前主机，设置中的面板习惯重置会清除全部主机布局。自定义监控插件自行管理其界面，本布局控件适用于内置仪表板。

CPU、内存、网络和磁盘读写图表共用带时间戳的历史记录。水平虚线标明刻度，鼠标悬停可查看采样时间和具体数值；聚焦图表后也可用左右方向键或 Home／End 浏览采样。从面板标题栏可打开更大的完整监控视图，同一连接的面板与完整视图共用一次采样循环。调整尺寸时只缩放图表，不重建采样曲线。

在远端监控面板中打开**进程**。进程管理器遵循**设置 → 监控 → 采样间隔**，
每次请求完成后才安排下一次采样，应用隐藏时暂停。轻量模式的间隔至少为五秒。
**暂停刷新**会保留当前列表，暂停期间仍可点击**刷新**进行一次采样。
刷新失败时保留已有行和上次成功更新的时间。

可以按进程名称、PID、用户名、用户组、UID 或 GID 搜索。点击列标题排序，再次
点击反转排序方向；未知值始终排在最后。每页最多显示 100 个进程，窄窗口下表格
可以横向滚动。选中某一行后可查看用户和组 ID、父进程、线程数、状态以及单核
口径的 CPU 使用率。

| 指标           | 含义与限制                                                                                                                                                     |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| CPU            | 最近间隔内进程 CPU 时间增量占整机 CPU 时间增量的比例，归一到 0–100%。详情中的单核口径在多核机器上可以超过 100%。首次采样尚无间隔数据。                         |
| 内存           | 驻留内存 RSS，共享页面可能被多个进程分别计入。                                                                                                                 |
| 磁盘读写       | Linux `/proc/PID/io` 提供实际存储读写速率，不含缓存命中。Windows CIM 提供进程 I/O 传输速率，可能包含缓存及非磁盘 I/O。macOS 暂不提供此指标。权限可能限制读取。 |
| TCP 接收与发送 | 根据 `ss` 公开的 TCP 连接字节计数估算，不含 UDP、两次采样间消失的连接和不可见的连接归属。共享连接可能被多个进程分别计入。                                      |
| GPU            | NVIDIA `nvidia-smi` 或 Linux DRM `fdinfo` 公开的最繁忙引擎占用，取决于驱动支持。                                                                               |
| 显存           | 驱动公开的分配量，按设备和客户端去重。NVIDIA 计算进程统计无法覆盖所有图形分配。                                                                                |

`—` 表示不支持、无权读取，或尚未取得有效的第二次采样。进程监控自动识别远端系统：Linux 使用 `ps` 和 `/proc`，macOS 使用系统 `ps` 和 `sysctl`，Windows 使用 PowerShell 与 CIM。采集不安装工具、不请求提权。macOS 的线程数、I/O、TCP 和 GPU，以及 Windows 的 UID/GID、TCP 和 GPU 暂不提供；Windows 的用户名需要足够权限。GPU 支持是可选能力；这些计数不能
用于完整核算全部进程流量或共享资源。

**停止**会在确认后，以当前 SSH 用户的权限操作：Linux／macOS 发送 SIGTERM，Windows 直接终止进程。PID 0 和 1 受到保护。
发送前会核对进程启动标识，拒绝操作已经退出或被复用 PID 的进程。
关闭窗口或切换服务器会使待确认操作失效。

进程表支持 25／50／100／200 条分页、首页／末页和页码跳转，表格内部滚动。右键或 Shift+F10 可以结束进程树、打开远端可执行文件目录或查看详情；进程树结束需要确认。“运行新任务”使用 SSH 用户在远端执行后台 Shell 命令（Linux／macOS 使用 `sh`，Windows 使用 PowerShell），可指定绝对工作目录。Windows 支持盘符路径、UNC 路径和 SFTP `/C:/` 路径，命令长度受默认 SSH Shell 限制；返回 PID 仅表示已提交。无交互终端，输入输出丢弃。

监控页和面板新增 CPU、内存、磁盘、网卡及可用 NVIDIA GPU 明细。CPU 包含速度、进程、线程和 Linux 文件句柄及逻辑 CPU 利用率；磁盘包含活动时间、响应时间及读写速率。指标来自远端实际权限可读的数据，缺失工具／驱动或首次速率采样显示不可用。
