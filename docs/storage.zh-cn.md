# 存储位置与重置

[English](storage.en-us.md)

在 **设置 → 高级 → 存储位置** 中查看各类数据的当前位置与大小。可以为单个分类
选择新文件夹，也可以勾选多个分类后选择父文件夹，为各类数据分别建立子文件夹。
环境变量管理的插件位置在该覆盖生效期间不能修改。

**重置位置**将一个分类迁回默认位置；**重置所选位置**批量处理所选分类。
若只是尚未应用的位置草稿，重置会撤销该草稿；已经使用默认位置的分类不需要再次
修改。已有待执行计划时，重置按钮会禁用。

先检查来源和目标路径，再选择 **下次启动时应用**。默认迁移当前数据；关闭迁移
开关会让该分类以空数据开始，检查页面会明确提示。完成当前操作后彻底退出软件，
包括托盘中的后台进程，然后重新打开。仅关闭再显示窗口不会执行迁移。

迁回默认位置时，软件先复制并校验当前数据，再将默认位置已有的旧数据归档到
`storage-recovery/<分类>/<迁移编号>/original`。数据库与缓存仅处理属于各自分类
的指定文件或目录，应用根目录、存储索引、无关文件以及其他分类的数据保留原位。
迁移来源也会继续保留。完成后，设置页会同时列出原位置和默认位置旧数据的归档路径，
便于恢复；归档不会自动删除。

所有选中分类准备完毕后才会切换位置配置。中断的回迁可通过日志逐项恢复；如果
已经迁入的文件被修改，软件会保留文件、报告冲突，并继续使用当前来源位置。
取消中断计划前也会校验已迁入的数据，通过后才恢复归档的默认数据。请先处理报告
的冲突再重试或取消，软件不会静默删除被修改的内容。迁往普通自定义目录时仍要求
目标为空。

存储位置属于本机配置，不包含在设置导出和 profile 中。系统凭据、外部密钥文件、
工作区文件以及远端文件不参与迁移。更多边界说明见
[设置文档](settings.md#storage-locations)。
