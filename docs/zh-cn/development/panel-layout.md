# 公共面板布局

`src/lib/layout/types.ts` 定义可序列化的 `PanelLayoutNode` 树。叶子记录面板 ID，
拆分节点记录 ID、方向、比例和两个子节点。比例为 0 到 1 的小数，工作区现有的
序列化结构保持兼容。

`src/components/ui/layout/` 下的 `PanelLayout` 是受控渲染组件。调用方传入布局、
`renderPane(paneId)`、`onResize(splitId, ratio)` 和已翻译的分隔条无障碍标签。
组件不依赖工作区、存储、文件管理或插件模块。布局有效性、持久化、停靠、标签操作和
隐藏面板状态由调用方负责。保持节点 ID 和渲染回调稳定，可以在调整比例时保留挂载内容。

`SplitPanels` 为布局树和功能双栏提供同一套分隔行为，支持横向／纵向、flex／grid、
可配置边界、分隔条尺寸、键盘与复位操作。拖动时每个动画帧最多直接预览一次 DOM 几何，
松开后才通过 `onRatioChange` 提交。指针取消、Escape、失焦或卸载会丢弃预览，
恢复最新受控比例，包括拖动期间通过键盘提交的比例。指针移动不会保存偏好或重渲染子面板。

工作区 `PaneLayout` 只负责适配状态仓库。文件管理 `FileSplitView` 使用同一个公共
分隔组件，保留原有本地偏好适配和 20–80% 边界。存储键改变时重新挂载偏好适配层，
防止不同文件视图互相覆盖比例。工作区仍使用 15–85% 边界。

应用与插件面板继续通过现有工作区停靠宿主接入，共享位置、尺寸、显隐与标签操作。
此次重构不会把实验性的插件工作区 API 自动提升为稳定接口。

行为检查见 `tests/components/PanelLayout.test.tsx`、
`tests/components/PaneLayout.test.tsx`、`tests/features/FileSplitView.test.tsx`
及工作区／侧栏停靠测试。新增消费者应复用公共控件，避免重新实现指针监听或持久化。

## 综合工作台面板

`WorkbenchPanel` 是内置面板和插件侧栏的默认综合容器，内部组合公共标题栏、位置菜单、
展示状态和小窗几何控制。业务只提供一份正文和可选的 `PanelHeader` 操作，宿主将操作
移入统一标题栏，避免重复标题。只有特殊用途才直接组合底层基础组件；任务、连接详情、
输出、文件预览和插件侧栏不再分别维护小窗与面板外壳。

`SidebarContents` 为已访问面板保留唯一 React 所有者，`SidebarMount` 在侧栏、工作区和
小窗之间移动同一个 DOM 容器。同文档切换保留搜索、选择、展开和滚动；关闭只隐藏展示，
不停止 SSH 会话、任务或插件运行时。工作区关闭保留隐藏槽位。小窗使用通用状态并迁移旧
任务几何数据；进程内检查点可恢复已打开的小窗，但冷启动不自动弹出临时小窗。插件贡献
被移除时清理展示；停止运行时保留已安装视图的启动占位，运行时资源仍按作用域释放。

此机制只适用于同文档，不等于跨 WebView 所有权交接；没有明确交接协议前，不得声称
原生独立窗体能够保留 DOM 或所有临时状态。

### 实验性插件控制

通过 `extensions.describe().panelPresentations` 发现支持的展示方式与方法。
`workspace.panels.list` 返回 `{revision,windowId,panels}`，仅包含标识、可用性、位置、
可见性、固定状态和几何数据，不包含业务正文、草稿、密码或任意 store。

- `workspace.panels.observe({revision?})`：revision 不同时立即返回，否则等待变化或最多
  十秒。revision 是进程内不透明值，不提供持久重放；取消会释放监听。
- `workspace.panels.setPresentation({panelId,presentation})`：将现有面板移到 `sidebar`、
  `workspace` 或 `floating`。文件预览必须已存在，插件面板必须仍在贡献列表中。
- `workspace.panels.close({panelId})`：隐藏面板，不停止业务资源。

读取和观察需要 `workspace.read`，变更需要 `workspace.write`。正常请求授权、取消与
回复前的运行时代次检查保持不变。`workspace://panels-changed` 仅是包含 `{windowId}` 的
UI 失效通知；RPC 插件应使用 `observe` 并重新读取，不可从事件交付推断当前状态。
冻结的 `workspace.snapshot` v1 不变。

## 分隔线交点

`SplitGeometryScope` 不增加布局包裹节点，可连接由 React portal 保留的不同正文。
应用在工作台外统一接入；独立使用 `SplitPanels` 时会自动提供局部作用域。不同 DOM
根分别处理，因此小窗不会调整无关工作区边界。几何注册使用实例级 ID；语义 split ID
只需在同一所有者／批量回调内唯一，不要求不同布局根之间唯一。所有者或拓扑变化会
取消旧手势。

宿主按真实分隔线段寻找 T 型或十字交点。交点可同时调整两轴，相接的同轴线段共同
移动，无关线段不参与。各参与者使用自己的容器尺寸和上下限，按最严格的公共位移
限制保持对齐。预览复用帧级指针控制，不重渲染正文或逐次持久化；Escape、指针取消、
失焦和卸载恢复最新受控比例。方向键调整单轴，Shift 精细调整，Home 或双击重置。

为 `PanelLayout` 提供 `onResizeMany` 以原子更新一个所有者的布局。工作台通过
`workspace.resizeSplits` 一次发布两轴变更。独立控件保留 `onRatioChange`；跨不同
业务所有者的手势按所有者各提交一次，不声称独立持久化适配器属于同一数据库事务。
插件可通过实验性的 `workspace.resizeSplits({ratios:{splitId:ratio,...}})` 操作，
需要 `workspace.write`；一至三十二个已知 ID 和有限的 0.1–0.9 比例全部通过校验后
才执行一次变更，既有工作区尺寸限制仍会钳制比例。冻结的 workspace v1 不变。

## 原生视图交接（开发中）

独立窗体不能再次启动整个应用。`panel_windows` 使用宿主签发的文档身份与
带 generation 的面板租约；迁移流程为 prepare → 目标惰性渲染并保持 inert →
确认就绪 → 主窗单例提交。超时、取消、重载或已撤销的目标不能获得操作权。
关闭独立窗前须先归还视图；崩溃恢复依赖有大小限制的内存检查点，不能持久化
秘密草稿，也不能复制业务 store 或重新创建后台资源。

适配器须显式加入 `windowViews.transferablePanel`。目前已适配连接详情、后台任务、输出与可信主机密钥：
主窗发布显式的只读投影，独立窗通过 `ConnectionModelScope` 复用相同内容，
不向可写业务 store 灌入副本。局部 React 状态通过 `usePanelViewState` 显式登记，
滚动与光标使用稳定的 DOM 标记单独保存。目标树须先实际渲染，再原地提升为所有者，
不能重挂载；已提交的局部状态和 DOM 事件会合并生成原生检查点，不能用空壳或
加载动画充当目标就绪。

私有原生控制协议是封闭枚举。只允许协调器发布投影；读取须验证当前完整租约，
或有效迁移中的目标身份。元数据和事件均不携带投影、凭据草稿或文档令牌。
独立窗的普通业务 IPC 默认拒绝；任务／断开操作使用封闭请求，在校验发起文档与完整
租约后入队，仅由主窗领取一次。任务回调始终保留在单例注册表中；实例票据拒绝替换
来源的旧按钮，但进度更新不会让按钮持续过期。未领取工作可取消或超时；已领取工作
须等主窗完成清理，不能因发起文档重载或执行器局部作用域释放而解除迁移保护。
即使领取回复晚于本地释放，也必须最终回报，不能用普通读取的释放后检查丢弃它。
请求、结果和票据均不得进入元数据或事件。
主窗入口应聚焦实际所有者，不能再创建一份同面板内容。

`PanelWorkspace` 组合既有 `PanelLayout`／`SplitPanels` 与 `WorkbenchPanel`，
提供文档内标签、横纵分栏、浮动及合并，只移动保留的 portal 容器，不重建 React 或
资源所有者。独立窗几何状态只放内存，不能覆盖主窗偏好。关闭单个面板只归还该视图，
关闭原生窗口才归还全部。从独立窗再次拆出目标窗，须在原生创建前后校验当前可交互的
适配器租约；只有创建文档能丢弃空目标窗，已初始化但放弃的目标也须自动回收。
原生销毁前须在所有权锁内预留空窗关闭，避免新迁移与平台销毁竞争；前端取消或重载
不能解除预留，只有原生销毁失败清理或实际销毁可以。

以上是分步实现，并不代表多窗功能已全部完成。其他内置面板、插件及原生跨窗拖拽仍需
适配与平台验收，其他资源专用界面也仍须完成窗体适配。
不能提前宣称支持，也不能以放宽网关权限
掩盖适配缺失。公开插件 workspace v1 协议保持不变。

### 文件预览资源与窗口句柄

`createPreviewReadSource` 将读取、解码和原生票据的生命周期从正文移到宿主所有者。
正文只订阅不可变结果，订阅和卸载不启动或关闭 I/O。目标、提供者或重试改变时创建
新所有者；取消后迟到的结果只清理自身票据，不能覆盖新结果或关闭替代资源。

私有 `publishPreviewResource` 仅协调文档可发布。目标窗通过 `openPreviewHandle`
取得绑定实际文档、精确租约或有效暂存交接的只读展示句柄。原始媒体票据不交给目标窗，
`preview` 协议按原生调用窗校验，异步读取完成后再校验同一句柄。交接提交原地提升
暂存句柄；取消、过期、文档重载、资源替换及 ABA 都不能恢复旧句柄。关闭展示句柄不
关闭宿主持有的文件，迟到的打开回复仍须清理。句柄容量有界，不出现在公共元数据、
插件 API、Bus 或状态胶囊中。

停靠的 `filePreview` 现已使用这些句柄接入显式跨窗迁移；实际验收范围见下文。
公开 preview v1 保持不变。

### 后台任务插件提供者

后台任务沿用主窗唯一任务注册表。已选择的 `backgroundTasks` 提供者使用原生签发的
展示身份和目标专用权限，而不是转发提供者的权限。独立窗从 `createView` 创建
作用域视图，不重复运行插件单例。主窗、迁移中目标及回迁使用同一状态胶囊；目标
实际恢复并渲染后才允许提交。无工厂旧视图仍明确拒绝迁移，不静默丢弃草稿。

`backgroundTasks.read` 允许展示，`backgroundTasks.write` 才能提交动作。迁移目标在
提交前只读；旧租约、隐藏替代树和被冻结的来源不能操作。提交绑定精确文档、子视图
和租约，进入既有有界动作队列；主窗按任务实例票据执行原注册表回调。票据与动作回调
不进入公共插件 API、状态胶囊或元数据事件。收到迟到回执后仍取消未领取动作。

原生 macOS 验收覆盖两次主窗→独立窗→主窗、草稿恢复和独立窗动作，插件只激活一次。
这是显式交接验收，不等同于物理跨屏拖拽、Windows/Linux 或 FUSE 连续性验收。

### 协调器中断与有界视图状态

协调器文档重载不能证明已领取的任意回调所提交的原生副作用已经停止。须将结果标为
未知，禁止重放，并按面板在原生层保留隔离保护；结果 TTL、来源销毁、认证解锁或复用
面板 ID 均不能解除它。显示可见警告并保持正文 inert；用户检查资源状态后须重启软件
解除此进程内保护，不能提供不安全的自动重试或强制解锁按钮。

重复列表使用 `PanelViewStateGroup`，由一个父字段聚合行状态，仍受严格 JSON 以及
整体字节、节点和深度限制。长列表不能在渲染时抛错；超限应在交接前捕获阶段拒绝，
保留可编辑的来源及全部草稿，不得截断以凑合迁移。

文档内指针拖拽支持标签排序、边缘分栏及中心停靠，包含浮窗的停靠手柄。保留的 portal
沿 React 祖先链传播事件而不是物理 DOM 链，因此接收区须用原生捕获监听校验文档内
不透明令牌。手势期间将被拖浮窗排除出命中测试，在松手、Escape、取消、失焦或卸载时
恢复其原有样式。

### 原生拖拽桥接（开发中）

通用指针驱动须区分正常松手与 Escape、丢失捕获、失焦、卸载；文档内已接收的拖放应
取消原生授权。跨窗松手前，宿主签发的短期、单次授权必须已经就绪，不能等待延迟回复后
再读取已经变化的鼠标位置。原生松手入口须重新检查发起文档及可交互的完整租约；后续
交接仍须匹配该实例，不能按面板 ID 悄悄换成新所有者。拖拽就绪元数据和插件消息均不
携带授权或文档令牌。

目标由原生命中测试确定：已有注册窗、来源窗（不操作），或全部可见应用窗之外（新建）。
几何／查询错误不等于窗外，不得因此新建窗。macOS 鼠标位置使用主屏幕 backing scale，
窗体边界却使用各窗自身 scale，比较前须统一为 Cocoa 桌面点坐标；Windows／Linux
保留原生物理桌面坐标，不可信任浏览器 screenX/Y。

真实 WebView 内的合成指针测试只能验证网关和分阶段交接，不等于实际 OS 指针捕获、
各平台输入路径、混合 DPI 多屏硬件、SSH 传输连续性或所有内置／插件面板均已通过验收。
公开完整能力或发布前仍须完成这些要求。

### 输出适配与单例读取

输出使用主协调器的唯一 `OutputSource`，不能每个 WebView 各维护日志游标。
文档内视图保留读取需求；独立窗已拥有或正在接收输出时增加后台需求，因此隐藏主窗
不会停止更新。最后一个消费者释放后停止轮询；仅本地消费者且文档隐藏时暂停读取。
刷新合并执行，不重叠读取；在途读取期间清空不能复活旧行，来源释放后的迟到回复须忽略。

独立窗通过 `OutputModelScope` 复用 `OutputPanel`。筛选、通道、等级、自动跟随和换行
使用临时状态胶囊，滚动使用共享 DOM 标记。运行信息只投影显示所需元数据，不传递完整
AppInfo、插件运行令牌、安装／数据路径或全部设置。刷新、清空、打开日志／目录、复制
通过封闭的租约操作中继执行；独立窗不能直接调用日志、文件系统或剪贴板原始命令。

输出按完整行的 UTF-8 JSON 字节限制，而不是 UTF-16 消息长度。输出私有投影单独允许
2 MiB 包络，以容纳有界行及显示元数据；其他投影与草稿胶囊仍保留 1 MiB 限制。
输出内容及复制文本均不得进入公开元数据或失效通知。

### 可信密钥面板与文档级确认保护

已知主机视图共享协调者数据源，在不同窗口复用 `KnownHostsList`。卫星窗口只接收
可信密钥的展示投影，不开放原始应用 IPC。搜索及显式标记的滚动/焦点经临时快照
迁移；刷新和忘记操作使用绑定精确租约的封闭动作中继。

确认界面打开前必须取得 `beginInteraction` 保护。不透明令牌绑定文档和租约，阻止
迁移、新建目标窗、拖拽授权及关闭回收，但允许提交已确认的动作。多个重叠确认各自
释放自己的令牌；取得授权前组件已卸载，也要释放迟到的令牌。这些保护随文档重载或
崩溃失效，不等同于资源动作保护；已接收的动作仍独立保持原生围栏，直到完成，或在
协调者丢失时进入现有的结果未知隔离。

发起窗口使用共享受控 `ConfirmDialog`，不传递回调、不在主协调窗重复弹框。明确展示
确认对象的算法和指纹；删除时在同一事务核对地址、端口、算法、指纹和更新时间，
不能用过期确认删除新的可信密钥。保留信任生命周期失败回滚，失败时保持可见且可重试。
旧插件无条件删除操作保持兼容，内置界面始终提交预期密钥身份。确认框、令牌和回调
不得序列化到视图快照、元数据事件或持久布局。

### 可跨窗口复用的传输与连接展示边界

`ConnectionPrompt` 统一连接、主机密钥和凭据界面，仅接收精简主机展示投影及显式的
`ConnectionPromptServices`，不启动 SSH、不读取主协调窗的凭据或主机 store，也不跨窗
导航。现有 `ConnectDialog` 是主窗口专用适配层，保留原生目标审核、单例连接获取和
工作区导航；卫星窗口不得使用它补缺，远程服务缺失时不能回退为本地原始接口。
连接质量测试及其取消必须经过同一个所属后端。忘记凭据的嵌套确认留在发起窗口，
失败时不能关闭确认或清除已保存凭据的提示。

传输行通过 `TransferTaskControllerScope` 接收控制器，不把执行直接塞入展示组件。
原生窗口控制器须根据当前所属任务解析封闭的位置类型，不接受视图任意传入的路径。
本地回退保留捕获的会话身份复核，不得把已断开的远程目标解释成本地路径。卫星窗口
缺少显式控制器时直接拒绝。展开状态、限速编辑器及未完成的草稿使用分组临时快照，
进行中的副作用不属于草稿。

原生传输适配在每条命令执行前核对来源及任务实例票据，只投影明确的传输展示字段和
可检查位置，不复制会话句柄或可写 store。协调者根据当前任务解析封闭的位置类型，
远程失联不能解释成本地路径。检查路径是显式用户操作，通过已注册文档的原生显示
网关唤起主窗口文件工作区，不放宽通用窗口 IPC 权限。

重连确认挂载前必须先取得精确原生保护令牌；原生在动作接收和领取时分别校验令牌。
多个缺失端点顺序确认时保持同一保护，每次副作用独立持有资源围栏，界面关闭不代表
副作用已结束。取消不得恢复传输；任务或确认句柄过期后，即使远程关闭失败，用户仍
能关闭本地确认并释放界面保护。暂停、取消、恢复须等待后端接收，不能把 store 的
异步发起误报成已完成。

审核连接句柄必须私有，并绑定租约代数、任务实例及保护令牌；限制数量和空闲生命周期，
所属窗口或来源失效时退役，仅取消该句柄自己命名空间内的诊断测试。凭据及密钥操作
限定在已审核路由主机内，后台连接请求由协调者构造，不接受任意目标。已保存凭据状态
随一次私有准备批量取得，避免无限并发中继动作。密钥安装路径、审核令牌及凭据不得
进入读模型、快照、公共元数据或事件。组件清理不能撤销已接收副作用的独立原生围栏。

### 独立插件视图传输

前端单例激活/就绪状态留在协调窗口；视图传输是有数量上限、可撤销的子级，不是互相
竞争的激活。已批准的不可变资源应共享引用。视图不能确认或上报单例激活失败；关闭
它不能撤销兄弟视图或依赖消费者。替换/关闭激活会撤销所有子级及其待处理调用。可选
状态工厂本身不授予原生窗口权限，也不代表提供者句柄已经支持跨窗口。尤其不能用异步
工厂外壳替代提供者同步挂载 Workspace/Screen 的契约。逐文档授权、状态警告和领域
网关齐备之前，保留旧渲染路径。

协议 CORS 使用受信任配置中的开发 URL origin，不回显请求的 Origin，也不硬编码
开发端口；打包应用的 origin 保持不变。隔离原生 QA 的标识和数据，不接触已安装应用；
需测试真实模块导入，而不只是 mock 加载器。

### 公开原生窗口元数据与生命周期 API

`extensions.describe().nativeWindows` 声明实验性、权限受控的 RPC：
`workspace.windows.list/observe/create/close` 和 `workspace.panels.ownership`。
读取要求 `workspace.read`，生命周期操作要求 `workspace.write`。不改变冻结的
`workspace.snapshot` v1，不暴露私有文档令牌、草稿快照或模型，也不授予卫星窗口底层
应用 IPC 权限。所有者 generation 和 `canMove` 仅供参考，实际修改仍检查原生状态。

list 和 ownership 返回同一份带 revision 的原生快照，包括窗口角色、就绪/关闭状态、
面板 ID 与当前所有者 generation。observe 是先订阅后检查的、可取消的十秒长轮询；
单纯业务进度不会改变 revision。`workspace://windows-changed` 仅包含不透明 revision
作为失效提示。RPC 插件可用 observe 替代原生 JS 事件；revision 不保证持久重放。

create 返回宿主构造的隐藏卫星占位窗口，使用现有原生多显示器定位，全局最多 16 个
窗口。不接受 URL、脚本、调用方窗口标签或任意原生命令。空占位窗口二十秒后回收。
创建等待被取消时，后台保留原生构造直到实际完成，清理迟到的空结果，包括已发送却未
被接收方读取的结果。插件撤销仅清理其旧 generation 的空占位窗口，不能销毁已有用户
面板的窗口，也不能中断正在交接的面板。

close 仅请求正常的卫星窗口捕获/归还流程，不能关闭协调窗口、强制卸载视图、丢弃草稿、
绕过凭据确认或停止 SSH/任务。`{windowId, requested: true}` 仅表示接受请求，不表示
已经关闭；应观察原生元数据确认结果，或在交互保护解除后重试。原生关闭或捕获失败时
必须保留可恢复的所有权。

平台创建或设置窗口失败时，也必须复用原子空窗清理预留，不可直接销毁目标窗口。
目标可能在创建者返回前就已接收其他用户面板；创建者刷新或失去权限不代表可以
销毁这些面板，也不能中断正在进行的交接。

### 公开移动请求必须在源文档执行

`workspace.panels.moveToWindow` 要求 `workspace.write`、已支持的面板及已就绪的现有
原生目标窗口。可选 `expectedOwner` 的窗口与 generation 用于拒绝过期自动化请求，
而不是悄悄改动新一代所有者。原生层记录双方文档身份、预留面板，只允许精确源文档
领取封闭、不透明的捕获任务。不可从协调窗口旧 store 捕获卫星草稿，也不能转发任意
UI 命令。

只有原生 prepare/ready/commit 才转移所有权；RPC 在提交后返回新 generation，不在排队
或捕获后提前完成。领取、准备及提交均重查插件权限；最终有界元数据提交在权限锁内
执行，与撤销线性化。锁顺序为原生所有权 -> policy -> invocation，撤销清理先释放
policy 再访问原生窗口。invocation 围栏在条目锁内同步重查传输取消与期限，并持锁完成
有界提交；不能因为异步调用方尚未再次被轮询，就绕过已经返回的取消。围栏内禁止业务
资源操作、await 或获取请求注册表。提交前取消/撤销必须删除预留或 staged offer，
保留源所有权；提交后取消不撤销已接受的移动。刷新、崩溃、超时、视图未就绪、移除面板只清理对应请求，不能把业务资源
当成请求的附属资源。

待处理移动最多全局 32 个、单插件 8 个，请求生命周期 25 秒，另受正常交接时限约束。
源执行器销毁时要释放迟到领取及未完成预留。协调器提交失败后若原生确认 offer 已退休，
应刷新快照，不要把预期取消误报为新错误。请求调用方负责错误展示，卫星不因插件取消
请求而弹出无关错误 toast。可移动能力仍按适配器显式启用，不能假称未支持的 provider
已经具备原生多窗口能力。

### 源文档展示适配器

每个文档只安装一个私有展示适配器。协调窗口适配器必须拒绝修改其他窗口所有的面板；
卫星适配器只使用本地布局与浮窗 slot，不读写主窗口业务 store，也不启动资源引导。
向原生源路由提供封闭布局元数据与同步 set/hide/reveal 操作，不能提供任意 store
访问。卫星支持 workspace/floating，不可把不支持的 sidebar 请求悄悄转成其他形式。

隐藏本地视图时保留原 slot、分隔比例与 portal 所有者，只在渲染投影中裁去隐藏区域，
不能破坏源布局；再次显示要恢复同一个 DOM、草稿与分组。原生成员移除仍须释放 slot
及观察者。适配器只操作当前文档；公开面板 API 必须经过原生所有权路由，不能用协调
窗口代理来修改卫星布局。

原生聚焦必须显示请求的面板，而不是只抬起一个仍选中其他标签的窗口。聚焦后仅通知
原生采样的所有者 lease，重查文档与 generation；源文档只显示精确匹配、非 staged 的
当前视图。聚焦不能启动资源、恢复插件激活或扩大卫星的应用 IPC 权限。

### 公开面板元数据与已接受展示操作

`workspace.panels.list/observe/setPresentation/close` 由原生 workbench RPC 处理。
读取要求 `workspace.read`，修改展示要求 `workspace.write`。list/observe 投影各精确
所有者 lease/文档发布的封闭布局元数据：窗口、展示形式、可见性、固定状态、有界位置、
可用性与支持形式，不包含视图内容、凭据、草稿快照、插件令牌或业务模型。冻结的
workspace v1 不变。源尚未发布时应返回 `panel.window.viewNotReady`，而不是伪造主窗
状态；list 最多等两秒，observe 最多等十秒。不可用的文件预览目录行只属于主窗，且
不能显示为可见。

布局 revision 与资源进度分离，先订阅后检查快照；`workspace://panels-changed` 仅发
不透明 revision 提示。目标确认前要发布实际 staged 布局元数据，提交时随新所有者
原子复制，保证移动成功后不会报告旧源位置。刷新或所有者变更后，旧元数据失效，
直到精确源重新发布。

set/close 预留封闭源操作，绑定插件 lease 和同步 invocation 围栏，只允许精确源领取
一次。原生 Begin 按所有权 -> policy -> invocation 锁顺序重查所有权、交互、权限及
取消；它是操作被接受的准入点。Begin 前取消应释放预留且不改 UI；Begin 后，调用方
取消、超时或权限撤销不能回滚已接受的同步展示效果。原生围栏须保留到源完成或精确
文档消亡，不能在迟到 Begin 回复仍可能修改视图时，允许其他窗口取得它。取消窗口
关闭不代表文档退休，不能释放已接受效果；效果结束前也不能复用面板 ID。

Begin 返回后，执行器重查生命周期和适配器，并在没有中间 await 的情况下同步修改
自身布局。完成时提交真实元数据：set 必须可见且形式匹配，close 必须隐藏；失败则通过
仅清理用途的精确源调用释放任务。迟到领取、销毁或适配器替换不能修改已退休视图。
效果结束前应预留该面板的元数据发布通道，避免旧刷新覆盖已完成结果；其他面板仍应
正常发布，不能被单条迟到的 Begin 回复阻塞。
待处理操作限制全局 32 个、单插件 8 个，排队 TTL 十五秒，RPC 最多等待二十秒。
这些操作只改变展示：隐藏保留渲染器、slot 和草稿，不停止 SSH 或其他业务资源。
源不支持的展示形式明确失败，不能转而修改主窗口。

### 异步临时视图状态捕获

面板交接与检查点等待 `captureAsync`；同步捕获仍兼容内建同步字段，但明确拒绝仅支持
异步的字段。每个面板同时共享一次捕获，总期限为 15 秒。取消某个等待者不释放不响应
取消的渲染器所占名额；所有选中回调（包括兄弟回调失败后仍运行的回调）实际结束后才
允许下一次捕获。沿用严格 JSON、字段数和总大小限制，不截断草稿。内容变化使在途快照
失效；窗口适配器仅在原总期限内重试，发布前再次校验精确控制器、租约与 DOM 根。
状态胶囊不持久化，也不进入公共元数据。

工厂渲染器通过面板作用域绑定 `{version, pluginId, viewId, state}`。恢复结束后才挂载
真实渲染器；暂存确认必须等待真实视图提交就绪，并覆盖随后注册的子字段。加载占位和
错误回退均不视为目标就绪。焦点和光标恢复同时等待就绪与所有权提交；来源 DOM 状态
必须在 `inert` 导致失焦前捕获，回滚时等待本地与原生冻结均解除后恢复光标。渲染异常仅隔离
对应面板；暂存失败回滚到原来源。不支持状态的工厂明确拒绝捕获，不伪造空状态。

独立窗口关闭前异步捕获全部面板，再调用原生 `beginClose`，校验其原子冻结的成员与
捕获租约逐一相符。失败仅取消已经开始的原生关闭，并按精确原租约解除本地冻结，旧
清理不得解冻替代实例。文档销毁取消等待，禁止迟到结果继续准备交接。

这只是异步状态与就绪链路的基础，**不代表插件原生视图网关已完成**。可跨窗的内建
适配器仍须逐项启用，不能据此开放独立窗口插件激活或原始 RPC，也不代表旧插件状态
警告与提供者等价性已经完成。

### 原窗口插件确认（内部网关）

原生视图的 `ui.confirm` / `ui.showMessage` 排队发送到精确的所属窗口及文档，
不得转发给隐藏的协调窗口。失效通知不含提示文本或能力。受限的列表/回复网关
从原生调用者获取窗口身份，校验文档与请求归属，并在最终交付锁内重新校验面板
租约、视图 token、插件代次/权限与调用取消状态。暂存或冻结视图不能发起确认。
锁顺序为所有权 -> 前端模块 -> 插件策略 -> 调用；同步门内不得重入安全或原生
所有权锁。

确认在结束前持有面板交互锁，阻止交接。每个原生窗口最多一个确认，每个插件
最多八项 UI 排队，全局最多 64 项。确认 55 秒超时返回 false，消息 15 秒超时。
传输取消或权限/文档撤销会撤下旧确认，不允许迟到的批准。两类文档共用确认
控件，不导入主窗口资源启动流程。既有用户对话框不能被替换；消息只展示一次
并确认接收。失效刷新加有限轮询在漏掉事件时同样撤下过期提示。文档销毁拒绝
当前确认，并忽略迟到 UI 回复。

`mounts.runtime.requestForceUnmount` 独立审查，只有已提交的原生视图可调用。
宿主私有的 `__mounts.forceUnmount` 提示始终使用危险操作样式，默认焦点为取消；
公开 `ui.confirm` 的参数不能选择此路由。待确认请求持续绑定 `mounts.write`、
精确原窗口及原调用。批准绑定规则、组、revision、运行实例和会话；接受后在组锁内
复核，文件系统探测结束、真正准入前再次检查，不能把旧确认用于替换后的实例。

保留的卸载策略按原窗口、权限、调用、运行状态的锁顺序，仅在元数据准入内同时提交
取消竞争和 `desired:false`，通知必须在释放这些门之后发送。准入前取消、撤权或
身份变化不修改原意图；准入后工作线程持有组锁直到卸载、子进程回收及宿主状态更新
全部结束，即使结果投递过期或权限变化也必须完成。成功清空实例及会话；失败保留
精确的清理预留、`cleanupRequired` 与 `desired:false`，阻止后台自动重新挂载。
最终状态更新是已准入副作用的收尾，不是另一项需要重新授权的插件写操作。前端
在发布确认框前登记精确回调，允许同步接受、关闭、替换或销毁，不能误关后来出现的
其他对话框。单元测试中的子进程夹具不等于真实 FUSE 挂载验收，验证报告必须区分。

旧挂载的 `mounts.legacy.list/convert/dismiss` 同样仅允许已提交的原生视图。
在等待或派生线程之前捕获原窗口及调用围栏；SQLite 互斥忙时退出所有准入门，
在有界工作线程中重试，不能阻塞异步执行器或持有策略锁等待数据库锁。
转换全程保留组锁和挂载注册表锁：以同主机、组 revision 和新规则 ID 校验并保存，
提交后无异步间隙地转移挂载所有者并登记运行实例，即使调用取消也必须收尾。
失败不转移所有权；一次性挂载原有的用户 SSH 会话只被借用，不能登记为专用连接，
不能随组连接释放而断开，也不能让恢复器把它误当成组连接。

`mounts.runtime.open/reveal` 在真正系统启动准入前，复核原窗口、原调用、写权限和
精确规则 revision／组／挂载实例／会话。注册表与组预留贯穿探测、路径包含校验及
系统启动；不能先取快照，再让卸载或替换抢先发生。嵌套文件系统超时仅结束结果等待，
实际线程仍持有原生副作用围栏和这些预留，直到真实调用返回。macOS 设备查询、
路径规范化、兼容打开操作及 Linux 有界挂载表读取共用保留工作线程的机制。
系统打开／定位在元数据准入门外执行；准入后完成已接受的操作，不因权限变化
重新授权收尾。测试中模拟系统打开或使用普通子进程不等于真实 FUSE 或文件管理器验收。

该内部传输及测试不代表生产插件面板适配器或资源 RPC/原生窗口能力已经完整。
实际适配器、真实副作用生命周期和原生验收完成前，能力发现仍保持保守。
面板 ID 接受完整插件/视图组合身份（7 + 128 + 1 + 128 个 ASCII 字节），不能
为了旧的 256 字节限制截断不同的 ID。

## 普通页面与空分组

所有内置工作区页面均可通过标签或分组菜单打开为同文档小窗。`PanelFrame`
是页面与 `WorkbenchPanel` 共用的表面、几何与 Escape 底座，两者只是适配器，
不是两套窗口系统。`WorkspaceContents` 始终只持有一次页面；`TabContent`
移动保留容器，保持编辑器草稿、终端实例及组件状态。浮动分组保留停靠目标与
返回分组；Escape 或“移至工作区”只回停靠，标签关闭才真正关闭页面。
拖动小窗标签到其他分组沿用工作区拖放适配器。浮动几何为临时状态，不扩展冻结
的 workspace v1，冷启动将保存页面恢复为普通分组。这不是原生窗口交接；
原生窗口仍必须使用前文的独立所有权协议。

插件可在 Manifest 的视图条目声明 `allowFloating: false`，省略则允许。
宿主在修改入口强制执行限制，并从能力快照及菜单中移除该展示方式。
内置页面不能采用允许列表或自行禁用小窗。所有浮动适配器共享一套叠放时钟。

侧栏、面板和标签顶栏统一采用 `--td-workbench-header-h`。空分组不显示标签
工具栏、锁或更多按钮，但内容区仍接受拖放。紧凑原生窗口仅保留必要的窗口
控制/拖动安全区。工作区面板不得重复显示标签栏已有的移动/关闭操作；业务
命令仅保留一套。输出的频道、搜索、错误等级、跟随、清空和更多位于标签栏
下方的同一业务工具栏，不向标签栏注册输出操作。

## 关闭连接消费者

`disconnectOnPanelClose` 默认开启，旧设置文件同样使用此默认值。显式关闭
页面后，仅当该精确会话的最后一个终端、SFTP 数据源、编辑器或监控消费者
消失时释放连接。双文件面板必须追踪两侧数据源。普通页面关闭不释放转发或
挂载规则持有的连接。移动、回停靠、隐藏或卸载组件不能断开连接。用户可关闭
设置以保留后台会话。该新增设置通过 `settings.get/update` 和设置配置档开放，
不得暗中扩展冻结的公共 preferences v1。

连接管理复用 `SearchToolbar`/`SearchField` 的文本、`@type`、`@status` 和
`@host` 解析。只允许选择当前可见的活动结果，查询变化清空选择。批量确认
绑定固定 ID 集合，限制并发清理数量，失败项保留以供重试。历史记录可以搜索，
但不能选择执行断开。

`mounts.dependencies.documentation` 只打开宿主指定的平台安装说明链接，不会为了打开说明扫描
FUSE 路径或运行 SSHFS。持久规则与旧入口都捕获原始窗口/请求，在浏览器启动准入时重新验证
`mounts.read`；有界启动工作者保留原生效果直到实际调用完成，即使调用方已取消交付。
浏览器启动在准入锁之外执行，暂存渲染器不能打开说明。

卸载前的存在性与挂载身份探测也必须在内部超时后保留原注册表/组预留，直到实际文件系统
工作者返回。探测超时不等于工作结束；不得让重试、规则接管或替换提前穿插。

### 转发面板视图状态适配

转发面板的主机选择、规则编辑身份、不完整输入字符串及组编辑/名称草稿使用通用临时面板胶囊。
外部导航先收敛到明确选择，目标文档不必复制主窗口导航仓库。草稿绑定主机、规则与 revision；
空端口保留字符串，直到用户明确保存。新组尚无 ID 时也携带主机身份。取消会注销草稿；
捕获本身不保存规则、不连接、不重启，也不写入偏好。

提供者的延续权限属于当前文档，绝不能序列化或在目标窗口悄悄升级为不受限的内置权限。
提供者编辑、待完成的连接/确认及进行中的规则/组修改必须拒绝捕获。
该捕获检查不是原生效果栅栏，也不表示转发原生窗体适配完成：原生资源准入、原窗口交互、
共享数据/操作传输以及提供者句柄仍须独立验证。

### 转发共享读取源

主机详情和全局转发面板保留同一份单例规则源及显式分组源。私有命令
`forwarding_groups_list` 接受可选主机 ID；省略时读取全部分组，包括没有规则的空组。
消费者按主机身份筛选，不能从规则行推断分组存在。第一个订阅者启动观察与读取，
最后一个订阅者退出时停止观察、清空快照并隔离已放弃读取的迟到响应。
连续失效合并为一次后续读取。组修改即使部分失败也刷新两个源，手动刷新同样重试两者。
此文档内共享源只是跨窗口数据/操作传输的前置工作，不代表后者已实现。

### 宿主持有挂载维护与旧安装说明入口

插件查询不再把全局进程/桥接清理当作隐藏的前置操作。已有宿主恢复循环负责非阻塞注册表维护，
也覆盖没有持久组的一次性挂载。注册表被精确事务预留时跳过本轮，后续再试；保持健康工作者、
所有权及原有清理错误。进程退出不等于文件系统消失，不能据此删除挂载记录。
仅记录新的清理状态时发送变更通知。

已有 `mounts.documentation` RPC 与 `mounts.dependencies.documentation` 共用原窗口、读取授权
及请求栅栏约束的浏览器启动器，不再经过旧注册表清理或依赖探测。两者只允许已提交的原生视图调用。
这不表示其他旧挂载别名已准入，也不代表物理 FUSE 或系统浏览器验收完成。

### 转发模型与服务边界

私有转发读取模型显式投影主机展示信息、规则配置/revision/运行实例标记、分组（包括空组）、
会话 ID/主机 ID/用途及错误展示文字；不复制主机密钥路径、备注、凭据、代理设置、插件授权或
任意错误对象。仅在目标窗口/交接需要时，协调器与本地消费者共用规则/组读取者；
仅订阅发布者不启动 I/O。最后释放共享读取者会隔离已放弃请求的迟到响应。
模型发布仍受原生大小限制及所有权检查约束。

规则、组和会话 Hook 可从显式读取作用域取值，不启动本地读取者、不回填可写仓库。
现有控制器、规则行和组组件的修改及剪贴板操作使用完整的 `ForwardingActions` 作用域，
只有主文档实现持有 IPC 和已提交数据更新。作用域服务拒绝后绝不能降级重试内置服务。
提供者延续仍是当前文档的权限，获取作用域后须重新授权；等待前捕获操作身份与可编辑字段，
不能把提供者权限或临时连接凭据序列化成草稿。主文档实现拒绝卫星窗体调用。
断开操作观察原生失败并保留失败会话，继续处理已确认批次的其余条目。

这些是可复用的数据/服务适配，不是完整的转发原生窗体支持。主机对话框、连接审查/确认的
原窗口准入、提供者原生句柄、封闭原生操作传输及实际资源效果栅栏仍须集成和验收，
之后才能把转发加入原生能力发现。本次未启用卫星渲染器或转发交接准入。

内置转发停止操作绑定界面所见的规则 revision 和准确运行实例；启动/重试期间
“当前没有监听器”也是明确快照，不代表允许停止任意后来启动的实例。
自动化准入锁覆盖注册表/数据库 CAS 与暂停恢复；拒绝过期请求不得取消新任务或
改变其恢复意图。清理先启动再返回交付句柄，监听器的组连接引用保留到清理结束。
历史调用同时不传两个标识时保留原行为；只传实例不传 revision 则拒绝，不得降级
为无条件停止。这些是领域正确性保证，不等同于独立窗体动作/来源准入已完成。

### 内置转发的原生修改入口

私有 `panel_window_forwarding` 目前接入规则保存、准确快照停止/删除、分组保存和空组删除。
请求不能携带提供者 origin、SSH 会话 ID、任意命令或调用者窗体标签。
审查后启动的凭据使用独立、封闭、有界的请求内载荷，禁止进入读模型、布局胶囊、日志或事件。
保存显式绑定 revision、分组及自动化选项；非回环地址暴露必须持有同一文档、
同一面板 lease 的有效交互凭证。

原生根据 IPC 来源校验窗体、文档、准确 lease 和面板可操作状态；工作线程在
实际同步领域事务前持有所有权锁重新校验，锁顺序为所有权 → 停止/删除时的自动化 →
转发注册表 → 数据库。每面板仅准入一个直接操作；回复等待守卫实际结算，
包括最后一个分组传输的后代清理。实际效果守卫由原生工作线程
持有，不依赖 JS 回复交付，停止/删除时保留到监听器/连接清理结束。最终准入前重载或
撤回交互凭证则拒绝；提交后取消不代表回滚。删除面板不能抹去直接原生效果仅有的
守卫；历史中继任务继续使用独立的结算记录与未知结果隔离机制。

删除必须携带原删除确认的有效交互凭证、规则 revision 和准确运行实例（或明确
无实例）；先校验运行快照，再在同一注册表锁内提交数据库删除。过期实例不能先删除
元数据再报错。规则、revision、自动化配置和分组归属原子删除，组本身保留；失败不得
暂停新恢复或取消新启动。原确认消失后，同文档后来创建的确认不能替它授权。

此入口和类型化文档客户端不等于完整独立窗体转发适配：连接/提示、提供者句柄、
删除确认 UI、剪贴板/主机对话框及卫星渲染仍需接入与验收，转发的跨窗发现保持
关闭。不得逐方法降级到原始命令，伪装成完整远程服务。

### 内置转发的审查后启动（私有入口）

`prepareStart` 仅返回连接提示所需主机/跳板元数据和原生路由审查，不返回完整主机、
密钥路径、代理或凭据记录。`start` 绑定此审查、规则 revision 和原面板有效交互；
强制后台转发用途和宿主管理的分组连接池，拒绝任意 SSH 输入、外来跳板凭据、调用者
窗体标签与提供者权限。这还不是完整连接提示适配：实际提示/提供者/渲染器仍必须完成，之后才能准入转发跨窗发现。

私有 `probe`/`trust` 操作同样绑定规则 revision、路由审查和原始交互，仅接收属于实际
审查跳板的有界凭据。信任操作重新探测原路由，比较所展示的指纹及预期跳板，并在锁外
观察代理/钥匙串状态。最终信任写入持有原所有权，在同一 DB 守卫下校验规则 revision、
所属主机和原路由，只批准实际观察到的端点并返回推进后的审查。失败或已撤回的操作
不能批准替代规则、主机、路由或后来的对话框。IPC 交付丢失时，传输清理仍持有效果
栅栏直至实际结束；这些方法不开放跨窗发现。

私有 `WorkLifetime` 可携带同步原生发布权限；有界后代工作继承效果守卫，在工作线程
准入和网络/认证步骤前检查。路由/钥匙串观察在所有权锁外执行；未公开会话插入与监听器
最终准入在短所有权锁内重新校验原窗体/文档/lease/交互。观察后的启动证明与其待提交
监听器不可分离，禁止持所有权/自动化/注册表锁进行慢 OS 检查。

待提交路由、监听器和未收取交付结果在调用者退出及后代清理期间保留效果。清理作用域
保留栅栏，但释放原资源不要求重新获得已撤回的确认。远程转发取消保留到 SSH 对端确认，
而非仅发送入队。已准入监听器释放临时启动效果，继续持有分组传输，避免运行规则永久
阻止面板移动。

### 内置转发的已审查凭据（私有入口）

`credentialStatus`、`saveCredential` 和 `forgetCredential` 绑定原所属面板交互、
规则/revision/主机及路由审查。状态只返回布尔值；保存只接受有界的请求内密码，不能
指定物理钥匙串标识、服务或提供者 origin。只能操作已审查的目标或实际跳板主机。
凭据绑定准入与发布在短暂的权限 → DB 守卫下共同检查原生来源、规则与路由。捕获的
凭据请求即使离开提交任务作用域仍保留原权限；平台读写不持有上述锁。OS 操作期间
撤回确认或修改规则不能发布暂存项，也不能删除替代绑定。

原物理项的退役清理不要求替代确认。现有有限清理任务会在实际 OS 工作期间保留来源
效果栅栏，涵盖后到的请求和已取消的协调器；替代清理任务扫描为空不代表旧工作结束。
清理失败保留原持久记录，不重放保存，也不追随已改变的逻辑目标。这些服务仍只是
完整提示/提供者/渲染器适配的前提，不开放转发原生窗体能力发现。

### 内置转发的审查后连接测试（私有入口）

`test` 绑定原窗体/文档/lease/交互、准确规则 revision 与已审查路由，只接受实际
跳板的有界凭据。小写 UUIDv4 `testId` 仅用于私有请求关联，不是全局 SSH 测试 ID；
原生另行生成内部诊断 ID，复用现有三次采样、25 秒总预算。结果提交前共同重新校验
规则/路由和原权限；取消或原交互退役后不能发布迟到结果，也不能准入新的网络/凭据工作。

`cancelTest` 只发送给准确来源作用域；同面板效果栅栏占用时仍可取消，原确认撤回后也能
释放原工作，不要求重新确认。它不能取消其他窗体、文档、lease、交互或全局 SSH 测试。
提前取消保留粘性墓碑，最多保留 64 条记录，不淘汰仍有效对话框的历史来放行重放。
原作用域退役时取消活跃工作、回收已结算记录。结果只提交一次，后来的取消幂等，不是回滚。

取消确认不等于 IO 结算。原生效果及面板删除/移动栅栏保留到已准入工作线程与实际传输
清理结束，包括超出测试 future 生命周期的工作；原测试 IPC 回复也等待此结算。
不提供全局 `ssh_cancel_test` 降级，不序列化提供者权限，也不开放转发跨窗发现。

### 内置转发的审查后密钥安装（私有入口）

`installKey` 必须绑定原面板交互、准确规则 revision/主机与路由审查，只接受有界的
请求内密码/跳板凭据，不能指定密钥路径、密钥、会话 ID 或提供者 origin。后代认证工作
同样保留原生来源和规则谓词；后来的对话框不能替代已撤回的确认。

共享密钥安装在权限/DB 锁外观察 OS/代理状态；本地发布准入、远端目录/创建/追加/写入
准入及最终认证方式切换共同检查原来源、路由与规则 CAS，最终检查位于修改主机认证
方式的同一 DB 守卫。生成本地暂存密钥后、无覆盖发布前再次检查，拒绝时清理暂存文件。
远端 APPEND 打开后、WRITE 前再次检查，失败仍关闭原句柄；WRITE 和 CLOSE 都确认后
才能修改本地认证设置。不持所有权/DB 锁执行密钥生成、文件系统或网络 IO。

已经准入的外部效果不承诺回滚：后续失败或撤回确认时，本地托管密钥或远端目录/文件/
公钥可能已存在；最终 CAS 拒绝必须保留原认证设置，不能修改替代主机/规则。专用安装
会话和实际传输清理持有原生效果到真正结算，而不是仅等 RPC 交付。原生回复为 `null`，
不返回密钥路径或内容；成功关闭提示，后续操作因认证方式改变必须重新准备审查。
此入口仍只是前提，不开放转发原生窗体发现，也不替代剩余提示/提供者/渲染器接入与验收。

### 原窗体中的内置转发连接提示

`createForwardingWindowPrompt` 通过封闭原生入口提供完整 `ConnectionPromptServices`。
它捕获准确规则/lease，在 `WindowForwardingConnectDialog` 挂载共享交互提示前取得原
交互凭证。React 只接收主机/跳板展示元数据；路由审查、输入凭据与关联记录仅存在原
文档中，不进入布局胶囊、模型广播、插件消息或可写主机 store。提供者主机/路由在独立
原生句柄完成前明确拒绝，不能降级成内置主机。

React 会同时启动探测与凭据查询；适配器串行实际原生请求（包括各跳板状态），失败后
队列可继续，但不重试效果。信任成功在队列内部推进审查，之后的请求才能执行。输入
在服务提交时捕获，而不是等排队结束再读取；原生决定 SSH 用途/分组，不转发任意 SSH
参数。`forward.changed` 清空输入凭据并禁用连接，必须关闭后重新审查。

取消绕过队列，但始终绑定原关联 ID/交互；原生测试真正结算前不放行队列。对话框历史
最多 64 条，不淘汰提前取消记录来放行重放。关闭、准备失败、身份替换、卸载或生命周期
重放都释放准确原交互，包括迟到的准入。界面关闭不等待 IPC，迟到结果/排队写入不能
复活旧提示；实际原生工作继续持有自身效果栅栏到结算。等价读模型刷新不能重新获取
确认或重启探测；忘记凭据继续使用同一文档中的共享受控二次确认。

这个完整内置提示服务/UI 前提本身不等于完整转发渲染器，也不提供尚未完成的提供者、
断开连接或主机对话框适配。转发跨窗发现与 `nativeWindows` 继续关闭，直到这些以及
全部普通页面/原生验收要求完成。

### 原窗口转发确认

`WindowForwardingConfirmationScope` 将共享受控 `ConfirmDialog` 与原始
`createPanelWindowInteraction` 生命周期组合；内置连接提示复用同一生命周期原语。
转发控制器在请求确认时复制规则/编辑输入、固定待断开会话 ID，只向对应的
保存/删除/断开动作传入原始 interaction，不将其视为提供者权限或写入检查点。
原生确认先获取交互再展示批准按钮，取消晚到的获取结果；并发请求不能替换已显示的
批准，客户端或 lease 替换会废弃旧界面与保留回调。普通模型刷新与生命周期重放
不得重新获取或静默替换正在显示的同意。获取中与确认中均阻止面板捕获，不能将其
恢复成已批准草稿。卫星窗口缺少显式确认服务时必须拒绝，不借用主窗口对话框；
主文档仍保留现有确认宿主行为。这一边界本身不提供原生断开、提供者、主机服务或完整
转发渲染器，也不开放原生转移发现。

### 准确转发会话断开

私有原生转发网关的 `disconnect` 只接受固定的内置主机/会话和原确认交互，
不代理任意 SSH 命令，也不接受序列化的提供者权限。当前所有者保护下的短事务按
自动恢复 → 监听注册表 → 数据库 → SSH 管理器顺序，先校验会话已发布、属于准确
主机且为非终端转发用途，再移出监听并废弃待启动工作。被拒绝的选择不能暂停新恢复。
成功的手动断开暂停准确会话规则及同主机/同组的待启动兄弟规则，不影响其他组或
未分组规则。

原监听与传输句柄在锁外退役。远端取消确认、挂载清理和传输关闭独立于 IPC 回包或
同意撤回，继续保留发起效果；清理不是新的连接授权。单条监听清理失败不会跳过后续
传输退役。残留挂载必须报告清理未完成，而非假报成功；这不等于真实 FUSE 连续性
验收。主窗口删除面板仍被实际工作栅栏阻止，直到已准入工作真正结算。完整转发渲染、
提供者/主机服务及跨平台物理拖拽验收仍是开放原生跨窗发现的前提。

同一私有转发网关提供受限 `copyAddress` 文本写入（最多 512 UTF-8 字节，不含控制
字符），不提供剪贴板读取、任意命令或提供者 origin 字段。实际工作线程准入前重新
检查准确窗体/文档/lease，OS 访问不持有所有权锁。已准入的 OS 写入保留原生效果
直到真正结算，即使 IPC 回包消失；后续文档退役不能回滚外部写入。这一原语本身
不开放完整转发视图或提供者适配。

### 当前转发界面提供者的视图附着

私有原生插件视图网关可以描述当前选中的转发提供者，并将作用域子视图附着到
准确的已持有转发 lease 或暂存交接。提供者由宿主设置选择，不接受调用方传入
激活令牌。描述只包含模块身份和选择 revision，不包含单例激活凭据。打开时复用
已运行的激活实例，不启动插件、不再次执行 `activate`，并尊重 `allowFloating: false`。

子视图绑定原生调用文档、面板、内置主机、选中视图/运行实例及选择 epoch。
切换后再切回也不能恢复旧描述或子视图。模块加载、调用准入、origin 检查和 UI
回复重新验证绑定；主机删除、权限撤回、运行实例退役或文档/交接失效均撤销访问。
准确交接沿用现有生命周期提升暂存子视图；已准入效果保留独立的实际结算栅栏。
关闭子视图不会关闭插件单例或替代它的新子视图。

视图附着本身不提供变更授权或完整提供者渲染。原生子视图不能使用
主文档的原始 `forwarding_provider_open` 桥接。提供者操作和连接提示仍需各自的
准确 origin 原生服务，完成后才可准入转发适配；附着本身不会注册普通侧栏适配，
也不会开放原生窗口发现。

### 原生转发提供者变更入口

私有原生插件视图网关还接受封闭的 `forwarding` 请求，包含原生子视图令牌、
准确已提交 lease 和类型化变更，不接受调用方指定插件身份、权限、提供者 bearer
origin 或任意 invoke。暂存/冻结子视图不能变更。准入与实际短事务重新校验原子视图、
选中模块、选择 epoch、读写策略、内置主机和捕获的规则/组 revision。
写操作必须有 `forwards.write`；读操作沿用提供者读取策略。锁内回调不能重入
frontend/security，也不能进行 OS/网络 I/O。

提供者创建的监听保留原插件运行代次归属，插件退役时准确清理。网络等待后选择或
权限已失效则不能发布。已准入的停止/断开只清理原句柄，即使随后撤销选择仍须完成；
实际后代持有面板栅栏直到结算。诊断取消绑定原子视图，不能由替代视图或内置路由
冒领；策略失效会取消待完成的提供者诊断。

这仍只是服务入口，不是完整 `ForwardingActions`、提供者连接提示或生产卫星渲染器，
不会开启原生窗口发现，也不放宽主文档原始 frontend lease 桥接。

### 原窗口提供者连接提示

共享 `WindowForwardingConnectDialog` 支持显式原生提供者子视图。准备、信任、诊断与
取消、凭据、密钥安装及托管规则启动全部使用同一个子视图传输；面板客户端仅提供
原交互生命周期，不能回退成内置变更。等价读模型刷新不重新请求同意；子视图、提供者
客户端、规则 revision 或原生所有者更换则退役旧作用域。迟到的准备/完成不能交给替代
回调。秘密仅存在直接提示请求中，不进入检查点或读模型。

批量后续目标按原顺序、原规则 revision 和同一内置主机捕获；每条后续规则单独准备，
且只能使用当前提示已审查的主机路由。单条监听失败会报告并继续后续规则；主机凭据或
信任错误则停止批量，避免跨独立 SSH 组反复错误认证。结果只含规则/会话元数据和错误，
不含凭据。完成回调失败后不能重放已成功启动的监听，必须重新打开提示。部分失败交给
宿主回调或错误 toast。这仍不是完整卫星渲染器或转发适配。

### 共享原生转发提供者界面

`WindowForwardingSurface` 复用持久规则行与编辑器组合，但通过原生选择描述发现
提供者，不使用主文档设置/安全 store 或 `frontendRuntime`。写能力只是当前实际授权
的展示提示，不是声明权限或变更授权；每个效果仍通过原生子视图重新授权。
工厂不会再次启动插件单例，也不会在选中提供者失败时回退成内置变更。

选择、安全、运行实例及所有权通知触发合并后的元数据读取，事件载荷不传给插件。
描述不变时保留组件、附着和草稿；选择 revision（含 ABA）、写能力变化及取消选择
退役旧来源。临时发现失败保留草稿并提供显式重试。暂存视图只读；提升时更换操作
所有者而不重挂子视图，捕获的旧所有者回调不能变更。退役时清理迟到的模块导入、
监听与附着。该共享界面仍不是 `SatelliteApp` 准入或完整原生窗口验收；完整适配集
通过验收前继续关闭原生窗口发现。

`WindowForwardingPanel` 是卫星渲染器使用的只读模型组合，不订阅主文档主机、SSH、
导航或对话框 store。稳定的展示所有者跨暂存提升保留，而已提交 lease 通过 effect
获取新的操作服务；交接、未决中断或记录替换会冻结旧回调。确认所有权变化不再
通过 key 重挂整棵内容树。提供者草稿和内置编辑字段沿用现有进程内面板捕获契约，
凭据和原操作令牌不进入快照。

手动刷新使用限定原转发面板、无参数的 `refreshForwarding` 封闭中继，使实际单例
规则/组读取器失效；只刷新卫星展示副本不能重新读取后端。渲染路由与交接/发现准入
分别实现；完整状态/就绪协议与真实原生交接验收完成前，转发仍不加入可交接适配白名单。

选中提供者的发现过程在子组件 layout effect 中注册私有就绪字段，早于目标窗口父组件
检查准入。元数据加载不等于就绪：现有捕获控制器还须等待真实工厂的模块导入、状态恢复、
渲染提交，以及等待期间新增的子字段。只有明确的无提供者元数据才准入内置界面；发现、
导入、恢复或渲染失败都拒绝暂存，不能把加载/错误外壳当作完成，也不静默回退。
就绪绑定卸载时拒绝原等待者，迟到的发现结果不能使其复活；显式重试创建新提供者工厂，
已拒绝的旧等待保持失败。`forwarding.selection` 捕获字段只是值为 null 的准入标记，
不是插件状态、凭据或操作授权。这些就绪测试不能替代真实原生交接验收，也不开启可交接
适配白名单。

主窗口的纯工厂转发提供者现在也沿用 `plugin.factory` 捕获契约；私有选择就绪门须等待
原视图作用域提交及子字段就绪，不能提前确认来源或恢复界面。提供者失败后即使内置
恢复界面可见，也不能把失败捕获成普通内置面板。要求同步 Workspace/Screen 插槽的
其他提供者不随之开启此工厂路径。

已有 `views.register` 渲染器保留原组件与激活实例；来源捕获要求准确视图实例的状态
丢失同意，只记录显式重置，不伪造空状态。模块同时导出 `createView` 时，重置可以
打开新的目标工厂而不再次激活插件单例。完全没有工厂的模块仍不能远程渲染：目标暂存
拒绝准入并保留原来源。无工厂旧模块的完整呈现与真实原生交接验收仍须完成，不能把
这个来源兼容保护当作它们已实现。

目标初始选择也必须匹配已捕获的提供者身份。捕获与发现之间取消选择，不能靠内置规则行
悄悄准入并丢弃 `plugin.factory`；目标应拒绝暂存，让来源保持可用。只有匹配选择的渲染器
已提交后才解除这一初始要求，其真实工厂绑定仍负责状态恢复与就绪。因此已恢复界面后续
由用户明确取消提供者选择仍可正常生效。

### 转发渲染器整合与原生交接检查

`renderablePanel` 将生产捕获/暂存整合与公开移动准入分开。转发现在在两个文档中都使用
真实 `NativePanelView` 的交互、就绪、DOM/焦点与检查点外壳，但仍不加入
`transferablePanel` 或原生移动白名单。可以渲染不等于新增创建或移动窗口的权限。

提供者发现须捕获准确的暂存/已拥有目标。请求期间因提升而失效的目标回复或错误，应针对
当前目标重新校验，不能当作新的提供者选择。已提交操作服务的生命周期也触发元数据重查：
原生失效通知可能先于本地协调器提交新租约。两条路径都不能重置提供者子视图。发现错误的
“重试”只重查元数据并保留原草稿；只有显式工厂渲染重试才替换失败工厂。真实的当前发现
错误仍拒绝就绪/捕获，且不会授予任何修改权限。

隔离 macOS 检查使用真实生产 `SatelliteApp`、原有捕获/恢复及原生协调器 ACK/提交，
完成两次主窗口/原生窗口往返。两向编辑草稿均保留，原有托管 SSH 组会话及转发 TCP 回显
持续可用，插件单例始终只激活一次。该检查使用显式第一方准备/提交，不是操作系统指针
拖拽；不覆盖无工厂旧视图、FUSE 连续性、Windows/Linux 指针释放、混合 DPI 或其余
页面/提供者适配。开启原生窗口能力发现与公开移动前，仍须完成完整能力对齐验收。

### 一次性挂载快照与资源控制

原生视图网关显式准入四个已有兼容 RPC：`mounts.list`、`mounts.dependencies`、
`mounts.open` 和 `mounts.unmount`，不是开放任意 `mounts.*` 转发。列举只读取插件
自有注册表快照，可在暂存渲染时调用；不隐式重算插件指纹、回收进程或探测文件系统。
依赖检测复用已审查的保留探测、终止与回收路径，仍只能在已提交视图中调用。

打开一次性挂载现在复用托管挂载的保留注册表事务，不再先列举挂载、稍后打开未保留的
路径。原插件 ID/代次须仍拥有准确记录，启动前检查传输存活、挂载身份与规范路径包含
关系。已转换、替换、异常或其他插件的挂载不能被打开。注册表保留跨越慢探测和实际
系统打开器；关闭视图、取消结果或撤销授权，都不能提前释放已准入操作。打开挂载不会
断开或接管原终端 SSH 会话。

卸载别名使用原始已准入租约及现有的准确来源/调用围栏卸载事务，保留注册表、嵌套探测
和子进程回收直到实际结束。原所有者/代次检查和旧 force 参数语义不变，公开 v1 输入/
结果契约也不变。挂载创建与浏览的后续独立接入见下文。普通子进程/打开器测试接缝不是实体 FUSE 或文件管理器验收，也不代表
所有资源 RPC 已对齐。

### 一次性挂载目录浏览

`mounts.browse` 现在与托管目录查询共用有界、独立、只读的 SFTP 通道，绑定原插件授权、
调用、原生来源及准确 SSH 句柄。迟到 OPEN 与对端 CLOSE 在实际清理前持续保留移动围栏，
不会断开共用的父连接。原生命令兼容入口也共用这条路径，不再使用未保留所有权的旧列举
辅助函数。暂存中的原生视图不能发起这项网络操作。

原有 `{path, entries}` 仍返回完整的纯目录列表，不增加 `nextOffset`、不静默截成第一页，
也不依赖解析无关的主目录；过大或恶意响应会明确失败。较新的
`mounts.paths.remote.browse` 保持现有分页结果。挂载创建的后续接入见下文；
允许浏览本身不代表全部原生窗口能力已经对齐。

### 端口转发独立窗口交付

端口转发现已与其他已准入面板一样提供新建独立窗口和移动至已有窗口的操作。TypeScript

### 独立窗口中的一次性挂载创建

`mounts.mount` 已接入仅限已提交视图的原生调用策略。请求和结果契约不变，保留最初的
插件租约、调用、文档/视图来源以及精确的已认证 SSH 连接句柄。路径准备和启动使用
有容量限制的保留工作者，文件系统校验不再阻塞运行时。就绪失败或最终授权失败会
等待该条挂载的清理；启动结果无人接收也会清理自身进程，并保留副作用屏障直到
SSH 通道 CLOSE 完成，不断开借用的父 SSH 会话。

只有启动成功发布后才释放创建调用的通道屏障，挂载此后由宿主注册表持有，可跨视图
迁移继续运行；失败路径仅丢弃释放回调不会提前释放屏障。现有托管挂载也复用该传输。
真实回环 SSH 测试覆盖传输、成功交接、失败启动的 CLOSE 和同连接其他通道的可用性；
普通子进程测试覆盖结果丢失后的回收。这不等于真实 FUSE 挂载或跨平台原生界面验收，
其余页面适配和完整独立窗口兼容性仍按上文跟踪。

### 预览协调器与视图状态

主预览所有者在 `PreviewFrame`、`NativePanelView` 上方同时发布既有公开元数据注册
和独立的宿主私有读取注册。暂时移除正文不会撤销注册或重新读取本地/SFTP 文件。
私有窗口发布器串行处理资源、模型以及协调器重启，去重未变化的资源，仅订阅当前
读取来源；原生快照通知不会形成模型发布循环。底层票据只进入 main 专用资源命令，
不进入模型、公开观察或视图胶囊。读取/解码错误不序列化任意原生异常内容。

文本正文放在私有读取模型，不放入不超过 1 MiB 的视图胶囊。仅预览模型允许最多

数据/服务，不自行获取文件资源；加载占位不确认就绪，等待真实内容或加载/渲染完成。

### 终端会话交接基础

`beginTerminalHandoff` 仅预留指定会话，去重后在首次异步准备前检查整批可用性。
原参与者在整批准备完成前保持预留；取消不能让迟到的 detach 落在 rollback 之后。
原生转移提交前检查 `isCurrent()`，目标实际接管后调用 `commit()`；提交后的来源即使
已经卸载也绝不能重新 attach。失败调用幂等 `rollback()`，只重试未成功的原参与者，
不会改用同 ID 的新参与者。后台挂起拥有独立批次，恢复通知不抢占其他窗口交接。

私有终端 JSON 编码把字符集、tab stop 和私有模式中的 undefined 显式转为可逆 null，
包括字符集数组空槽；恢复时还原 xterm 需要的 undefined，而不是直接使用 JSON.parse
的 null。版本、结构、字节、节点和深度检查在实际拆除/恢复前执行，超限不截断。
面板编码上限 1 MiB；后台继续使用既有 64 MiB 上限，完整快照仍受原生总量限制。
后台快照 v2 使用这条编码，兼容读取原 v1。快照含屏幕与输入草稿，始终只留在内存，
不得进入设置、日志、插件 Bus 或公开发现。

此批次接入了后台恢复，并使用实际发布的 xterm 解析器测试 JSON 往返、Unicode 分包、
备用屏幕、字符集和键盘模式；它没有开放终端独立窗口。后续仍需精确文档/面板租约的
原生 PTY 流端点、主协调器动作与共享资源句柄、页面适配及真实 SSH 窗口验收。

### 原生终端流端点

私有 `panel_window_terminal` 仅允许主协调器把已有、已发布、用户管理的 PTY 绑定到
原生面板；插件/专用后台连接不可借此变成终端。绑定捕获精确 writer 通道，不按会话 ID
重新寻找或连接。动态 `terminal:` 前缀本身不准入移动，只有当前协调器文档绑定的
实际存活资源才可移动。移除面板退休绑定，不关闭 SSH；进入原生呈现后的会话必须由
新的原生呈现租约继续 attach，不回退到不带租约的旧订阅。

Attach 使用专用 Tauri Channel，不经插件 Bus 或公开事件发布屏幕内容。输出逐包检查
原文档/面板/代次及资源实例，并在同一所有权锁内投递；暂存目标不能 attach。Detach
返回 actor 的输出序列屏障，目标须在提交后、恢复屏幕及注册监听后才 attach。
旧接收方失效或投递失败会把精确字节保留到有界缓冲，恢复时不跳号、不重放已经交付的
包，满缓冲沿 SSH channel 回压。旧无租约 attach 不得夺回已经进入私有呈现的流。

Write/resize/detach 在入队和实际执行时都校验精确来源。已准入工作的面板围栏跨越 IPC
接收方销毁、队列等待及真正的 SSH 写入，操作完成后才释放；拒绝入队不自动重试输入。
主机/凭据/连接创建、断开和任意 IPC 不在这个流入口开放。前端客户端只清理本地监听，
不在销毁时发可能抢占后继接收方的迟到 detach。

该批提供端点与宿主私有客户端，测试包含本地真实 SSH 协议/PTY actor 的接收方交接、
拒绝旧输入、序列回放及连接保持，但不是实际原生窗口或用户远程服务器验收。
终端页面/设置/提供者/资源生命周期的接入仍在进行；目前不展示终端跨窗入口，也不宣称
通用 `nativeWindows` 能力已齐备。

### 终端渲染服务与关闭回放

`TerminalPageView` 是共享生产渲染器。主协调器提供本地服务；独立窗口适配器需注入
只读终端设置、限定作用域的 I/O/事件、检查点注册及主窗持有的界面操作。设置投影
不包含插件授权、代理配置等无关可写数据。字体、检查点及事件监听恢复后才报告
渲染就绪，随后才请求 attach；暂存适配器可在 attach 中等待正式获得所有权。
视图或租约失败不能作为断开原 PTY 的依据。

面板捕获区分 `checkpoint` 与 `move` 意图，不同意图不得共用正在执行的捕获。
日常输入/滚动保存不是持有迁移暂停屏障的授权；未指定意图的旧调用仍视为检查点。
真正的迁移仍需完成提交/回滚处理，仅有此区分不会开放终端独立窗口入口。

远程 shell 在暂离时退出，actor 最多保留 60 秒的尾部输出，覆盖有时限的窗口交接。
关闭后拒绝新增远端输入和尺寸修改，只接受通过授权的回放连接；成功排空后才完成
常规会话清理。接收端拒绝数据时继续保留，直到有效 attach 或到期；用户主动关闭
仍立即清理。这是有界内存交接缓冲，不是持久化终端历史。

### 生产终端独立窗口适配

内置终端标签在主窗和独立窗复用生产渲染器。首次渲染前绑定已有 PTY，主窗发布明确的
只读会话/设置投影，shell 退出后保留显示元数据直到标签关闭。目标先恢复解析器，再按
正式所有权 attach；迁移检查点预留持有到原生提交或回滚。断开、文件/历史导航、剪贴板
及用户启用的命令记录由主窗执行，调用不能选择其他主机/会话或修改无关设置。

普通标签菜单提供跨窗入口；独立窗复用本地工作区/小窗框架和返回操作。当前选中终端
界面提供者时禁止向外迁移，但始终允许返回主窗；在外期间切换提供者会明确显示恢复
提示，不静默替换插件。公开通用 nativeWindows 发现仍为 false。

隔离 macOS 验收使用真实 SatelliteApp 与本地 SSH：跨窗往返始终只有一次认证和一个
shell，未完成命令在目标继续输入，ANSI/中文/emoji 屏幕返回后保留，旧来源输入被拒绝，
测试资源已清理。此验收不覆盖真实鼠标跨窗拖拽、Windows/Linux 混合 DPI 或任意远程服务器。

自然退出但标签尚未关闭的终端可继续迁移只读显示绑定；这不会重新打开 PTY，也不会在
退出后授予输入或尺寸修改权限。

### 文件页面资源边界

`SftpPageView` 为共享生产文件渲染器；必需的 `FilePageServices` 提供明确的会话/主机/
文件设置只读模型，以及文件系统、工作区/剪贴板/搜索/预览操作、插件菜单、提供者界面、
原生文件拖入及快捷键路由。主窗专用包装继续提供既有 store/IPC 服务；独立窗必须注入
带租约的服务，不得填充主窗可写全局 store。面包屑子目录读取也使用同一注入后端；
`createFileSystem` 的操作失败不会回退到主窗全局 IPC。

此拆分保留当前主窗文件功能，但尚未开放 SFTP 标签跨窗；仍需接入精确原生资源注册、
实际执行围栏、限定作用域的操作/提供者、状态交接与真实 SSH/SFTP 窗口验收。完成前
继续隐藏入口，不用只读演示替代完整文件工作流。
