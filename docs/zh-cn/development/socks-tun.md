# SOCKS5 域名转发与 TUN 插件

[English](../../en-us/development/socks-tun.md)

## 协议边界

代理组拥有一个已认证 SSH 连接和一个本地 SOCKS5 监听端口。客户端连接该端口并发送
SOCKS5 `CONNECT` 请求。域名请求不会在本地解析，而是原样通过 SSH `direct-tcpip`
交给 SSH 服务器解析，因此不会修改 hosts 或系统 DNS。

首版支持 greeting、无认证、用户名密码认证、IPv4、IPv6 和域名目标。仅支持 TCP
`CONNECT`；`BIND` 与 `UDP ASSOCIATE` 返回稳定的 SOCKS 拒绝回复，不会被静默当作
TCP 处理。

代理组默认只监听回环地址且无认证。非回环监听必须启用用户名密码认证，界面和运行时
都会显示暴露警告。握手、连接建立、空闲连接、并发连接和规则数量均有上限。

## 规则匹配

规则属于代理组，优先级固定为：

1. 精确域名和端口；
2. 精确域名、任意端口；
3. 最长 `*.example.com` 通配符和端口；
4. 最长通配符、任意端口；
5. 最长 CIDR 前缀和端口；
6. 最长 CIDR、任意端口；
7. 组级未命中策略。

通配符只支持 `*.example.com` 形式，`example.com` 不匹配子域，不支持正则。命中后
使用规则配置的远端目标；目标字段留空时保留原请求目标。未命中策略为 `direct`、
`remote` 或 `reject`，默认 `direct`；`remote` 保留原域名交给 SSH 解析，`reject`
返回连接拒绝。

同一代理组及其规则共享一条 SSH 连接。`dedicated` 规则使用独立本地 TCP 监听端口。
独立监听字段只接受可绑定 IP；输入域名时，客户端可将其解析为本地地址并显示最终可
连接地址。

## 运行时与观测

启动代理组会建立 SSH 连接、组监听端口及所有独立监听端口。停止组、断开 SSH、撤销
插件运行代次或退出应用时，会关闭监听及活动连接。运行中的组修改 revision 会被拒绝。
手动停止或显式断开会使自动启动保持暂停；只有启用重试选项时，SSH 连接意外关闭才会
自动重连。

连接记录包含来源、匹配规则、目标、字节数、开始时间和状态。API 可列出并主动关闭
连接；SSH 句柄、已保存凭据和认证校验材料不会暴露。

## TUN 插件

TUN 是可选流量适配器，不属于本体代理运行时。宿主负责代理组、规则、未命中策略、
SSH 会话、授权、状态和连接观测；插件负责各平台 TUN 设备、路由、DNS 适配和用户态
TCP/IP 栈，并通过组的本地 SOCKS5 端点转发。

一个 TUN 会话绑定一个主机或代理组；切换主机或组必须重新启用。DNS 模式包括：

- `system`：不接管 DNS，只支持 IP/CIDR 规则。
- `synthetic`：为匹配域名分配虚拟地址，连接前恢复原域名并交给 SOCKS5。
- `custom`：在用户明确确认风险后使用配置的上游 DNS。

首版只转发 TCP。UDP 只能直连或拒绝，不能伪装成远端转发。插件可携带自有 helper，
但必须显式安装和授权；发现 `trafficAdapters` 清单贡献不授予执行权限。授权在 helper
发布者/签名身份变化或用户主动撤销时失效。

helper 持有独立看门狗。宿主或插件异常退出时，它负责撤销路由、DNS 和虚拟网卡；
清理失败时，界面必须显示残留状态和修复入口。

## 权限与 API

实验性 API 可通过 `api.describe` 发现：

| 命名空间 | 权限 |
| --- | --- |
| `proxy.groups.*` | `proxy.read` / `proxy.write` |
| `proxy.routes.*` | `proxy.read` / `proxy.write` |
| `proxy.runtime.*` | `proxy.read` / `proxy.write` |
| `proxy.connections.*` | `proxy.read` / `proxy.write` |
| `proxy.tun.attach` | `proxy.tun` |

所有写操作都会重新检查原窗口/文档、运行时租约、revision 和取消状态。
`proxy.tun.attach` 只返回当前本地 SOCKS5 端点、一次性认证信息、规则快照和 revision，
不返回 SSH 句柄或原始存储凭据。

## 导入导出

存在代理组或规则时，主机迁移使用 `tunnelde-hosts` 第 2 版；继续导入第 1 版。没有
代理数据时仍导出第 1 版。第 2 版包含代理组和规则，导入时重新映射主机与组身份，并
排除明文密码、SSH 句柄和运行时会话。认证校验材料只存在于现有认证加密信封中；普通
导出不包含它。密码保护的导出继续使用现有认证加密信封。导入后缺少认证校验材料的密码组
保持停止状态，直到用户重新设置密码；自动启动不会绕过此要求。
