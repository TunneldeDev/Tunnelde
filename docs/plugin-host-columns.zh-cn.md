# 主机表格列

内置主机面板的「主机视图与列」菜单可切换树形和表格视图，默认仍为树形。表格可显示或隐藏列，拖动列头调整顺序，拖动可见分隔线调整宽度。点击列头依次切换升序、降序、默认顺序。键盘可用 Alt+左/右移动列，在分隔线上用左/右、Home、End 调整宽度。名称列横向滚动时固定，始终显示在首位，保证主机操作入口可达。设置 → 工作区也提供视图切换和重置列配置。

显示配置存入 `hostList`，随设置导出和 Profile 切换。插件列键为 `plugin/<插件ID>/<列ID>`。停止或卸载插件会移除其列，但保留显示偏好，同一插件恢复后可继续使用。排序列暂不可用时回到原主机顺序。文本采用自然排序，数字按数值排序，布尔值中 false 排在 true 之前；缺失值在两个方向均排最后。表格与树形共用主机选择、搜索、右键菜单和连接行为，手动调整主机顺序仍在树形视图进行。

实验扩展点 `hostList.columns` 支持运行时归属的纯数据列，要求声明并获准 `hosts.read` 和 `workspace.write`。注册或完整替换一列：

```ts
await context.api.call("hostList.setColumn", {
  id: "budget",
  label: "月预算",
  type: "number",
  width: 140,
  cells: [{ hostId, value: 0, tooltip: "按当前配置币种计算的预算" }],
});
await context.api.call("hostList.removeColumn", { id: "budget" });
```

`setColumn` 返回 `null`，`removeColumn` 返回当前运行时是否移除了已有列。列 ID 为 1–64 个 ASCII 字母、数字、点、下划线或连字符，标签为 1–120 个 Unicode 码点，宽度为 64–480 的整数像素，默认 140。类型支持 `text`、`number`、`boolean`，所有单元格必须匹配声明类型。文本最多 512 码点，可为空；数字必须有限；可选提示为 1–512 码点。标签、文本和提示均拒绝控制字符及双向覆盖/隔离字符。未知属性、重复或不存在的主机 ID、null、类型错误会拒绝整次替换。单列最多含 256 台不同的已保存主机。未提供的单元格显示为未设置，`0`、`false`、空文本保留原义；空 `cells` 不删除列。此接口不支持 HTML、CSS 或可执行的单元格渲染器。

每插件最多 8 列，全局最多 128 列；列的序列化 JSON 每插件最多 512 KiB，全局最多 4 MiB。替换时在注册锁内校验总配额，不重复计算被替换的旧列；失败保留旧列。贡献绑定已授权的插件指纹和运行代次，停止、崩溃、替换、撤权、受限模式和卸载均会清理。旧代次延迟退出不会清理新代次贡献。WebView 重建后读取权威快照，安全状态变化前排队的快照不再应用。此表现接口不创建已保存主机、不拥有 SSH 连接，也不代表新增插件订阅契约。

已知校验错误为 `plugin.hostList.invalidColumn`、`plugin.hostList.hostNotFound`、`plugin.hostList.limit`，另有常规权限和运行时错误。API 发现及扩展目录描述此能力，SDK 同步独立 DTO，不暴露内部表格实现。方法仍属实验状态，不修改 `apiVersion` 或已有稳定核心契约。
