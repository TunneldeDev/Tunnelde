# Legacy catalogue

The marketplace is maintained independently in
[TunneldeDev/tunnelde-hub](https://github.com/TunneldeDev/tunnelde-hub).
Tunnelde 0.21 and later consume its generated `registry.json` directly.

`index.json` is a compatibility snapshot for older desktop clients. Its package URLs point
to immutable releases in the hub. Submit plugins and themes to the hub repository.
