# 故障排查

## 终端没有颜色

Tunnelde 向服务器请求 `xterm-256color` 终端并呈现 256 色输出。如果会话仍显示为单色，请检查远端 shell
及命令本身的配色配置：

- `ls` 通常需要别名，例如 `alias ls='ls --color=auto'`；非交互式 shell 或没有配置文件的 root 用户可能没有该别名。
- 某些系统会在 `/etc/profile` 或 `~/.bashrc` 中将 `TERM` 设为 `dumb`；可在服务器运行 `echo $TERM` 检查。
- `git`、`grep` 和 `less` 也有各自的设置，例如 `color.ui`、`--color=auto` 和 `LESS=-R`。
- 若提示符由 shell 着色，确认 shell 实际加载了其配置文件，例如 Bash 的 `~/.bashrc` 或 Zsh 的 `~/.zshrc`。

在应用终端中可用以下命令快速检查 ANSI 色彩：

```sh
printf '\033[31mred\033[0m \033[32mgreen\033[0m\n'
```

如果明确的转义序列可以显示颜色，请检查命令和 shell 的配置。终端表格应统一使用等宽字体；xterm 按 Unicode
字素宽度计算，窗格大小变化时会重新计算网格。

## macOS 窗口无法从程序坞重新打开

更新到 0.24.1 或更新版本。程序坞的重新打开事件可恢复已关闭、隐藏或最小化后保留的主窗口。常规设置可以在
窗口关闭时隐藏程序坞图标；此模式下使用菜单栏托盘图标或再次启动 Tunnelde。选择退出会终止应用。

## AI 插件只显示本地或提示缺少工作目录

更新桌面程序和助手插件，在聊天的运行位置菜单选择已连接主机，或点击已保存主机的**连接 · 主机名称**，
通过连接弹窗验证主机密钥与凭据后自动选中。旧版桌面程序需要先在主机侧栏连接。选择模型不会选择机器，
无需复制会话 ID 或手动配置主目录。

需要自定义工作目录或可执行文件时使用工作区和执行设置。编码 CLI 必须在选定机器上安装并登录，本机登录不能
认证另一台远端安装。启动失败会显示有长度限制的标准错误和原生任务错误，包括找不到可执行文件。若无头 SSH
会话的 PATH 与终端不同，可设置其明确路径。不要向模型发送登录令牌或私钥。

远端 API 助手需要明确授权远端 Node 环境，并在上传源码前确认。普通远端编码助手通过 SSH 标准输入/输出运行，
无需下载 `tunnelde-agent`。参阅[助手指南](ai-assistants.md)。

## 配置后密钥登录仍失败

- Tunnelde 在 `<data>/keys/tunnelde_ed25519` 保存自己的密钥对，并将公钥追加到服务器的 `~/.ssh/authorized_keys`；写入成功后主机会切换为密钥认证。
- `authorized_keys` 和 `~/.ssh` 不能允许组或其他用户写入，否则 `sshd` 会拒绝密钥。可检查并按需使用 `chmod 700 ~/.ssh` 和 `chmod 600 ~/.ssh/authorized_keys`。
- 非标准主目录或受 chroot 限制的 `internal-sftp` 可能导致密钥落在账号实际主目录之外。可使用 `ssh-copy-id` 手动添加，并在主机对话框中选择密钥文件。

## 插件文件夹或压缩包无法安装

- 文件夹根目录必须包含 `tunnelde-plugin.json`；压缩包可以包含一个带有该清单的顶层文件夹。
- 更新已安装包需要重新审核身份和权限，先停止正在进行的工作。替换会保留插件专属设置，并校验新文件。
- 归档最多包含 2000 个条目、解压后不超过 64 MB；试图越出目标文件夹的条目会被拒绝。

## 文件预览要求安装插件

从市场安装兼容的预览提供者以支持更多格式。选中文件后按空格或使用预览按钮。文本和 Markdown 提供内建预览；
不支持的媒体编码可能仍需外部播放器，预览插件不会安装系统编解码器。图标主题与预览插件相互独立。

设置详情参阅 [SSHFS](network-storage.md#sshfs-挂载插件) 和[助手指南](ai-assistants.md#远端运行环境授权与文件)。

## 切换网络后传输停止

重新连接同一已保存主机，从状态栏或 F1 打开**传输**并选择恢复。保留的传输会重新绑定该主机和地址的新会话；
修改主机地址不会重定向现有任务。已完成文件会保留，恢复前会校验保留的部分数据。

取消会停止任务并尝试移除暂存文件；移除操作会在任务拥有的临时数据清理后删除任务。如果目标离线，清理会保持
待处理并在重连后重试。任务详情保留错误和重试操作。显示“排队中”表示正在等待共享通道容量，开始运行前不会
显示速度估计。参阅[传输恢复](network-storage.md#暂停与恢复传输)。

发布页面而不是直接下载。
