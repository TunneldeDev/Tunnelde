# 使用习惯持久化与管理

使用习惯是用户数据，重启、版本升级和安装包替换不得清空；禁止在启动或升级时按应用版本清理。
设置 → 使用习惯提供独立入口，可搜索。每个类别同时说明保存范围、重置后果和生效时机。
重点说明使用文字与警告区域突出，重置前列出所选类别并显式确认；失败保留选择与错误。

| 类别           | 保存位置与行为                                                                        | 重置范围                                                               |
| -------------- | ------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| 原生窗口       | window-state 的应用配置目录；大小、位置、最大化、全屏；监视器变化时由原生恢复逻辑校正 | 主窗口与当前独立窗口恢复默认尺寸并居中，重新保存                       |
| 面板           | 数据库 settings 的私有 `user-habits-v1` 记录，浏览器缓存用于同步读取                  | 呈现位置、浮窗尺寸／位置、打开／固定状态、侧栏选择、私有工作区浮窗几何 |
| 字体和字号     | 原有应用 Settings；导入字体独立保存                                                   | 仅恢复字体选择、界面及等宽字号；不删除字体文件                         |
| 外观与排版     | 原有应用 Settings                                                                     | 主题、颜色、自定义 CSS、密度、动效、侧栏与右侧面板宽度、主机列表风格   |
| 文件视图       | 私有习惯记录；每位置列宽、排序、分组、布局和分栏比例                                  | 清除对应缓存，重开视图生效                                             |
| 打开路径和面板 | 原有工作区 tabs 及冻结 v1 布局记录；远端路径以离线状态恢复，不自动连接 SSH            | 清除下次启动快照；当前编辑保留，本次运行暂停启动快照保存，避免马上写回 |

后台任务浮窗无用户几何时默认右下角，避开状态栏；已保存位置优先。超出可用区域时校正至可见范围。
工作区浮动位置存于私有扩展记录，不修改冻结的公开 workspace v1 契约。

启动先读取原生持久副本，再恢复已创建的面板 store，然后恢复工作区。仅在原生记录不存在时迁移旧
localStorage；空记录同样是有效的重置结果。数据库读取失败时不写默认数据覆盖原记录，管理页显示错误。
主文档串行写入最新快照，独立窗口通过同源存储事件通知主文档；不得获得通用设置或数据库写入权限。
允许的键前缀、条目数、单值及整体大小均在原生端校验。不要将习惯正文、目录路径、文档内容或凭据写入诊断日志。
设置独立窗口通过封闭的 `habitsReset` / `habitsDetails` 所有效果调用同一主窗口服务；持续投影仅含状态和计数，明细通过按需读取返回。

验收必须覆盖：旧缓存迁移、更新后原生副本恢复、已初始化面板再水合、慢写入有序、损坏副本不被覆盖、
分类重置不触及主机／凭据／草稿，以及主窗口／独立设置窗口的相同行为。UI 风格登记见
[功能界面台账](ui-surface-catalog.md)。

每类提供独立展开入口，按需读取具体记录；展示已保存、当前值、默认值来源，允许选择和复制长路径。展开不勾选重置；读取失败显示错误及刷新按钮。重置后旧明细失效，重新展开读取最新值。窗口坐标和尺寸以物理像素展示。工作区仅展示白名单布局和路径，不包含编辑内容。
